## Purpose

Builds the second tavern list: 64 positions, each with a four-bit progress variable; a position with a nonzero variable gets an entry.

## Behavior

- V: walks positions 0..63 except 18, 21, 52 and 53, reads event variable 960 + position; a nonzero value v (1..15) makes the list item `v + 16 x (position - 256)` as a u16 (bank 30 message 16 x position + v).
- V: stores the items into the shared list array and the parallel array with the same 128-entry check as the story event list, sets up the list widget (sub_140379F3C(11, n)), and pushes page kind 31.
