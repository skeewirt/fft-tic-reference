## Purpose

Loads the numbered key texture part (a key icon) into a widget: builds its path, asks the widget to load it and returns the name.

## Behavior

- V: path = Str_Format('ui/platform/%s/textureparts/key_%03d_uitx', 'win', key), then the UITextureParts scheme prefix (the word UITextureParts, a colon, two slashes) followed by the path; widget == 0 returns 0. sub_1403FBE3C(widget, name, flag) loads the resource; 0 returns 0. When outName != 0 the name is copied there (256 bytes). Returns 1.
