## Purpose

Applies a picked id to a slot, copies the scratch record's hand words into the candidate array and refreshes
the detail.

## Behavior

- V: When the id is non-negative it calls `sub_140288590(0x36, slot, id)` (masked id), then copies the scratch
  record +0x54 to `g_EquipCandidates` with a qword move (0x14036C2DE) and the word at +0x5C to the fifth candidate
  (0x14036C2EB), and calls `sub_140287354`.
- V: The copy is raw, so a bit-15 word in the scratch record travels into the candidate array.
- V: It ends in `sub_14036C320` to refresh the two-handed/detail state.
- I: This is the shop/equip "confirm one row" path; the applied id is masked, but the candidates keep whatever
  flags the scratch record had.
