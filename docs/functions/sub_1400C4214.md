## Purpose

Requests one resume point from the autosave container: the main part always, and optionally the world, attack and fturn parts, then kicks the read.

## Behavior

- V: it always requests the main part of the point.
- V: with the all-parts flag it requests the world, attack and fturn parts for points 2 to 4, or the world and attack plus the main part for point 1.
- V: the per-entry requests are made by the name routine, six of them at most in one call.
- V: it ends with one read kick for the `AUTOENHANCED` area, which is what makes the delivery path run.
- V: four callers and six sites: the boot ring builder, the load-screen setup, the load confirmation and the title.
- I: the "point 1 has no fturn part" exception matches the fan-out, which writes four parts for a battle point and three for a world point.
- ?: what a point index above 4 would request; no caller passes one.
