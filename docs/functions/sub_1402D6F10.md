## Purpose

The per-frame dispatcher of the Outfitter/equip screens: it builds a small message from the input state and
calls one of the three screen handlers by menu id.

## Behavior

- V: It reads `word_141848BB0` (0x1402D6F23) and builds a message with dword -1, byte 0, the input dword and
  the input word (0x1402D6F45 and 0x1402D6F50).
- V: Menu id 6 calls `sub_1402D67C8` (0x1402D6F9E); menu id 7 calls `sub_1402D6914` (0x1402D6F92); menu id 12
  calls `sub_1402D6E14` (0x1402D6F86).
- V: Every other id falls through without a handler.
- I: The three handlers are the equip screen, the shop screen and the commit/cancel screen; the dispatcher is
  the single place that decides which one runs.
