# sub_140206C14

- **Address:** `0x140206C14`
- **Area:** [Battle](../areas/battle.md)
- **Prototype:** `? sub_140206C14(int chargeType)`
- **Callers:** The charge step of an action
- **Callees:** sub_140255D8C, sub_1402607C0

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Maps an ability's charge type to a charge motion through the charge-motion pair table.

## Behavior

- V: the body reads the charge-motion pair table at 0x1406735A8 (named g_ChargeMotionPairs).
- V: the pair table gives two bytes per charge type, and the function selects the motion from that pair.
- V: it also reads the battle state word and a battle UI global.
- I: the charge type comes from the first byte of the ability animation row (g_AbilityAnim), so this is the bridge from the animation table to the charge pose.
- ?: the meaning of the second byte of each pair.

## State touched

- Reads: [g_ChargeMotionPairs](../globals/g_ChargeMotionPairs.md)

## Notes

Evidence: the body scan. 123 bytes; the pair table is the only table it touches.
