# sub_140327004

- **Address:** `0x140327004`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `void sub_140327004(void *record, int direction)`
- **Callers:** sub_1402CDBC4, sub_1402CE7A8
- **Callees:** memmove

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Moves the ten item order lists between a work record and the live arrays, in either direction. The record keeps the lists
contiguously after a small header, so one call can save or load all of them.

## Behavior

- V: the first argument is the record; the second selects the direction.
- V: direction zero copies the live lists into the record; a non-zero direction copies the record's lists into the live
  arrays.
- V: the record holds the lists from offset 50 onwards in this order: five item order lists of 141, 30, 38, 34 and 21
  words, then the equipment block of 141, 30, 38, 34 and 262 words.
- V: the copies are twelve inlined fixed-size moves, six per direction, with the sizes 282, 60, 76, 68, 42 and 1010 bytes.
- V: besides the lists it copies a number of other record fields in the same direction.
- V: it writes only the record or the live arrays, never both in one call.
- I: the two callers are the pair that stores and restores a world-state copy, so this is their order-list half.
- ?: which game record the callers pass; one passes a static buffer, the other a variable.
