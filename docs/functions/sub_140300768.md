## Purpose

Event unit-block task that paints one scene unit: it reads the shape byte of the unit's job row and drives the sprite and text setup.

## Behavior

- V: It reads the 49-byte job row at 0x140785E30 and guards the job id with an 8-bit compare against 0xAE before the read.
- V: The field it takes from the row is byte 46 (shape); This reader does not touch the skillset byte.
- V: Sprite work goes through SpriteId_ToShape, and resource setup through ResourcePool_AllocBlocks, sub_1402F3A04 and sub_14033EA08.
- V: SceneTask_WaitFrame makes it a frame-yielding task, so the painting is spread over several frames.
- V: Three callers, all in the event unit-block path (EventUnitBlock_RunTask, sub_14020E578, sub_1402357C4).
