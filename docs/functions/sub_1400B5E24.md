# sub_1400B5E24

- **Address:** `0x1400B5E24`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `?`
- **Callers:** `sub_1400B57FC` (one site)
- **Callees:** `sub_1400C3814` (settings writer)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Applies a changed option block and asks for the settings container to be written.

## Behavior

- V: it is the config update path: the new values are collected by the caller and handed on, and the settings writer is called at the end.
- V: the settings writer copies a 240-byte block into the save object, computes its CRC and queues `settings.sav` with version 0, then kicks the `SYSTEM` container write.
- V: one direct caller, the option-change handler; the launcher's mode flags go through a different caller of the same writer.
- V: the write happens immediately on the change, not at quit, so a settings change survives a crash.
- I: the block is a whole snapshot, not a delta: every field is rewritten, which is why an older build's missing field comes back as a default.
- ?: which option change reaches this path and which one only updates memory until the next write.
