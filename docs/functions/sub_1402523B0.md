## Purpose

Parses a scene task's u16 token stream into its 0xA8-byte data record.

## Behavior

- V: the output record is 0xA8 bytes; the parser writes the four dwords at +0x88..+0x94 and the four u16 at +0x98..+0xA4.
- V: it writes the value 0x79 to 0x140D8ECB0, the dword immediately after the battle tile table.
- V: the four dwords at +0x88 are zero in every captured payload; the u16 pair is a map or task value in the 150..620 range.
- V: it also reads scene variables and NXD rows while parsing the stream.
- I: the token stream is a compact description of what the task should show or do, which is why the record is only 168 bytes.
- ?: the token encoding and the meaning of the four dwords.
