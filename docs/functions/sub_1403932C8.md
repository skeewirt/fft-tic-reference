Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The item screen's second row-icon callback: it takes one list index, masks the table word to an item id and hands it to `ItemIcon_Set`.

## Behavior

- V: reads `word_141D32F00[index]`, masks it with 0x3FF (`0x1403932DF`), and calls `ItemIcon_Set` with the masked id.
- V: the table word is the same 256-word item list used by `sub_1403931F0` and `sub_140393250`.
- V: bit 14/15 of the list word are dropped by the 0x3FF mask; the callback does not test the flag itself.
- V: no direct callers were found; the screen stores its address in `qword_141D3B948`.
- I: the callback is the icon-only counterpart of `sub_140393250` (which returns the palette bytes).
- ?: which of the two icon callbacks a given row uses.
