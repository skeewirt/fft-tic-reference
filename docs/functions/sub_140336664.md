## Purpose

Fills one row of the equipment list from the shared display list at a given index: the item, its price and count, and three
boolean flags the row gadget shows.

## Behavior

- V: takes the output row pointer, the list index and a kind byte.
- V: initialises the row from the display list entry at the index.
- V: reads bit 14 of that entry and stores it as the row's "cannot equip" flag.
- V: compares the row's item id with up to five equipped words of the selected unit record and stores the result as the
  "equipped here" flag.
- V: when the item's count check fails, it asks the inventory helper and a shop-entry helper for a fallback, and stores the
  result as a third flag.
- V: ends by calling the UI routine that pushes the row to its gadget.
- I: the five-word comparison against a unit record identifies this as the equipment screen's row, not a shop row.
- ?: what the kind byte changes; only its use as a pass-through was read.
- V: bit 14 is tested with the 0x4000 constant at 0x14033669C and the test at 0x1403366A1; the result is stored as the row's cannot-equip byte at 0x1403366B4 (entry +24).
