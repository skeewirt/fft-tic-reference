Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Writes every party unit's record back to its save row.

## Behavior

- V: It loops `g_PartyCount` units (0..count-1) and calls `PartyUnit_WriteBackToSave` for each (0x140285A7F).
- V: It is called by the commit handler after `sub_1402D65D4` has stripped the session bits, so the save rows
  receive clean words on that path.
- V: It is also called by the equip-now path `sub_140288590` and the return path `Party_ReturnHandItems`, which
  write committed (masked) ids.
- I: This is the save write of the equip session; a caller that runs before the strip would write a flagged
  word and `PartyUnit_WriteBackToSave` would index the item table with it.
