## Purpose

Takes a snapshot of the inventory counts that the battle code reads while the item menu is open.

## Behavior

- V: It clears a global dword, calls a helper on a global buffer and then walks the inventory.
- V: Each item id is masked to nine bits before the record lookup that decides whether the id is listed.
- I: The buffer it fills is the inventory snapshot the battle code reads, because the only other writer of that buffer is the equip-snapshot function.
- V: It calls five helpers and has one direct caller.
- I: The snapshot exists so that the battle item list does not change while the player is browsing it.
