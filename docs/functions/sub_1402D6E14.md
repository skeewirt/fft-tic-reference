## Purpose

The Outfitter's commit/cancel message handler. Message 0x3D commits: it flushes the session price, strips the
flags from all units, saves them and refreshes the job screen. Messages 0 and 6 cancel.

## Behavior

- V: Message 0x3D posts message 0xF811 (0x1402D6E47), then flushes `dword_143D1AC68` to gil by calling
  `sub_140284684` with its negation (0x1402D6E54) and zeroes the accumulator (0x1402D6E5B).
- V: It then calls `sub_1402D65D4` (0x1402D6E61) to strip the session bits and return the overrides, calls
  `sub_140285A6C` (0x1402D6E66) to write every party unit to the save, and ends with a tail jump to
  `JobScreen_RefreshAfterChange` (0x1402D6E9C).
- V: Messages 0 and 6 call `sub_1402D5B6C` (0x1402D6F03) to restore the override words; message 0 posts
  0xF802 and message 6 posts 0xFFFFFFFF.
- V: Message 7 only posts the close message.
- I: The order is deliberate: the price is charged first, then the flags are stripped, then the cleared words
  are written to the save. A save taken between the flush and the strip would not contain a flag.
