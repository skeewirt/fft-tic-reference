## Purpose

Picks the weapon animation for a battle action from the item in the unit's weapon slot and its record category.

## Behavior

- V: The weapon slot it reads lives at +0x1C8 of the unit record passed in the first argument.
- V: The id is masked to nine bits before the item record lookup.
- V: The rest of the function maps the record's category and kind onto an animation selector; the third argument is carried through unchanged.
- V: Two direct callers reach it and it calls three helpers.
- I: The +0x1C8 word is the unit's current weapon, since the same slot is read by the attack-damage code.
