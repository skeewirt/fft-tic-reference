## Purpose

The preview twin of sub_1402828E4: works out the MP cost of the action under the cursor and the same refusal codes, without paying.

## Behavior

- V: clears the MP cost byte (byte 0x1407B078E); the command kind is looked up in g_CommandKind at the formula block's command byte (0x1407B0776); the ability is the word at 0x1407B0778; the unit is the pointer at 0x14186AF78.
- V: the same chain as sub_1402828E4: a unit with the +0x65 mask-0x04 status or a non-zero sub_14030DD1C answer returns that answer + 6; a Toad unit (+0x63 mask 0x02) returns 5 unless the ability is 0, 367 or 29 (a command kind of 10 returns 5 whatever the ability).
- V: an ability above 0x16F skips the rest, so it gets no cost and no refusal here; for a kind-0 or kind-6 command with a stock id the action row's flag +5 mask 0x20 together with the unit's +0x62 mask 0x08 returns 2.
- V: for command kind 0 and a unit whose job byte is not 93 the cost is action-row byte +13, halved when unit +0x99 has bit 7; it is stored in byte 0x1407B078E only (no MP is taken, no 'not enough MP' answer).
- V: the single-id tests against 367 and 29 sit at 0x14030B202 and 0x14030B208.
