## Purpose

Looks up the button icon / name string for a control action id: the icon a key / pad rebinding table gives for (actionId, slot), else the default one from UI table 25.

## Behavior

- V: *outIconKey = 0. When the config byte g (qword_143CD9EE8 + 13696) == 1 (pad mode): key = sub_1400F6B5C(u16 at qword_143CD9EE8 + 16 * (slot + 86 + 3 * actionId)) (the bound button's icon id); if key != 0, writes the icon text with sub_1403DC8D0(outStr, key, outBuf, 0).
- V: if no key: slot 1 returns 0; slot 0 reads UITable_GetRow(25, actionId): when the row's dword at +16 is non-zero, uses icon 165 (a default / 'unbound' mark) via sub_1403DC8D0.
- V: otherwise (mode != pad or nothing found): id = sub_1400F6A80(actionId); if id != 0 returns sub_1403DC7BC(outStr, id, outBuf, 0) else 0.
