## Purpose

Returns the price of the item in a shop list row, with the list's cannot-equip flag reported separately.

## Behavior

- V: It masks the list entry at the row index to ten bits and reads the item record's price word.
- V: It then masks the entry with 0x4000 to read bit 14 and returns that flag alongside the price.
- V: It calls one helper and has no direct caller.
- I: The price and the flag travel together because the row drawing code needs both in one call.
- V: the id is masked at 0x14036A9B0, bit 14 is selected at 0x14036A9C1, and bit 30 is set at 0x14036A9C7; the row value is the item price plus that bit.
