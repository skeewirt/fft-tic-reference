## Purpose

Refreshes a unit's sprite palette for the item it holds, branching on the unit's current pose/shape.

## Behavior

- V: takes two object pointers and a flag; returns at once when the two pointers are equal.
- I: the first pointer is the render object and the second the unit, because the second is read for the unit fields below.
- V: reads a word at unit +0x1FC, halves it, and special-cases the values 26 and 52.
- V: reads the unit's held-item pointer at +0x148 and calls a pose/shape helper.
- V: when the helper's result is below 2, takes the item branch.
- V: on the item branch it calls ItemSprite_LoadPalettes with the item id taken from the held record at +0x1C2 and the flag set to
  1.
- V: eleven direct calls (sub_140204CDC three times), plus the stack-cookie check.
- I: the callers are battle and unit-render paths, because they pass unit objects and the flag controls whether the palette is
  rebuilt.
- I: the function rebuilds the palette rather than setting it once, because it is called from several animation paths.
- ?: the meaning of the 26 and 52 pose values.
