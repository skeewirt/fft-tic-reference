# sub_1402D58EC

- **Address:** `0x1402D58EC`
- **Area:** [UI framework](../areas/ui-framework.md)
- **Prototype:** `char sub_1402D58EC(void)` (screen-table handler)`
- **Callers:** none direct; called through the screen table pointer at 0x140680A88
- **Callees:** `Input_TestAction`, `Item_GetRecord`, `PartyUnit_ReloadEquipment`, `sub_140286DDC`, `sub_1402BD740`, `sub_1402BDD74`, `sub_1402C4880`, `sub_1402D5854`, `sub_1402D64CC`, `sub_140328F0C`, `sub_140303DE8`

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The Outfitter slot-list handler: it tracks the selected slot, shows its help id, and on confirm either undoes
a pending bit-15 purchase or opens the equip-change preview for the slot.

## Behavior

- V: It reads the selected slot word at unit +0x54 + 2*slot, masks it with 0x3FF for the help token
  (a 0x3FF mask at 0x1402D59E6) and stores 0x6800 + id in `g_HelpIdSlot`.
- V: On the confirm input it tests the word against 0x8000 (a comparison with 0x8000 at 0x1402D5A6C): a word below it
  sets UI state 5 and does nothing; a word at or above it is treated as a pending purchase.
- V: For the pending word it subtracts its masked price from `dword_143D1AC68`, calls `sub_1402D64CC` to
  restore the override (0x1402D5A90), calls `PartyUnit_ReloadEquipment` (0x1402D5A95) and sets UI state 7.
- V: When the selected slot changes it re-reads the word, tests it against 0x8000 again (a comparison with 0x8000 at
  0x1402D5ACD), and either closes the preview (below 0x8000) or opens it by calling `sub_140286DDC` with
  `g_EquipSet` (0x1402D5B00), the unit's record copy and the override word (0x1402D5AF7).
- V: It updates the help panel (`sub_140328F0C`) and the cursor word at 0x143CDA8C2; it ends with the price
  delta helper `sub_1402D5854` when `byte_140D408E3` is set.
- I: The two 0x8000 tests are the same session flag at two moments: the first is the confirm/undo action, the
  second is the preview switch when the cursor moves.
