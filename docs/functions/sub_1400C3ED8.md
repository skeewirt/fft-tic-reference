## Purpose

Packs one resume record under a given name: it ensures a map record exists for the name, copies the group's buffer into it, clears the group's ready byte and queues the entry.

## Behavior

- V: the name is the entry name already formatted by the caller; this routine does not build names.
- V: it stores the group's payload through the group store, which frees the old record buffer and copies the new one.
- V: after the copy it clears the group's ready byte, so the same capture is not packed twice.
- V: when the file object is absent it falls back to queueing the entry directly through the entry writer.
- V: one call site, the name fan-out of the flush.
- I: the map insert plus the store is the dedupe: two captures for one name keep the newer bytes and one queued entry.
- ?: what the fourth and fifth arguments select (point and flag) beyond being passed through.
