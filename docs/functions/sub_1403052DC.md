## Purpose

Filters the pending add / remove status sets of the current action against the target's immunities and the status property table; returns how many bits remain.

## Behavior

- V: works on the current target (qword_14186AF68) and the action work block (qword_14186AF70: add set +29..33, remove set +34..38).
- V: when the target's byte +436 is negative, masks the add set with byte_1406829E4.
- V: copies both sets into a work area at qword_143CD9EF0 + 693675.
- V: removes from the add set the target's immune bits (+58 / +63 / +68) and, when target byte +5 bit 2 is set, the mask at xmmword_1411A6A70 + 1; masks the remove set with the target's +466 bits.
- V: unless `skipChecks`: for each status k in the add set, drops it when any of entry k bytes 11..15 meets the target's +97..+101 (the address 0x140788FEB, entry 0 byte 11, is loaded at 0x140305420); then for each status k still added, clears entry k bytes 6..10 from the add set (the address 0x140788FE6, entry 0 byte 6, is loaded at 0x14030547E).
- V: returns the sum of the ten set bytes (add set + remove set, byte values, not bits).
- I: bytes 11..15 = statuses that block this one, bytes 6..10 = statuses this one cancels.
