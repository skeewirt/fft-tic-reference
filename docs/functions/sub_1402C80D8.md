## Purpose

Counts the copies of an item a unit has equipped, used by the equip screens to show whether another copy is available.

## Behavior

- V: It walks the unit's equipment words and masks each one to nine bits for the record lookup.
- V: A word equal to 255 is skipped; three separate sentinel loads re-establish that value across the loops.
- V: The count it returns is the number of matching slots, not a boolean.
- V: It calls fourteen helpers and has one direct caller.
- I: The walk covers the roster record's seven equipment words, while the battle record exposes only five hand slots.
