## Purpose

Item-menu command handler: it reacts to the current menu command read from the UI core, opens the shop or the list, and advances the menu state.

## Behavior

- V: It reads the dwords at UI core +0x3488 and +0x348C and returns 1 when they are equal.
- V: It handles the value 2000 (0x7D0) specially: it fetches the UI context at +0x160 and calls its vtable slot +0x18.
- V: It then calls sub_1400EBFC4, sets context +0x48 to 1, and calls sub_1401AA494 when a list object exists at +0x40.
- V: It calls sub_140334A48 and sub_140338060 to rebuild the list for the new state.
- V: Two callers, sub_140332DB0 and sub_140335B88.
