## Purpose

Fades a guide slot in or out: finds the slot of row `row`, sets its node visible byte and plays Gauge_on / Gauge_off.

## Behavior

- V: finds the slot (of 8, stride 272) whose dword at +312 (row +40 from slot start) == row; returns if none.
- V: if slot node (+296 from slot base) != 0 sets its +144 = on, GUINode_UpdateColourAndMatrix, UpdateSubtree. on != 0: copies pointer +304 into +240 and sets +248 = 112, calls sub_14028F804(slot + 224); on == 0: sub_14028F804 then +240 = 0.
- V: when node +272 exists: stops 'Gauge_off' (on) or 'Gauge_on' (off), then plays the other (state +104 = 1, GUINode_PlayState).
- V: sets byte +316 = on and +317 = 0.

## Notes

sub_14028F804 plays 'Gage_out' (note the different spelling 'Gage') and stops the slot's sound with sub_1400F4C54. The 'Gauge' states here are named for the timed bar, not a character gauge.
