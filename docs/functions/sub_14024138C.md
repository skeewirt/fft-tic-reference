# sub_14024138C

- **Address:** `0x14024138C`
- **Area:** [Event system](../areas/event-system.md)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Applies or clears a status on a preview unit from an event command, then refreshes the unit's status display.

## Behavior

- V: it is the helper behind event status apply, the 0x92 event command (0x92 is the event opcode id, not an immediate in this body).
- V: it copies the status bytes for preview units, so the panel shows the change immediately.
- V: SceneCallback_Dispatch is called three times, once per callback the event task needs.
- V: the status resolver and the status icon updater are reached through stored pointers, not direct calls.
- V: it reads scene variables and the live unit table.
- I: an event command that inflicts or removes a status outside battle, with the UI refreshed in the same step.
- ?: the operand layout of opcode 0x92 and what each of the three callbacks does.
