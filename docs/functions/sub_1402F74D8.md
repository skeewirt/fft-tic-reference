# sub_1402F74D8

- **Address:** `0x1402F74D8`

- **Callees:** none

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Expands one 16-colour RGB555 palette into the two working palette forms a unit sprite slot uses.

## Behavior

- V: takes a palette pointer, a sprite palette slot (5 or 6) and an index.
- V: reads 16 two-byte colours, 32 bytes in all, from the palette pointer.
- V: writes each colour as a 16-bit value into one working table and into a second working table at a different base.
- V: also writes a 7-byte-per-colour form, expanding the five-bit channels to bytes with the high bit kept.
- V: all destinations are addressed from the slot and the index.
- V: two direct call sites, both in one palette-set routine.
- I: the 7-byte form is the shader-facing colour record and the two 16-bit copies are the raw RGB555 source kept per slot, because
  the same 16 colours feed all three.
- ?: the exact table layout and why three copies are needed.
