Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Fills the "Level Requirements for <job>" window of the Change Job grid: one row per job the selected cell's job requires, with that job's icon and name, the required level and the unit's current level (or "Locked").

## Behavior

- V: it does nothing unless the grid cursor (`addon + 19016`) is 0..18. The selected cell's job word (`addon + 0x22C8 + 148 * cursor`) goes through `Job_IdToIndex`, and the result is the key of the GeneralJob row (table 0xBD) it reads; no row, no change.
- V: the window title takes the selected cell's name (the string at the start of the cell record, `addon + 0x2280 + 148 * cursor`) as its argument.
- V: the GeneralJob row's list columns are read as offset / count pairs: required job indices at `+16` (count `+20`), required levels at `+24` (count `+28`, 16-bit entries; a missing or smaller entry counts as 1).
- V: for each required index it searches the 19 cell records in order for the first cell whose job word answers that index through `Job_IdToIndex`. From that cell it takes the icon (`+64`), the record for `JobTreePanel_SetJobIcon`, the state (`+132`: not 0 shows "Locked" in place of a level) and the unit's level (`+68`). The level text is red when it is below the required level.
- V: when no cell answers the index, the row's icon, name and current level are not written: the row keeps what it showed the last time the window was filled. Only the required level is written.
- V: a job word the mapper does not list (anything but 74..93, 160 and 161) answers index 0, so a cell whose job word is 0 matches a requirement of index 0.
- V: after the rows it plays the node state `Num%02d` of the count of required jobs, which sizes the window to that many rows. With a count of 0 it formats `Num00`.
- V (seen live 2026-11-24): with the 19 cells holding a later part of a longer job list (the first two jobs not in any cell), the window of a job that requires those two showed for the first a locked "???" row (a cell with job word 0 answered index 0) and for the second a row with another cell's icon, no name and "Lv." with no number. With the required jobs' records in the cells the same window showed both names and levels.
- V (seen live 2026-11-24): with the cursor at -1 (no cell selected) the confirm button does not open the window.
