## Purpose

Refreshes the job-tree panel's job rows: it walks the GeneralJob prerequisite lists, maps each job id to its index and writes the panel's name, icon and prerequisite text.

## Behavior

- V: it reads the GeneralJob row's four list columns (`+16`, `+20`, `+24`, `+28`), which hold prerequisite job indices and the count of the required-jobs list.
- V: it resolves each job id to an index through the job index mapper, so a job id the mapper does not list (anything but 74..93, 160 and 161) collapses to index 0, the first slot.
- V: it sets the panel's icon through the job-tree icon setter and its text through the text slot setter.
- V: it reads only those list columns; the later review of the table noted that the flag bytes the earlier brief attributed to it are not read here.
- V: two `Job_IdToIndex` call sites inside the routine.
- I: the prerequisite lists are what draw the tree's "requires" arrows; the count column is the guard for the list length.
- ?: how the panel decides which row it is refreshing; no row argument was visible in the call.
