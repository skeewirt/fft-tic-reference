## Purpose

The stat calculator behind `sub_140287354`: it masks the five unit and candidate words and computes the
attack/defence differences into the block.

## Behavior

- V: When `unit_words` is set it fills two five-word arrays with the unit words and the candidate words, each
  masked with 0x3FF (0x140287176/0x140287196).
- V: It calls `sub_140286FEC` twice to build stat rows for the job/mode and the extra argument, then
  `sub_140286E7C` to write the difference into the block.
- V: It returns the difference of two stat words and stores them at record +14 and +20.
- V: A flagged word is masked before it reaches the stat row; no flag is tested.
- I: This is the only place the block's +0x06/+0x12/+0x1C stat groups are written from a candidate/unit pair.
