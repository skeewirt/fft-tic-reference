Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Rebuilds the row list of the Poachers' Den screen from the saved poach ordering, taking a vector of 40-byte entry records as its input.

## Behavior

- V: the second argument is a vector whose element size is 40 bytes; the function derives the element count from the vector begin and end pointers.
- V: it reads the poach sort array at 0x1411A7810 + 716 and the poach order array at + 619 while assembling the rows.
- V: the poach arrays are 97 bytes each, indexed by poach type, and the order array terminates on a zero entry.
- V: it calls sub_1402AA904 on a UI object obtained from the manager chain, then sub_140134DA8 and the two vector helpers sub_1401CAB50 and sub_1401CAC8C.
- V: the function returns without a value and does not write the poach arrays.
- I: the 40-byte element matches the shop entry structure used by the item list screens, so the den shares the shop row layout rather than defining its own.
- I: the purpose is the den screen's list refresh, because the only globals it touches are the poach ordering arrays and the entry vector.
- ?: how the order and sort arrays are combined into a row order; only their reads were traced.
