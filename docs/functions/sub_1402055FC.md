# sub_1402055FC

- **Address:** `0x1402055FC`

- **Callers:** sub_1402059AC, sub_140210AF0 (the battle state machine)
- **Callees:** none (it fills the queue directly)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Pushes one deferred battle message onto the sixteen-entry queue.

## Behavior

- V: the queue base is 0x142FCF870 and its count at 0x142FCF864, with a ceiling of sixteen entries of sixteen bytes.
- V: the entry id byte is written as 0x1C or 0x1D depending on the branch, together with the unit byte and a qword value.
- V: for the item message the value is the battle unit's u16 item id at +0x1C2; bit 15 is set when the flag word at +0x1D0 carries 0x1000.
- V: the function returns immediately when the unit argument is null and does not touch the message object.
- I: setting bit 15 tells the consumer to take only the low eight bits of the item id, which is why ids wider than a byte alias there (0x100 is the first id that does not fit, not an immediate in the body).
