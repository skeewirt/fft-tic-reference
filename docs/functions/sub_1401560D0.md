## Purpose

Fills the four command radio buttons of a command screen: each button gets the icon and the title of the skillset named by its text token (name token 0xB000 | set), so it is the one place a skillset's name is read straight from the JobCommand-en table.

## Behavior

- V: finds RadioButton01..04 (as parts of the widget's node and as descendants) and, for each button whose token dword (at widget + 0xA4 + 8 * i) is non-zero, sets the button's flag byte (+144) and takes set = token - 0xB000 as an int with no mask (the marker 0xFE is only a value the subtraction can give, not an operand).
- V: calls JobCommandTable_GetRow(set) and uses the row without testing it for null: the title text is read at row + 8 + *(int *)(row + 8) (0x14015645A). V (live 2026-11-12): a set id of 254 (token - 0xB000 = 254) has no row: the load at 0x14015645A faulted and the game froze when the battle Abilities menu opened.
- V: builds the icon path with JobCommand_FormatIconPath(set) and sets the Icon part of the button to it; sets the Title part's string with GUITextNode_SetString.
- V: set 17 (0x11, the Charge command) takes a second path: the title is expanded text 3018 with two arguments, the row's own text and the ability name row of the terrain ability for the unit at the screen's selected slot (byte_14067F750 indexed by the tile's terrain, AbilityTable_GetRow).
- V (live 2026-11-12): it runs when the battle Abilities menu opens, so it is the battle command title widget; I: the token is the name token the battle code writes (pool 22, 0xB000 | set); the caller sub_1400E8728 was not read.
