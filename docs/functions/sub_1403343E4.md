## Purpose

Refreshes an item detail or help panel for the selected record and builds the help text id that the panel shows.

## Behavior

- V: the selected index is a 16-bit global; the function compares it with the previously shown index and, on a change, calls the record and panel setters before reading the new record.
- V: the record pointer comes from a global pointer table at 0x141800F50 indexed by the selection; its +0x54 and +0x5C fields are copied into UI state.
- V: the help id is read from a per-item word table (base 0x3D1ADD8) indexed by the selected slot.
- V: a non-zero table word becomes 0x6800 plus the word and is stored in the help-id slot at 0x1418736B4; a zero word stores -1 (no help).
- V: the function then polls input with sub_1400FC598 and calls the shop helpers.- I: the panel is the item detail or help window of a shop or the party screen, and the table word is an item help index.
- ?: which screen owns the panel and what the table at 0x3D1ADD8 holds per slot.
