## Purpose

Identifies which text pack and which text kind a string-pool pointer belongs to. The scene message and battle message code use it to turn a raw pool pointer back into a class and a kind before choosing a handler.

## Behavior

- V: both output dwords are set to -1 before anything else; a null input returns 0 with those values.
- V: the function walks a table of 45 qword pack pointers with a stride of 8 bytes.
- V: for pack classes 0, 2, 3, 4, 5, 6 and 7 the pack pointer itself is compared with the input; a match reports kind 0.
- V: for the other classes the input is compared with all 32 group bases of that pack, each computed as the pack base plus a fixed header plus the dword offset stored for that group.
- V: a match writes the class index and the kind index and returns 1; the walk stops after class 44 and returns 0.
- V: the function calls nothing; it only reads the pack tables.
- I: the class is one localized text pack (45 of them) and the kind is the 5-bit text-id kind, so the pair (class, kind) is the full namespace of one text id in that pack.
- ?: what each of the 45 packs is; the class numbers 0 to 7 being treated as single-group packs is unexplained.
