## Purpose

Stores a freshly built payload into one resume group: it frees the group's previous buffer, allocates the new size, copies the bytes and marks the group ready.

## Behavior

- V: it frees the old buffer at group `+0x270` with the engine's allocator, then allocates the new size from the same allocator and copies the payload in.
- V: it writes the new length to `+0x278` and sets the ready byte at `+0x281`, which is what the flush later tests.
- V: the allocator is the one held on the file object (`qword_140C696D0 + 0x10`); allocating from a different heap would corrupt the next free.
- V: two call sites: the producer that captures a snapshot and the per-name map insert.
- I: the ready byte is cleared by the flush after the payload is queued, so a group is written at most once per capture.
- ?: whether a zero length is allowed (the copy would then be a no-op with a valid buffer).
