## Purpose

The unit-targeting confirm handler: it stores the chosen value in the command request and starts battle program 3 for a found unit node.

## Behavior

- V: like its sibling it writes the same 16-bit value to request +2 and +8.
- V: it additionally resolves a battle unit node for the target with Battle_FindUnitNodeAt before the script starts.
- V: battle program 3 is started with BattleAction_StartScript(3, slot, 0).
- I: the unit-node lookup is why this is the second dispatch path: C4 lists it beside sub_14020327C and sub_140202F34 as one of the three program-3 starters.
- ?: which commands take this path and how the node is chosen.
