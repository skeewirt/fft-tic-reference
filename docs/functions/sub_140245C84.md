# sub_140245C84

- **Address:** `0x140245C84`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `? void sub_140245C84(int mode)`
- **Callers:** Boot clear, classic list, the clear-and-reload state machine
- **Callees:** memset, sub_14033EAA4

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Clears every stored slot to the empty-slot pattern.

## Behavior

- V: it fills the 2,008,200-byte slot cache at 0x142C8B970 with 0xFF, the empty-slot pattern (the value is produced by an OR with -1 before the memset, not an immediate).
- V: it requests a flush afterwards, so the cleared cache is written out rather than only held in memory.
- V: the boot clear calls it with argument 1 before the auto-slot header is imported.
- I: the argument selects an extra clear of the auto slot, because boot needs both and the list rebuild needs only the cache.
- ?: what the second helper does and whether it clears the auto slot or the slot table.
