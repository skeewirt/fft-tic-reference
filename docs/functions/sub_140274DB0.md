## Purpose

Builds ten 5-byte status masks (one bit per status 0..39) from the flag bytes of the status property table.

## Behavior

- V: clears 0x80 bytes at xmmword_1411A7680 and the mask block at xmmword_1411A6A70 (50 bytes).
- V: walks the 40 entries of the status property table (the address 0x140788FE5, entry 0 byte 5, is loaded at 0x140274DCA; step 16).
- V: byte 4 bits 0, 1, 2 and 7 set status bit k in masks 0, 1, 2 and 3 (mask m at +5*m); byte 5 bit 7 and bits 0..4 set masks 4..9.
- V: then writes three constants (word +0x32 = 0x8560, byte +0x34 = 14, byte +0x36 = 32).
- I: the masks group statuses by property (for example which statuses are removed at battle end); the meaning of each bit is ?.
