## Purpose

Scales the working attack by a percentage tied to the equipped item category and stores the result as a 1/100 fraction.

## Behavior

- V: It reads the item id at 0x1407B077A, resolves it with Item_GetRecord and takes the category byte at record+5.
- V: The command byte at +0x3E and the level byte at +0x2B are read from the context at 0x14186AF78 (the body also reads +0x3F, +0x40 and +0x2D there).
- V: It writes the command value to 0x1407B0770 and command*level/100 to 0x1407B0772, using the divide-by-100 reciprocal multiply.
- V: A zero result is raised to 1 before it is stored.
- V: Six call sites in four functions, all physical formulas: NormalAttack three times, WotL distance-scaled, Dancer, and sub_140306EF0.
- V (from the disassembly): this is the weapon-stat setup of the formula blocks (proposed name Formula_WeaponPA). Its output is the pair A (g_FormulaBlock +0) and B (+2), not a fraction: type 0 (bare hands) gives A = the caster's PA (+0x3E) and B = max(1, PA * Brave (+0x2B) / 100); every other weapon type gives B = the weapon power byte 0x1407B07AC and an A that depends on the type (PA, (PA + Speed) / 2, PA * Brave / 100, a random share of PA, or other mixes).
- V: the older bullets above call the two inputs 'command value' and 'level byte'; they are PA and Brave.
- V (disassembly, 2026-11-18): it loads caster +0x3E (PA) into r9, +0x3F (MA) into r11 and +0x2B (Brave) into ebx; by the item record's category byte (+5): 0 (bare hands) A = PA and B = max(1, PA x Brave / 100); every other category B = the weapon power byte 0x1407B07AC and A = PA for 3, 7, 11, 15 (swords, rods, crossbows, spears); (PA + Speed (+0x40)) / 2 for 1, 2, 12, 32 (knives, ninja blades, bows, thrown stars); max(1, PA x Brave / 100) for 4, 5 (knight swords, katanas); MA for 8, 16 (staves, poles); 1 + a random value below PA (Battle_Rand15) for 6, 9, 17 (axes, flails, bags); (PA + MA) / 2 for 13, 14, 18 (harps, books, cloths); max(1, PA x (100 - Faith (+0x2D)) / 100) for 35; A is left as it was for any other category (guns, 10, use formula 3).
