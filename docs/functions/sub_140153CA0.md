## Purpose

Binds one item or ability to a UI cell: it sets the cell's icon path and name from a 16-bit text id, reads the inventory count for an item, and records the cell state.

## Behavior

- V: the fifth argument is the 16-bit text id; the kind is `a5 & 0xF800` and the value is `a5 & 0x7FF` (`0x140153EF5`).
- V: kind 0x3800 is the item case: it formats the small item icon path with `ItemIcon_FormatSmallPath`, resolves the name with `ItemTable_GetName(a5 & 0x7FF)`, and for a value below 0x105 writes the inventory count from `g_InventoryCounts` (`0x14015415B`).
- V: kind 0x7000 is the ability case: it formats the ability icon path, resolves the row with `AbilityTable_GetRow`, and reads the ability's auxiliary record for the level text.
- V: the two-kind split is why the same 11-bit value serves an item id and an ability id; the field is a text-id value, not an item word.
- V: the kind is stored in the cell node at +0xF8; a dirty byte at +0x13C is set; the cell state dword at +0x60 is set to one of four constants (0x67, 0x68, 0x69, 0x6A).
- V: the function returns no value and has one direct caller.
- I: this is the renderer that consumes the 16-bit cell words the item and ability lists build.
- ?: the producer of the fifth argument; the meaning of the two cell-state constants.
