## Purpose

Builds the flag word (dword_142FCE878) of tile events that apply to a unit that has just stopped, for sub_14020435C to work through.

## Behavior

- V: bit 1 is set when Battle_IsTileOccupied(unit +79, +80, +81 >> 7, 65) is not negative: flag 65 (0x41) matches only units whose +0x61 bit 0x40 (status Crystal) or +0x62 bit 0x01 (status Chest) is set (the byte tests are inside Battle_IsTileOccupied, not in this body), so bit 1 means a crystal or a chest is on the unit's tile. No team or job test is made.
- V: bit 0x400 (set by a bit-or the compiled code does not show as an immediate) is added when a pending status set on the unit is non-empty (Status_FilterPendingSets), after resolving it.
- V: bit 4 is added when the tile record (sub_140271D80) has its bit 0 set and the unit has +158 bit 0 (or is a Chemist-type job while g_ShopModeGate is set); else bit 8 when the tile record has its bit 1.
- V: bit 0x10 is added when sub_140271C50 is true. The remaining bits (2 and 0x20..0x200) come from the unit's +156 / +157 flag bytes.
- I: bit 4 is the map item and bit 8 the trap, from the branch each takes in sub_14020435C.
