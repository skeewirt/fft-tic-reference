# sub_1400C43D8

- **Address:** `0x1400C43D8`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `void sub_1400C43D8(SaveDataManager *manager, void **out, int part)`
- **Callers:** the Continue header import (one site)
- **Callees:** none found (leaf)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Returns the payload buffer and length of one part of the current resume point, so the Continue path can read the header without a copy.

## Behavior

- V: the out pointer is read from one of four fixed manager offsets (0x3D5190 for the default part, one per part for 2, 3 and 4), and the qword returned comes from the field 8 bytes before the chosen offset (0x3D5188 for the default); the parts are 0x288 apart but each offset is a separate immediate, not a stride multiply.
- V: it returns pointers into the manager's own storage; it does not copy and the caller must not free them.
- V: it is called once, by the Continue header import.
- V: it is not present in the exception directory, so tooling that enumerates functions from that table does not see it.
- I: because the returned buffer is the group's live buffer, a later capture into the same group would invalidate what the caller just read.
- ?: what the caller does when the part has never been captured (a null buffer).
