## Purpose

Builds the 0x8800 text message for an errand or battle result record: it switches on the record kind, composes the text and posts it to the UI.

- V: the function has no direct caller; the result screen reaches it through a stored task or callback.
- I: this is a result-screen text builder rather than a generic message, because the record carries kind and counters and the fragments are unit result strings.
