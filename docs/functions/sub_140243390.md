## Purpose

Sets a text node from either a text id or a string and records the current-message descriptor. It is the callback that actually renders a panel's 0x3800 or 0x6800 text id.

## Behavior

- V: a fourth argument below 2 means the first argument is a text id; the function calls sub_140226208 with it and uses the returned string.
- V: otherwise the third argument is used directly as a string pointer.
- V: the function fills the current-message descriptor at 0x140783210 from the record it is given (a word at +0 and a dword at +8).
- V: it also expands a second inline form, the 0xF0-high form with a low nibble below 4, consuming three bytes and filling the two dword fields at [rbp-0x21]/[rbp-0x25] before the terminator test.
- V: it parses the string for tag bytes in the 0xD0 to 0xDF range and dispatches each through sub_1402439DC (the upper end is the `and 0xF0` / `cmp 0xD0` test, not a separate 0xDF immediate).
- V: it takes the first path (text id) through the same decoder that the event and battle text use, so a panel id and an event id share one resolution.
- I: the tag loop is the panel's own inline-markup handler, separate from the text-node control codes.
- ?: the full tag set and whether the callback runs per command or per frame.
