## Purpose

Builds a resume entry name from a part index and a point index: `resume_enNN_<part>.sav`, `resume_enwm_main.sav` or `resume_enbtl_<part>.sav`.

## Behavior

- V: point 2 to 4 produce `resume_en%02d_%s.sav` with the part name appended.
- V: point 0 produces the single world-map name `resume_enwm_main.sav`, which has no index.
- V: point 1 produces `resume_enbtl_%s.sav`, the battle-copy name with no index either.
- V: the part names come from a four-entry table (main, world, attack, fturn) based at `0x140671E70`.
- V: the output buffer is the caller's; the longest name fits well inside the container's 32-byte name field.
- I: the asymmetric numbering is what makes the autosave set look irregular in a file listing: three point patterns and one fixed pair.
