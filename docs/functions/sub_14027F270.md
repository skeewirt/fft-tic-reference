## Purpose

Computes the reachable-tile highlight for a unit, extending the base movement/jump by the best Jump-command abilities in its skillset.

## Behavior

- V: gets the unit's ability list via sub_14030E368 (v39 = ids) and for every id with `(id - 394) <= 11` reads kind3: byte 0 (byte_140789260[2*(id-394)]) and byte 1 doubled (byte_140789261[...]); each is kept as a maximum over the list (initial 8 / 16 when the unit byte +0x...E3 == 93, else 1 / 2).
- V: the range check at 0x14027F3A9 subtracts 0x18A from the id and skips results above 0x0B (unsigned); the byte reads follow at 0x14027F3B1.
- V: the maxima feed sub_14027EBF8 and a 256-entry tile pass that sets or clears flag 0x40 on tile records at 0x140D8DCB0 + 8*i + 5; returns the number of marked tiles.
