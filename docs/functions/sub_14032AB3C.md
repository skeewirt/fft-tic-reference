# sub_14032AB3C

- **Address:** `0x14032AB3C`
- **Area:** [Graphics](../areas/graphics.md)
- **Prototype:** `int sub_14032AB3C(unsigned saveIndex, void *rec, __int64 unused, int *outColour)`
- **Callers:** sub_14032ACE0
- **Callees:** PortraitCode_FillCell

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Finds the portrait code of a save unit record (by its marker byte, job byte and job row) and fills a portrait draw record with it; returns the code's low byte, or -1 when the code carries bit 8 or 9.

## Behavior

- V: saveIndex below 0x36 selects g_UnitSaveData + 600 * index; a larger index leaves the record pointer null and the function reads its marker byte through it (a fault: no caller passes one).
- V: the look index: a marker below 0x80 is the index itself; 0x80 (man) gives 2 * job - 52 and 0x81 (woman) 2 * job - 51 (Mime, job 93, two less); 0x82 takes byte +46 of the job row of the job byte; 0xA2 / 0xA3 take the byte at record +2 as job with index 0; job 91 gives index 130 and job 92 index 131 on the 0x82 path.
- V: an index below 0xD3 reads the code word of its own copy of the portrait codes (word_140683A70); otherwise the code stays 0.
- V: marker 0x82 ORs job row byte +47 << 10 into the code (the colour bits); a zero marker gives code 0; markers 0x80 / 0x81 with job 160 give code 104 (105 for odd markers), jobs 161 and 164 give 106 + (marker & 1); 0xA2 gives 108 and 0xA3 109.
- V: a code with bit 8 or 9 set is refused (returns -1, nothing filled); otherwise PortraitCode_FillCell(rec, code, null, outColour) runs and its byte is returned.

Rewritten 2026-11-08: the earlier sheet called this a text id builder for a script message; the code builds a portrait, not text.
