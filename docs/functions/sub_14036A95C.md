## Purpose

Returns how many copies of the selected shop row's item the party has equipped.

## Behavior

- V: It reads the same global shop list index as the total helper and returns zero for a zero index.
- V: It masks the list entry to ten bits and asks the equipped-by-party helper.
- V: The count is sign-extended before returning.
- V: It calls one helper and has no direct caller.
- I: The pair with the total helper gives the shop both numbers it shows for an item.
- V: the id is masked at 0x14036A983; the entry's flag bits are discarded.
