## Purpose

The save-confirmation handler: it writes the chosen slot from live state, then updates the screen and plays the confirmation cue.

## Behavior

- V: it calls the slot writer with the selected slot and the situation value the screen holds.
- V: the writer packs the slot from live state, stamps the situation byte and, for a battle save, also queues the battle resume entry.
- V: after the write it refreshes the screen through the UI helpers and plays a cue through the UI sound routine.
- V: it is a menu callback, so it has no direct caller in the code; the screen's button table holds its address.
- V: it runs on the game thread inside the frame update, like the other save menu callbacks.
- I: because the writer only touches the in-memory cache, the file is written later by the flush, not by this handler.
- ?: which situation value the screen passes (0 for a world save, 1 for a battle save) and where it is set.
