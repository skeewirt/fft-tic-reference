- **Address:** `0x14021A030`
- **Area:** [Save data](../areas/save-data.md)

- **Callers:** The classic card layer (mode selected by 0x1407D453C)
- **Callees:** sub_14021C620, sub_14021BD04, sub_140245B7C, sub_14021849C, sub_14021AEC0, SaveWork_UnpackToLive, EventTask_Start

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The classic save/load menu: it lists the slots, maps slot 0 to the auto slot, and runs the save or load step.

## Behavior

- V: it builds the slot list with sub_14021BD04 and starts the save step sub_14021AEC0 or the load menu sub_14021C620.
- V: slot 0 of the list is the auto slot, reached through sub_140245B7C; the other slots are the cache shifted by one.
- V: it imports the auto-slot header with sub_14021849C and unpacks the chosen work copy with SaveWork_UnpackToLive.
- V: it starts an event task for the transition and shares the same cache and fftsave.bin as the enhanced path.
- I: this is the classic-mode card UI, not a second save format: it reuses the same container and slot records.
- ?: which card-layer virtual call enters the addon and how the two modes are switched at the title.
