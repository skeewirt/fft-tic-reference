## Purpose

The second item command list builder: it assembles the list of items a unit may use in battle and labels each entry with its count.

## Behavior

- V: It keeps a seven-entry byte list of item ids per unit, terminated by 255, and initialises six further byte slots at fixed offsets to 255.
- V: Each list entry is read as a byte id and copied into the wider entry array the panel consumes.
- V: The count for an entry is read from the inventory array using the same id, so the panel can show how many are left.
- V: It calls ten helpers and has one direct caller.
- I: The byte list is the tightest item-id store in this area: nothing above 255 can appear in it, whatever the inventory holds.
