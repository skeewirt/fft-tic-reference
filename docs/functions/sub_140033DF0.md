## Purpose

The generic entry dispatcher: takes one inflated container entry, copies its 16-byte header into the file object, and hands the payload, size and version to the object's own handler.

## Behavior

- V: it copies the 16-byte entry header into the file object and then dispatches the payload, the payload size, the version word and a "checked" flag to the handler selected by the object's vtable.
- V: the handler is the file object's own (its vtable's first slot); the header's version word is passed to it as an argument, not used to choose it, so the object that asked for the entry decides which routine runs.
- V: it is called once per entry record from the per-record dispatch loop, so a container with several entries runs it several times in one load.
- V: the name of the entry is copied aside before the dispatch, so the handler does not need to see the container layout.
- I: this is the seam where a second named entry would be delivered; the loader only dispatches names that were requested, so an entry nobody asked for never reaches here.
