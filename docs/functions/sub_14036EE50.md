## Purpose

Builds the new-arrival notice's item lists: it collects up to 128 item ids into two parallel 16-bit arrays.

## Behavior

- V: the loop walks candidate ids and calls sub_14036F53C to test whether an id belongs in the notice.
- V: for an accepted id it takes the current text id, subtracts 0x3800 to recover the item id, and stores that id as a 16-bit word at 0xD498F0.
- V: it stores a second 16-bit value (zero) at 0xD497D0 in the same iteration.
- V: the loop stops at 0x100 entries, so each array holds at most 128 ids.
- V: the display row data comes from the keyed UI table lookup at sub_1403DBC74.
- I: the second array is a per-entry state or order value, because it is written in lockstep with the id array.
- ?: where the candidate ids come from and what the second array means.
