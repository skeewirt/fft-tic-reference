# sub_1402F2500

- **Address:** `0x1402F2500`
- **Area:** [Event system](../areas/event-system.md)
- **Prototype:** `int64_t sub_1402F2500(int soundId)`
- **Callers:** EventCmd_SetSlotRecord, EventCmd_ServiceRequests
- **Callees:** sub_1402B1ED0, sub_1402B1E74, sub_1402B1D58

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Records the music sound id a command script asked for: frees the old slot, binds the id to a slot and stores the id with the slot in the 16-bit word of the command state.

## Behavior

- V: when the low byte of the word at 0x14186246A is nonzero it resets the music state (sub_1402B1ED0); when the high byte (a signed slot number) is nonzero it releases that slot (sub_1402B1E74), otherwise the slot is 2.
- V: binds the id to the slot with sub_1402B1D58, stores `id | slot << 8` in the word at 0x14186246A and the full id in the dword at 0x140D4955C + 4 x slot, and the slot in the dword at 0x140D49568.
- V: an id above 255 would overwrite the slot byte; the slot byte is only ever 2 in this word (the only writer of a nonzero high byte).
- V: callers are the class 32 command (byte 9 of its record) and EventCmd_ServiceRequests (event variable 94, a 32-bit value).

## Notes

Returns the slot. The word is part of the 56-byte command context that the save keeps in five copies.
