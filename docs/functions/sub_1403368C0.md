## Purpose

Builds the equipment screen's candidate list for the current slot: it asks the list builder for the items of the slot's
group, filters them through the saved equipment order, publishes the result to the UI and fills the rows.

## Behavior

- V: reads the current equip slot through a UI-state helper and gives up when the slot index is five or more.
- V: maps the slot to a list group: the two hand slots share group zero, and slots two, three and four map to groups one,
  two and three.
- V: calls the candidate list builder with the shared display list as output and a count mode computed from a comparison
  between the current slot's table value and the current unit state.
- V: selects the equipment order list of the group and filters the display list through it.
- V: publishes the list and its count to the UI through a helper, then fills one row per entry.
- V: for one slot it also calls the shop-entry price helper.
- I: the slot-to-group mapping is what makes both hands show the same ordered list.
- ?: what the last argument passed to the row filler (the kind byte) does.
