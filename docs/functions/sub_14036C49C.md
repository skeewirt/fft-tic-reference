## Purpose

Opens the shop's sell screen: it builds the tab-zero list from the party inventory, fills the entries in sell mode and binds the list for the sell panel.

## Behavior

- V: a one-shot byte at 0x14184A665 (the sell screen's own flag) guards the first-time setup, so re-entry keeps the existing rows.
- V: it calls sub_1402C40BC with minus one in both arguments, then clears the order-group byte at 0x140D408E7.
- V: it calls sub_14036C3EC with tab 0 and the flag clear, which makes that helper take the inventory branch and fill the shared list buffer at 0x141811470 from the party's own items.
- V: it then calls ShopList_BuildEntries with the returned count, mode 1, and the last two flags 0 and 1.
- V: sub_140327854 and sub_14036B53C bind the list and the row handlers, and sub_14036C70C runs after the binding.
- V: it finishes by calling sub_1402C40BC with 0xF802, which restores the screen's background task.
- I: this is the sell screen because it asks the tab helper for the inventory branch and uses entry mode 1, the mode that makes ShopEntry_Fill compute a sell price and the worn count.
- ?: what sub_14036C70C does after the rows are bound.
- V: the list is built through sub_14036C3EC(0, 0) at 0x14036C4F0 and ordered at 0x14036C500; the row callbacks installed at 0x14036C55F onward include the bit-14 readers.
