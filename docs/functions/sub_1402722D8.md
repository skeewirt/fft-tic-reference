## Purpose

Applies the outcome of a crystal or chest pickup to the picking unit's record: a chest item goes to the inventory, a crystal restores HP and MP, or the rolled abilities are learned.

## Behavior

- V: it resets the unit's action result block (record +446) and then acts on the bits of `flags`.
- V: bit 4 (chest): Inventory_ReturnItem(unit, word_1411A6B0C), the item id the roll chose (result block +92).
- V: bit 2 (crystal restore): the result block's HP and MP deltas are max minus current (record +0x32 - +0x30, +0x36 - +0x34), the result block's type bytes (+0 = 1, +2 = 0, +39 = 0x50) are set and a UI sound cue (id 0xE9) is started.
- V: bit 1 (crystal learn): for 19 jobs x 3 bytes it ORs the roll's learned-slot bytes (the result block at +24, 0x1411A6AC8) into the unit's learned bits at record +162 (the job's three bytes at +162 + 3 x index), then sends an AbilityLearningBySuccession notification with the unit slot (record +444) and the byte at +2.
- V: it returns 0, or the Inventory_ReturnItem result for a chest.
- V: the loop bound is 19 and nothing else is written: no JP, no level, and nothing outside the unit's record, so a stock job's learned bits live only in the battle record until a later write-back.
- ?: where the battle record's learned bits are copied to the save at the end of a battle.
