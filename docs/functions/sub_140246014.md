## Purpose

Moves the 0x9CE4-byte slot record between the work copy and the checkpoint copy: a non-zero second argument copies the checkpoint back into the work copy; zero builds the work copy from the party and stores it in the checkpoint copy.

## Behavior

- V: second argument non-zero: one memmove of 0x9CE4 bytes from g_SaveCheckpointCopy (0x142E80450) to g_SaveWorkCurrent (0x142C81C80); nothing else is touched (Src is not set on this path).
- V: second argument zero: points Src at g_SaveWorkCurrent, fills it with the byte -1 (all bits set), calls UnitWork_BuildForSlot(0) and SaveWork_PackFromParty(0), then moves the 0x9CE4 bytes into g_SaveCheckpointCopy; it does not copy the live unit records (compare sub_1402CEEE8, which does so afterwards).
