## Purpose

Opens the shop's buy screen: it builds the shop's item list from the current shop number, fills the row entries in buy mode and binds the list to its gadget and callbacks.

## Behavior

- V: a one-shot byte at 0x14184A641 guards the setup so the list is built only on the first entry to the screen; later calls reuse the existing list.
- V: it calls sub_1402C40BC with minus one in both arguments, which sets up the screen's background task.
- V: it reads the shop number from the 16-bit global at 0x141811684 and calls Shop_BuildItemList with a unit of 0xFFFF (the all-ones word produced by ORing esi with -1), category 5, the list buffer at 0x141811470, mode 0 and the sort flag clear.
- V: it then calls ShopList_BuildEntries with the returned count, mode 0 and the last two flags 0 and 1, and clears the order-group byte at 0x140D408E7.
- V: sub_1402C0554 and sub_140327854 bind the list and the row callback table; the function fills the callback table at 0x141876AD0 through 0x141876B00 with the row handlers.
- V: the selected-row word at 0x141876B50 is set from the list gadget after binding.
- V: the function has no direct callers in the image, which is consistent with a virtual method installed in a screen table.
- I: this is the buy screen rather than the equip or sell screen, because it passes mode 0 to the entry filler and uses the sentinel unit value.
- I: the one-shot flag exists so that re-entering the screen keeps the scroll position and the existing rows.
- V: the shop list is built at 0x14036AA4D with mode 0 (no equip check, so no bit 14) and then ordered at 0x14036AA5C; the row callbacks installed after that are the ones that test bit 14.
