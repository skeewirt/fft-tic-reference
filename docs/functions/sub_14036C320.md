## Purpose

Recomputes the two-handed word from the five candidate words and renders the equip detail record.

## Behavior

- V: It calls `sub_140284998` with `g_EquipCandidates` and the unit's flag byte +0x16E (0x14036C320 body) and
  stores the result at 0x141876C50.

  `sub_1400ED124`.
- V: It reads the candidates only through `sub_140284998`, which masks each with 0x3FF.
- I: This is the detail refresh that follows an equip change; it never writes a flag.
