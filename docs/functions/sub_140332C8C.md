## Purpose

The equipped-count twin of the shop row helper: it returns how many copies of the row's item the party has equipped, with the same flag bit.

## Behavior

- V: It masks the list entry to ten bits for the item id and asks the equipped-by-party count.
- V: It tests bit 14 of the entry with a 0x4000 mask and sets a high bit on the result when the flag is present.
- V: It calls one helper and has no direct caller.
- I: The two helpers differ only in which count they ask for, so the shop row can show both totals.
- V: the id is masked at 0x140332CA8, bit 14 is selected by the 0x4000 constant at 0x140332CB0 and the AND at 0x140332CB5, and bit 30 is set at 0x140332CBA.
