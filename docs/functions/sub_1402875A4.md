## Purpose

The alternate candidate filler: it builds the five equip candidates from the equipment inventory list (mode 3,
no bit-14 marks), sorts each category's stack list and copies the chosen ids into the output.

## Behavior

- V: It reads the selected unit's two hand words and flag byte +0x16E, decides which hand is the primary from
  the item category, and calls `Inventory_BuildEquipList` with mode 3 (0x14028775E) for each of the five
  category bytes.
- V: Mode 3 of the builder never sets bit 14; this path therefore produces plain ids, unlike the shop builder
  with mode 1.
- V: It merges the category lists through the same stack sorter and `sub_14028B180` comparator; when two hands
  hold the same category it prefers the one with the higher menu field.
- V: At the end it may swap the first two output words (a two-word swap
  at 0x140287D64/0x140287D68/0x140287D6B) when the primary hand is one-handed and the pair fails its weapon
  check.
- V: It does not set bit 15 anywhere; the output is a plain candidate list, and the caller (`sub_140333FE0`)
  passes it to `sub_140287354` for the stat block.
- I: This is the equip screen's own picker, while `sub_140287D9C` is the Outfitter/shop picker; the two use the
  same output shape but different mark conventions.
