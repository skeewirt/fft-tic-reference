## Purpose

Reads the second direction pair (actions 35 = -1 and 36 = +1, masks 0x8000 and 0x2000): reports a step and whether it may wrap.

## Behavior

- V: if sub_1400FC29C() (an analog stick held in both opposite directions, see that sheet) returns 1 the result is 0 (no step).
- V: if sub_1400FC6D8(keys, 0x8000, 35) then *delta = -1; else if sub_1400FC6D8(keys, 0x2000, 36) then *delta = +1; else returns 0.
- V: on a step: repeat < 0 -> *wrapOut = 1; else *wrapOut = sub_1400FC598(repeat, mask, action) (is the repeat flavour of that key held: pressed => wrap allowed); returns 1.
