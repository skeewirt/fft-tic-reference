## Purpose

Fills the errand report window: the title line and the report text chosen by the grade of the result.

## Behavior

- V: copies the entry's three 104-byte unit blocks into the window, and takes the Profit row (UI table 0xB6) of the entry's errand id (entry +312); its +4 string (title) is pushed as the first format argument.
- V: the text is chosen by the grade (*grade): 0 (succeeded) the row's +0x0C (success_report); 2 (failed) +0x10 (failure_report); 1 (partial) +0x1C (partial_report_2) when the second unit block's slot dword (entry +200) is above 0 and that string is not empty, else +0x18 (partial_report); any other value takes +0x0C.
- V: fills the reward panel with ItemObtainedPanel_Fill and shows up to three amounts from the grade record (+24..+32).
