## Purpose

Sorts the shared display list by one chosen field, or rebuilds it in obtain order. It is the sort the sort menu and the
shop list use, as distinct from the eight-preset sorter.

## Behavior

- V: the first argument is the field selector; the third is an id used as a tie-break input by the comparator.
- V: field selector 8 is special: the list is first filtered through the obtain-order list, then the given id is inserted at
  the front when it is positive. This is the "obtained order" view.
- V: every other selector runs an insertion sort with the comparator over three fields: the equality of the tie-break id,
  the chosen field, and the id itself.
- V: an id the validity check rejects is compacted out before the sort, as in the preset sorter.
- V: the scan that finds the insertion point stops after 145 entries, the same cap the list builder uses.
- V: the list must be 0xFFFF-terminated; this function does not use the 255/261 rule.
- V: it returns the resulting count.
- I: because the third argument is the id the player acted on, the sort keeps that id at the front after the chosen field
  has been applied.
- ?: none.
- V: compaction shifts whole words at 0x140286273, the insert writes the row word unmasked at 0x140286339, and the sort swaps whole words at 0x1402863AA and 0x1402863AE; the row compare masks the list side with 0x3FF (constant at 0x14028625A, mask at 0x14028625F).
