## Purpose

Marks the items sold in any open shop.

## Behavior

- V: walks item ids 0..; an item whose record +10 is not above event variable 111 is checked against every shop (sub_1401DF5B4 says which shops are open) with the same mask test.
- V: the mask is two bytes per item at 0x14067F890 + 2 * id (high byte first).
