- **Address:** `0x140245B7C`

- **Callers:** The classic save/load menu sub_14021A030 and the classic list

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Maps classic list slot 0 to the auto slot record and moves the 0x9CE4 bytes between them.

## Behavior

- V: the move is 0x9CE4 bytes, the size of one slot record, between g_SaveAutoSlot at 0x142E75DF8 and the cache.
- V: the classic list is the cache shifted by one, so list slot 0 is the auto slot and list slot n is cache slot n-1.
- V: it touches the slot table base at 0x140D405B4 and the cache at 0x142C8B970.
- I: the direction (copy in or copy out) is chosen by the caller's argument, since the same move serves save and load.
- ?: which argument value selects each direction and how the auto slot is validated.
