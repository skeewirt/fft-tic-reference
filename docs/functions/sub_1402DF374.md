## Purpose

Builds and runs an event message scene: it resolves the message text, places the speaking units and their sprites, and waits frame by frame until the message ends.

## Behavior

- V: the message id selects a byte in the table at 0x14067E00C, and that byte indexes 0x708-byte records at 0x143789DE0 (`imul 0x708` at 0x1402DF761 and 0x1402DFD81).
- V: the text is resolved through EventText_FindMessage and sub_140109134, the two text entry points.
- V: unit sprites and markers are set up through the 0x1400E5xxx render helpers and memcpy of the scene blocks (the 0x1400E5xxx range covers 0x1400E51E4..0x1400E562C).
- V: the function waits with EventTask_WaitFrame and ends with EventTask_Terminate, so it is a task body, not a one-shot builder.
- V: the 34 callers are the event message opcode variants, which pass different message ids and scene modes.
- V: the record stride of 0x708 and the byte-to-index table are the J8 table-census entry for this function.
- I: this is the common event dialogue builder, because every caller is an event message path and the text comes from the shared message table.
- ?: the four different callers and what each mode changes; the mode argument was not decoded.
