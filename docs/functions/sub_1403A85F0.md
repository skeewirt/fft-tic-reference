## Purpose

Vector-deleting destructor for 272-byte objects: destroys one object, or an array whose element count is stored at a1 - 8, and optionally frees the memory.

## Behavior

- V: flags bit 1 set (array form): count = *(a1 - 8); loops from the last element down, calling sub_1400321C0(elem) on each (element stride 272 = 0x110 bytes); then if flags bit 0 is set frees the block at (a1 - 8) with size 272 * count + 8 via sub_14041FB00; returns a1 - 8.
- V: flags bit 1 clear (single form): sub_1400321C0(a1); if flags bit 0 is set frees a1 with size 272; returns a1.
- V: this is the MSVC scalar / vector deleting destructor pattern (the count-in-front array cookie). Its only references are data (tables at 0x1406FB110 and 0x143D40120), not direct calls.
- I: sub_1400321C0 is the 272-byte type's destructor; the type is not identified here.
