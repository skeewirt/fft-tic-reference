## Purpose

Applies the 'unavailable / dimmed' palette to a cell's chara sprite (palette bit group 6) when the cell is the cursor cell with state 0 or sub_140132D48 says so, and marks the cell tinted.

## Behavior

- V: mode p+19008 == 0 or 7 or 8 returns. g = sub_140132D48(p). If cursor p+19016 > 0x12 or cell != cursor: needs g or returns. For the cursor cell: g is forced to 1 when the cell state dword [148 * cell + p + 8964] == 0.
- V: rec = p + 148 * cell + 8924. When g: SpriteRecord_SetPaletteBits(rec, 0, 6). Always sets bit 2 of the dword at rec + 12. When request != 0: CharaRender_SetSlotRequest(g_CharaRenderMgr, rec).
