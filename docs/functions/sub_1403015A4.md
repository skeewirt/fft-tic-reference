## Purpose

Builds an event or message record from a text id, choosing a different id range depending on the text id's kind.

## Behavior

- V: The text id value decides which range check applies: the default path uses 0x100, a text id equal to 0x7800 selects 0x300, and one equal to 0x6800 selects 0x105.
- V: The 0x6800 branch is the item-name token: it takes the low part of the token as an item id and validates it against the item range.
- V: An out-of-range token falls through to the generic message path instead of being treated as an item.
- V: The record it produces carries the message id, the kind and up to four argument words.
- V: It calls eleven helpers and has no direct caller.
- I: The three different ranges show that the token kind and the item range were tuned separately, which is why widening items would also move this bound.
