## Purpose

Builds the ability list of a job-screen ability page for the selected party unit: the rows of the unit's own job plus the jobs 75..92, optionally sorted by a name-row order key.

## Behavior

- V: it calls JobScreen_BuildJobTabRows for the unit's job id and then for job ids 75..92 (the loop runs 18 times, id = index + 74 for index 1..18); the ids of other jobs are never tried.
- V: for modes 2, 4 and 6 (the test (mode - 2) & ~6 == 0 with mode 8 excluded) a job from the loop is built only when JobList_BuildForPartyUnit lists it for the unit; other modes build all 18. (Corrected 2026-11-11: this line first said modes 2, 3 and 9.)
- V: every row's ability word (the word at row +2) is tested with sub_140289F4C(job word at party +36, word & 0x3FF), a ten-bit ability id.
- V: when the sort flag is set, a bubble sort orders the rows by the sort_order column of the Ability row (table 39, int32 at row +0x34); 999999 when the row is missing or the value is 0; ties by ability id.
- V: the rows are 8 bytes; the finished list copies one row per distinct run of the ability word at +2 and ends with a row whose +2 word is 0xFFFF; the function returns the count.
