## Purpose

The battle state machine: one step per frame from command input through action resolution to the next turn.

## Behavior

- V: it switches on the battle state word at 0x140C6B1CC; state 3 calls the confirm dispatcher sub_140203620.
- V: it calls the three confirm dispatchers sub_14020327C, sub_140203450 and sub_140202F34, each of which starts battle program 3.
- V: it calls the command handlers sub_14020A7F0, sub_14020AD64, sub_14020BCF0 and sub_14020C704 by state.
- V: it both produces and consumes the deferred battle message queue (the calls at the two sites).
- V: it tests the action's ability word against the no-ability sentinel by masking with 0xFDFF, so 0 and 512 count as no ability.
- V: it calls Battle_Init, BattleAct_Step, BattleAction_Kickoff, the apply step and the resume materialiser sub_140257354.
- I: the command menu, the resolution and the presentation are states of this one machine rather than separate loops.
