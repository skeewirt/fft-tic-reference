## Purpose

Returns the party's total holding of the item in the currently selected shop list row.

## Behavior

- V: It reads a global shop list index, and if that index is zero it returns zero without touching the list.
- V: It reads the list entry at the index, masks it to ten bits and asks the item total helper.
- V: The result is sign-extended to 64 bits before returning, so it is a signed count.
- V: It calls one helper and has no direct caller.
- I: The zero-index guard means the first list slot is used as a valid row only when a real index has been set elsewhere.
- V: the id is masked at 0x14036A94B; the entry's flag bits are discarded.
