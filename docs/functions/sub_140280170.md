## Purpose

Builds the weapon part of a battle action: which item is in the acting unit's hands, what damage it does, and which animation it uses.

## Behavior

- V: It reads the acting unit's hand words and passes each one to the weapon accessor only when it is not 255 and is below 261.
- V: The accepted weapon id is stored in the action record's weapon field.
- V: The weapon record then supplies the attack value and the animation selector used by the rest of the action build.
- V: It calls eight helpers and has a single direct caller.
- I: This is the point where an equipped weapon becomes the action's weapon, so an item the weapon accessor cannot see becomes an unarmed attack.
