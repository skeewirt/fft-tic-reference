## Purpose

Returns one of the two save-root strings held on the manager, selected by index: the primary root or the fallback root without the Steam id.

## Behavior

- V: it is a nine-way switch: index 1 returns the string at +0x430 and index 3 the string at +0x530; the other seven indices return further manager fields, and any other index a fixed string.
- V: sub_1400366B0 passes index 1 or 3 (it doubles its boolean and adds 1); the switch cases sit past the first ret, at 0x14006BA60..0x14006BA9D, so a scan that stops at that ret sees only the default case.
- V: the three callers are the exists, the open and the legacy numbered-file probes, all of which format a path against the returned root.
- V: it does not build or copy anything, so the caller shares the manager's buffer and must not write into it.
- I: the second root exists so that a save written before the account id was known can still be found.
- ?: whether the second root is populated at startup or only when the Steam id is unavailable.
