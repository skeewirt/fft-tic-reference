Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

One step of the event command task: it starts the task, runs one queued command per step, and tears the task down when the script ends.

## Behavior

- V: mode 0 sets bit 13 of the context's flag dword and returns, which is the task's "claimed, not started" state.
- V: mode 1 calls the command runner; when it reports that nothing ran, the context's service routine is called instead.
- V: mode 1 then clears bit 9 and, if bit 2 was set, clears it, resets a 0x38-byte record's words and dwords to -1 and 0, and calls the context reset with value 7.
- V: mode 2 clears bit 13, which returns the task to the idle state.
- V: any other mode does nothing.
- I: the bit pairs are the task's started and finished flags; the 0x38-byte record is the command register the handlers read.
- ?: what the service routine does when no command is ready (wait, poll input, or pump a message).
