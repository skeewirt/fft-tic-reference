## Purpose

The Brave roll that decides whether a reaction fires; on success it stores the reaction id and the amount the reaction acts on in the action block.

## Behavior

- V: runs only when the action block's flag byte +39 has bit 7 set (the result may be reacted to).
- V: in a simulation (g_BattleSimulating non-zero) it passes without a roll; otherwise it rolls Rng_Percent(100, unit byte +0x2B) on the unit at g_BattleActingUnit and passes on the roll's failure value as the code is written (the helper's polarity was not read; I: the Brave percent roll).
- V: on a pass it copies the block's word +6 (the HP result) to word +40 and stores the reaction id at word +16.
