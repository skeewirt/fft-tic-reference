# sub_140260CF0

- **Address:** `0x140260CF0`
- **Area:** [Unit rendering](../areas/unit-rendering.md)
- **Prototype:** `? sub_140260CF0(int slot)`
- **Callers:** The unit sprite renderer's slot update
- **Callees:** sinf, cosf, sub_1402708F4, sub_140270A04

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Updates one unit render slot's transform: rotation, scale and placement from the unit's facing.

## Behavior

- V: it uses sinf and cosf, so the slot's rotation is computed rather than looked up.
- V: it reads the unit sprite renderer global at 0x143CC96B8 and its per-slot state.
- V: it reads the high-definition sprite entry by shape, one of the four readers the live census hit.
- V: it compares a record byte with 0xAA, the marker T1 records in this function.
- I: a per-frame slot transform update for the unit currently drawn (the facing angle comes from the battle unit).
- ?: which renderer pass calls it and whether it also updates the shadow or the ground marker.
