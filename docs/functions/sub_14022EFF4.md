## Purpose

Refreshes a battle help panel from the currently selected 16-bit word. A word tagged as an ability or as an item is reduced to a plain id and stored for the help panel, which then looks the name up by its own source.

## Behavior

- V: the selected word is read from a global pointer table indexed by a signed index taken from a record field.
- V: the kind is the word masked with 0xF800.
- V: when the kind is 0x7000 (ability) the function subtracts 0x7000 and stores the id as a 16-bit word.
- V: otherwise it subtracts 0x3800 and stores the resulting item id as a 16-bit word.
- V: a second source path reads a byte from a table, adds 0x3800 to it and keeps the sum as a 16-bit word.
- V: the panel state is recorded in a global byte before the command dispatcher is called.
- I: the panel is the battle help bar for the action or item list, and the two word stores feed its name and description lines.
- ?: the two source tables and which panel object owns the record.
