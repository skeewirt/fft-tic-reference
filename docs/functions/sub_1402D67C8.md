## Purpose

The equip screen's message handler for the leave messages 0, 6 and 7: it closes the screen, refreshes the job
screen when the unit changed, and zeroes the session price accumulator.

## Behavior

- V: Message 6 calls `sub_1402C4880(6)`; message 0 posts message 63490 and closes.
- V: Message 7, when the selected unit differs from `word_141811420`, calls `JobScreen_RefreshAfterChange` and
  then copies the selected unit record into a stack record with `sub_1402C33D0`.
- V: At the end of the message-7 branch it sets `dword_143D1AC68 = 0`, so the session price is dropped.
- V: It does not call `sub_1402D65D4` or `sub_1402D5B6C`; the strip/cancel is in the other handler.
- I: Message 7 is "leave the equip screen", and the price accumulator belongs to the Outfitter's equip session, so it
  is cleared here when the equip screen closes.
