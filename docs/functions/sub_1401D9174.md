## Purpose

Starts a background music transition: looks the transition up in the BGMTransition table and binds the music id of the sound entry it names to slot 1.

## Behavior

- V: looks up the BGMTransition row (nxd table 306, key = the argument) and its SoundEnhancedId (row dword +8).
- V: when that SoundEnhanced row (nxd table 280) exists, binds the dword at row +16 as a music sound id to slot 1 (sub_1402B1D58(id, 1)) and stores the dword at +12 of the transition row (a float in the data) at the new entry; the id is a full 32-bit value (no byte, no word).
- V: before that, when a byte of the sound object (at +32) is set and no track is current (id -1), it activates a slot with MusicSlot_FetchRecord.
