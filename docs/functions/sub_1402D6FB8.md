## Purpose

Builds the five (id, price) preview pairs for the equip panel from the live unit words and the override array,
then posts the preview record.

## Behavior

- V: It clears a 5-pair (8 bytes each) stack array, then walks five slots of the selected unit
  (`g_PartyUnits[g_SelectedUnitIndex]`) against the override array at 0x14184A680.
- V: The word is loaded zero-extended and its bit 15 is extracted with a shift right by 15 (0x1402D704C); a set bit
  yields the masked id (0x1402D7056), a clear bit yields -1 (0x1402D7060).
- V: It also compares the raw unit word with the signed override word (a signed read of the override word at 0x1402D7060): when
  they differ, the pair is zeroed (0x1402D706F); this is how a slot whose value equals the override is marked
  unchanged.
- V: For a set bit 15 it prices the masked id with `Item_GetRecord(..., +8)` (0x1402D7087-0x1402D7094).
- V: It calls `sub_140284998` with the five candidate words and the unit's flag byte +0x16E (0x1402D70BE)
  and stores the two-handed result as a byte in the posted record.
- I: The preview distinguishes "pending purchase" (bit 15) from "unchanged" (equal to the override); a plain
  changed word is shown without a price.
- V: the id of a flagged slot is the hand word AND 0x3FF (mask loaded at 0x1402D7027), which strips the session flag; a mask that keeps bit 15 makes the id 32,768 plus the id and `Item_GetRecord` then reads a record 32,768 rows past the item block (behavior OutfitterPreviewReadsRecordPastItemBlockWithSessionFlag).

## Notes

V: builds five (id, price) pairs for the preview. Bit 15 is taken with shr 0xF (0x1402D704C); the override is compared as a signed word, so a bit-14 override reads as negative.
