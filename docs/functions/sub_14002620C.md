## Purpose

A bounded string copy: it moves a source string into a caller buffer, stopping at either the destination capacity or an explicit source limit, and terminates the result.

## Behavior

- V: the argument order as used is destination, destination capacity, source, source limit; the UI passes `(buffer, 256, path, 255)`, so the copy is capped one byte below the 256-byte buffer.
- V: it is the single copy primitive behind the texture and part path builders, the save container's entry-name handling and dozens of UI addon methods (160 direct call sites counted in the code).
- V: the bounded form is used everywhere a path or a name is assembled into a fixed buffer: the 0x104-byte item picture buffers, the 0x100-byte UI path buffers and the 264-byte block copied into a UI part (the 0x100 and 0x104 are caller buffer sizes, not operands here).
- I: it stops at the source limit or at the terminator, whichever comes first, and always writes a terminator, so a truncated result is still a valid string.
- ?: whether a source exactly at the limit is truncated silently or reported to the caller was not read; no caller tests a return value.
