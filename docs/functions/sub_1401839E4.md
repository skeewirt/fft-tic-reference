## Purpose

Agent state 5 of the save/load screen: the load handler. Phase 0 starts the fade and loads the chosen slot, phase 1 waits for the fade and the save I/O, and phase 2 performs the scene resume.

## Behavior

- V: phase 0 clears UI focus with `GUICore_FocusNode(0)`, resets the scene state, loads music track 8 in mode 2, requests fade state 9, and requests the saving-overlay show when the overlay's byte at `+0x44` (68) is clear.
- V: phase 0 reads the selected slot at `+228` and the checkpoint/auto flag at `+244`. With `+244` set it requests the slot's parts through `sub_1400C4214(g_SaveManager, slot, 1)`; with it clear it calls `SaveSlot_LoadToLive(g_SaveManager, slot)`. It then detaches the list add-on at `+1576` and clears that pointer.
- V: phase 1 advances only when the fade timer at `g_UIStateFade + 16` is 0 or below and `sub_1400C3790()` returns 0. I: that helper (not shown in this body) reports a pending save request through the save request manager's dword at `+392`, or the dirty word at `qword_140D405B8 + 260`. It then requests the overlay hide through byte `+0x46` (70) when `+0x44` (68) is set, or sets state 0.
- V: phase 2 with `+244` set calls `Save_ResumeCheckpoint(agent)`. With `+244` clear it reads the situation byte at `+282` of the 40,164-byte slot record in `g_SaveSlotCache` (record `40164 * index`) and, when that byte is 1, calls `sub_140257354(40164 * index)`.
- V: phase 2 then sets `g_GlobalWork + 102` to 1, `dword_142E80228` to 1 and `g_GlobalWork + 104` to 1, calls `sub_140182E7C`, frees the System agent's add-ons through `UIAgentFFTOSystem_FreeAddons`, and calls `sub_140151B34`.
- I: `+244` selects the checkpoint/auto resume path over a manual slot load, resting on event 1 storing the source entry's auto badge there and on the two phase-2 branches.
- ?: what `dword_142E80228` and the two `g_GlobalWork` bytes gate; what `sub_140151B34` does.

## Notes

Whole function read (402 bytes). Earlier versions of this reference treated `+282` as an agent field; the byte is read in phase 2 from the slot-cache record (`g_SaveSlotCache + 40164 * index + 282`), not from the agent. The `sub_1400C4214` request is the `+244` checkpoint branch in phase 0. Phase 0 does the live load, phase 1 only polls the fade and the save I/O, and phase 2 does the scene resume. The pointer at `+1576` is the list add-on; the object at `+1584` is the saving overlay.
