## Purpose

One of the battle unit panel builders: it fills the panel rows for a unit's equipment from the unit's item slots.

## Behavior

- V: It walks the unit's equipment slots and masks each id to nine bits before the item record lookup.
- V: A slot word equal to 255 is treated as empty and draws no row.
- V: The record's category byte decides which icon and which sub-record the row uses.
- V: It calls seven helpers, including the record and weapon accessors, and has one direct caller.
- I: The nine-bit mask is the panel convention shared with the other four panel builders; the record accessor itself accepts a full 16-bit id.
