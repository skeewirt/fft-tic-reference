## Purpose

Validates whether a unit can equip an id in a slot and whether the other hand's weapon conflicts with it;
returns 1 for a legal pick, 0 for a legal-but-not-needed pick, and a negative value for a refusal.

## Behavior

- V: It rejects a non-existent unit through `Party_GetSlotState` and otherwise masks the id with 0x3FF
  (`a3 & 0x3FF` in the export) before `Item_CanUnitEquip`.
- V: A zero id returns 1. A non-zero id goes through the equip check with the unit's job/level data
  (+36 and +115).
- V: For a hand slot it inspects the other hand's word, masks it with 0x3FF, and applies the two-handed /
  dual-wield rules through `Item_GetWeaponRecord` bytes +1 (bits 1, 4 and 8).
- V: It never reads or writes bit 15 of the incoming word: the mask removes it before any item lookup.
- I: The function is the gate that keeps a flagged word from reaching `Item_CanUnitEquip`; the flag is removed
  by the mask, not by a test.
