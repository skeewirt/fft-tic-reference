# sub_140220E10

- **Address:** `0x140220E10`
- **Area:** [Data access](../areas/data.md)
- **Prototype:** `int sub_140220E10(unsigned selector, unsigned id)`
- **Callers:** The scene text formatter (sub_140243390 and its argument walk)
- **Callees:** none

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Builds a tagged 16-bit text id from a format byte and a bare id.

## Behavior

- V: format byte 0xE9 adds 0x3800 to the id (item text), 0xEA adds 0x7000 (ability text) and 0xEB returns the id bare (0xE9/0xEA/0xEB are successive `sub` steps from 0xE0; the addends are in the tail blocks at 0x140220E38..0x140220E54, past the first `ret`, because this leaf has no .pdata extent).
- V: 0xE0 returns the constant 0x4000, 0xE1 adds 0x4000 and 0xE5 adds 0x9000 (0xE1 and 0xE5 come from the same subtraction chain; 0x4000 and 0x9000 are added to the id in those tail blocks).
- V: any other format byte returns -1, and the formatter stops its argument walk on that value.
- V: the function is a 74-byte leaf that calls nothing and touches no global.
- I: it is the per-argument half of the tagged text-id scheme: the formatter holds bare ids and this gives each one its kind bits.
