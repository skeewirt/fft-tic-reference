# sub_14039684C

- **Address:** `0x14039684C`
- **Area:** [Items and shops](../areas/items.md)
- **Prototype:** `__int64 __fastcall sub_14039684C(int group)`
- **Callers:** the routine at 0x14033DE68 (five calls, groups 0 to 4; its symbol label is unrelated)
- **Callees:** Item_MenuCategory, sub_140286070, sub_140286160

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

A second synchroniser for the saved item order lists. It applies the same owned/not-owned rule as `ItemOrder_SyncGroup`, but takes membership from `g_InventorySnapshot` instead of the live count, and reaches the lists through the alias table `off_140689C38`.

## Behavior

- V: takes a group index from 0 to 4 and selects `off_140689C38[group]`, a pointer table to the five saved order lists.
- V: the loop index runs 1 to 260 (`0x14039694D`); the entry word is compared with 0xFF and with 0x105, where the upper constant is the form 0xFF+6 built by the lea at `0x14039687E` from the 0xFF sentinel.
- V: membership is the byte `g_InventorySnapshot[id]` (`0x1403968B8`); a zero byte means not owned, and the `& 0x3FF` on the index is redundant because the loop index is below 261.
- V: `Item_MenuCategory(id)` selects the group: category zero maps to group zero, otherwise category - 1.
- V: an owned id that is absent is inserted at index zero and the tail is shifted right; an id that is not owned is removed by shifting the rest left.
- V: the list end is the word 0xFF or any word at or above 0x105; the insertion path stops at 146 entries.
- V: afterwards it calls `sub_140286070(group)` for the equipment order list and tail-jumps `sub_140286160` for the obtain-order list.
- I: this is the path used when the live inventory is not the authority, for example after a battle or a snapshot rebuild.
- ?: which game moment the calling routine belongs to; its symbol name is wrong and its own callers were not traced.

## State touched

- Calls: [sub_140286070](sub_140286070.md), [sub_140286160](sub_140286160.md), [Item_IsValidId](Item_IsValidId.md)

## Notes

- V: whole body read. The order-list pointer table is the alias table.
- V: the stock order lists terminate at the word 0x00FF, not 0xFFFF.
