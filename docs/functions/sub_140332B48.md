## Purpose

Returns the string pool that belongs to a text kind; the kind selects a pool, which is prepared and then returned by pointer.

## Behavior

- V: The argument is reduced through a chain of subtractions, giving kinds 0..8 plus a default case.
- V: Each case calls sub_1402BACCC with a fixed pool index (9, 12, 16, 22 and others) and then loads a global pointer.
- V: One case returns a fixed address (0x1408F4EC0-relative) instead of a prepared pool.
- V: The text-id decoder calls it with 2 for group 14, which makes the ability-name pool the source for that group.
- V: Twelve callers, including EventText_FindMessage, sub_140226208 and the two scene tasks.
