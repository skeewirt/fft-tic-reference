## Purpose

Advances the calendar held in event variables 0x67 (year), 0x2E (month) and 0x2F (day) by a number of days and updates the 64 date-keyed bytes and records beside it.

## Behavior

- V: It divides the day count in ecx by 365 (`imul` by 0xB38CF9B1, `sar 8`) and adds the quotient to event variable 0x67, the year.
- V: It converts the current month and day (event variables 0x2E and 0x2F) to a day-of-year with the 12 month lengths at 0x140680FF8 (the last 12 bytes of the 0x140680F00 table), adds the remaining days and carries a full year into 0x67.
- V: It walks the same 12 month lengths to split the result back into month and day, which it writes to event variables 0x2E and 0x2F.
- V: For the 64 slots it adds the year delta to the bytes at 0x1411A7220 and clamps them to 0x63; slot 0 takes its month bounds from event variables 0x5F and 0x60, the others from the byte pairs at 0x1407B8130.
- V: It walks the 64 records of 9-byte stride at 0x1411A71A2, tests the flag byte at -2 against bits 2 and 4, advances the byte at +0 and calls sub_140340FD0 with the word at +2 when the flags allow it.
- V: It updates the 64 bytes at 0x1411A7140 with a 0x3F mask derived from the elapsed day count.
- V: It does not read the instruction-length table or return an instruction address; the earlier text-cursor reading was wrong.
- I: One caller, sub_14033EEDC.
