## Purpose

Builds a unit's usable ability list for skillset a2 (ids plus cost, value, flag and availability arrays); sibling of sub_14030E368.

## Behavior

- V: loops 16 skillset slots with Skillset_GetAbility(a2, slot); ids 1..0x16F take data from AbilityAction_GetRecord (byte 12 & 0x7F cost, byte 13 value halved when unit flag +153 is negative, byte 5 bits).
- V: ids 406..413 take the kind4 byte 0 as cost: the byte is read from byte_140789280 at offset id*2 - 0x32C (0x32C = 2*406), after a range check that subtracts 0x196 from the id and skips results above 7 (unsigned), at 0x14030DF77.
- V: the cost is halved or zeroed by unit status flags in byte +155 (bits 8 / 4) unless record byte 5 & 4; availability comes from sub_14030E2F0(unit, cost, ctx, 0).
- V: writes ids to a3 (0xFFFF terminated), cost to a5 and parallel arrays a4, a7, a8; returns the count.
- V (live 2026-11-10): at 0x14030DEA9 it reads the ability's action record (AbilityAction_GetRecord, then byte +6); an id with no action record (a Charge ability) faulted the scene task at 0x14030DEC4 and the game froze (behaviour AFaultInAGameTaskFreezesTheGame).
