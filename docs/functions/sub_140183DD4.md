Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Deletes one manual save slot: it fills the slot's 40,164-byte work copy with the empty pattern, copies it into the cache and marks the cache dirty.

## Behavior

- V: the work copy is filled with `0xFF` over exactly 0x9CE4 bytes before the copy, so no field of the old slot survives (the fill value is produced by an OR with -1 before the memset call, not an immediate).
- V: the filled copy is moved into the cache slot at `40164 * slot`, which is the only write the file later sees.
- V: it marks the cache dirty so the flush rewrites the whole container; there is no per-slot file to delete.
- V: it never touches the resume entries of the autosave container, so a stale battle entry can outlive its slot.
- V: it then refreshes the slot list and plays a cue.
- I: the `0xFF` fill is what makes a deleted slot fail the slot-validity test, so it disappears from the list rather than showing as empty.
- ?: whether the deletion is confirmed first; the confirmation UI is above this callback.
