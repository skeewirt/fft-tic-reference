## Purpose

Fills battle snapshot block B from game-data table rows and repairs the live save arrays from it; it is the only writer of that block.

## Behavior

- V: It starts by reading scene variable 100 and, when that is 0, variable 61, comparing the second with 8 and 195 to choose a 0x200-byte size.
- V: exactly one indexed 16-bit store into block B occurs in this function, at 0x1402FBB15; the rest of the block is written through the surrounding stores.
- V: Table data arrives through NxdRegistry_Find and the NXD accessors (by keys, by row id, entry count, leaf count), so the block is a copy of table rows rather than a computed value.
- V: It calls SaveWork_UnpackToLive_Repair once, which rebuilds the live item and flag arrays from the save image.
- V: Three callers, all in the event unit-block path: EventUnitBlock_RunTask, sub_14020E578 and sub_1402357C4.
