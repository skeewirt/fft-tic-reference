## Purpose

Opens one area container for reading: it checks the parent-folder candidate exists, then prefers the Steam-id subfolder copy and falls back to the parent folder when only that one exists.

## Behavior

- V: it formats the %s%s.png path against the root at +0x430 and against the root at +0x530 (both are inline manager offsets here, not selector calls); it checks the +0x530 candidate first, then prefers +0x430 and falls back to +0x530 when only that one exists.
- I: the existence probe asks for the same two roots one at a time, so "exists" and "open" agree about where a file is.
- V: a 0x100-byte buffer holds each formatted candidate path.
- V: the file is opened read-only; the routine returns a handle or a failure for the caller to interpret.
- I: the two-root order is what makes a save written under one Steam account still findable after the account id changes.
- ?: which error paths fall through to the second root and which return at once.
