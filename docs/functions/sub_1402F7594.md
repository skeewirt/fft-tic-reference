## Purpose

Builds one 16-colour palette block for a sprite slot and records that the slot is ready, so later calls for the same slot return at once.

## Behavior

- V: The slot index is multiplied by 0x992 and used as a record offset from 0x140C6B320; byte +9 of the record is the ready flag.
- V: A set ready flag returns before any palette work is done.
- V: With mode 1 it clears 16 bytes at record+0xA in a nine-byte stride, one byte per entry.
- V: It then walks 16 entries with a 0x20-byte output stride, calling sub_1402F74D8 for each (output, slot, entry index).
- V: On exit it writes 1 to the dword at the table base 0x140C6B320.
- V: Fifteen callers, among them ItemSprite_LoadPalettes, SceneUnit_BuildPalette and SceneUnit_RunPlacement.
