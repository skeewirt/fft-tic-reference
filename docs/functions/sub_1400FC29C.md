## Purpose

Detects an 'opposite directions held at once' state on the pad / keyboard direction set: returns true when two opposite inputs of any axis are down together, which makes direction stepping ignore input.

## Behavior

- V: reads the analog stick bytes at qword_140C69680 + 2608 / + 2609 (signed); a magnitude above 0x32 (50) counts as pressed in the sign's direction (v0..v3 booleans).
- V: v7 = the input source byte; when it is 2 (an input source that reports no digital keys) the digital tests are skipped, otherwise sub_1400F0D4C(qword_143CD9EE8 + 8, action) is tested for actions 0xA4 / 0xA5, 0xA6 / 0xA7, 0x21 / 0x22, 0x23 / 0x24, 0x2A / 0x29.
- V: for each opposite pair (A4+A5, A6+A7, 21+22, 23+24, 2A+29) the function returns true when both members are down (digital or analog).
- V: otherwise false.

## Notes

Prevents stepping when e.g. Left and Right are both held; the five pairs are actions 33/34, 35/36, 41/42 and the stick action 164..167.
