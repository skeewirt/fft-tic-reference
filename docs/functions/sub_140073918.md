## Purpose

Creates a directory: the engine's mkdir, used for the save folder, the pack cache and the log folder.

## Behavior

- V: it takes one path and creates it, returning a status; it does not create intermediate directories on its own.
- V: eleven call sites, all of them folder setup: the save folder builder, the boot mount machine, the container writer and several asset caches.
- V: it is called before the first save is written, so a player who never saves still gets the save folder.
- V: the recursive case is handled by the callers, which build the path one segment at a time or know the parent exists.
- I: the status is ignored at most sites, because a folder that already exists is not an error.
- ?: whether an existing directory returns success or a distinct "already there" code.
