## Purpose

Refreshes a battle-side panel object from a packed text id or from the panel's own selection fields. It fills the icon, the name and the help text of the panel's cells, choosing the source by the text kind.

## Behavior

- V: the function takes the panel object in the first argument and reads two of its fields (+0xE5A4 and +0x102AC), clearing the second.
- V: it looks up named gadget parts of the panel by string and checks the part kind before using them.
- V: a text kind of 0x3800 selects the item path: an Item-en row through the inlined accessor and a large icon path through ItemIcon_FormatLargePath.
- V: a text kind of 0x7000 selects the ability path through AbilityTable_GetRow.
- V: a text kind of 0xB000 takes a third branch that does not use the Item-en or ability tables.
- V: window byte +66256 is a random-icon flag, cleared first: an ability action (kind 0x7000) copies the Ability row byte +0x42 (column random_icon); a weapon attack (kind 0xB000) sets it when either of the two hand item ids kept at window +66252 has the Item row byte +0x2D (column random_icon).
- V: when the flag is set, after the damage number is drawn the node at window +248 (IconRandom) plays 'Show' and 'Hide' is stopped.
- V: the action word shown is at window +58780 (kind in bits 0xF800).
- V: text is set through the text-node setter and the argument push helper; the function has no return value.
- I: it is a panel refresh driven by the currently selected id, not a per-row list builder.
- ?: which screen owns the panel and what the two source fields hold.
