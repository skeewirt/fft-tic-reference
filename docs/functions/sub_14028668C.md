Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Builds the job list of a unit given as a work record (C), not a party index: it points the bit reader at the work record's unlock mask and calls JobList_Build in mode 1, so the result holds only the jobs the unit has unlocked.

## Behavior

- V: sets the job-list flag byte to 1 and the bit reader to C + 159 (the unlock mask of the work record) before the call.
- V: builds JobList_Build's four info bytes from the record: the job word is the byte at C+3 widened to 16 bits, then C+0, C+6 and a flag (byte C+0x12 + 0x50 <= 0x2F).
- V: the list goes to the caller's buffer and JobList_Build's count is returned; g_RuntimeJobList is not written.
- V: JobList_Build is called directly from here (JobList_BuildForPartyUnit is a separate entry).
