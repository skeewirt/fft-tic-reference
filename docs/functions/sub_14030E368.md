## Purpose

Builds the list of ability ids (with cost and availability arrays) a unit has for command/skillset a2; the shared worker of the per-command list functions.

## Behavior

- V: a2 selects the skillset: 5..0x17 map by index (a2 - 5), 0xE0 via Job_IdToIndex(160), else it must equal the unit's byte +18 or +402; the available-slot mask comes from the unit's bytes +162..+164 (3 per job index).
- V: loops 16 slots (`v20 < 16`) with Skillset_GetAbility(a2, slot); ids 1..0x16F take cost data from AbilityAction_GetRecord like sub_14030DD8C.
- V: ids 406..413: the byte read from byte_140789280 at offset id*2 - 0x32C, after a range check that subtracts 0x196 from the id and skips results above 7 (unsigned), yields the kind4 byte 0 as cost, at 0x14030E5D9.
- V: outputs a3 ids (0xFFFF terminated), a5 cost bytes and side arrays a4, a7, a8; returns the count.
- V (2026-11-10; corrects the first bullet): the learned-slot mask for the skillset a2 is chosen so: a skillset 5..0x17 uses job index a2 - 5; 0xE0 uses Job_IdToIndex(160); a skillset equal to the unit's byte +18 or +402 (primary or secondary) uses index 0; for any other skillset, and for any monster unit (byte +6 mask 0x20), and when the index found is -1, the mask is set to all 24 bits, so every slot counts as learned (it is not the Squire bits).
- V: its Charge test is at 0x14030E5D3.
- V (live 2026-11-10): the learned-bit group is chosen at the join 0x14030E55A; for a skillset id above 226 that is the unit's primary or secondary skillset the game's group 0 applies (an Archer's Squire bits were seen).
