# sub_14026A508

- **Address:** `0x14026A508`
- **Area:** [Battle](../areas/battle.md)
- **Prototype:** `int sub_14026A508(unsigned short effectWord)`
- **Callers:** The action presentation step
- **Callees:** Effect_AbilityHasNoEffect

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Decides whether an action's effect word means no ability, treating both 0 and 512 as empty.

## Behavior

- V: it masks the effect word with 0xFDFF, which clears bit 9 and so maps 512 onto 0 (the 16-bit mask appears as the 32-bit test value 0xFFFFFDFF).
- V: the masked word is passed to Effect_AbilityHasNoEffect, which classifies the special no-effect ids.
- V: the body is 55 bytes and touches no global.
- I: a predicate used before the presentation step: an action whose word is 0 or 512 has nothing to show.
- ?: the return convention: whether a true result means 'no effect' or 'has effect'.
