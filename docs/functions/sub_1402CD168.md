## Purpose

Posts a parameterised UI message from a kind and a value, after checking both against the small pair table the message system accepts.

## Behavior

- V: the first argument points at the kind dword and the second at the value dword.
- V: the kind must be 1 through 12 and the value 1 through 30; anything outside returns without posting.
- V: the pair is looked up in the byte table at 0x140681010, which maps a kind to its accepted value range.
- V: the kind is converted through a table walk and the value is compared with the selected range.
- V: sub_1401D80A8 receives the resolved pair as a UI message.
- V: the routine is used by the save header, the errand results and several scene screens, so it is the common message poster.
- I: the 12 by 30 pair space is a message-kind registry rather than free text, because the value is range-checked per kind.
- ?: what each kind means; the table entries were not named.
