## Purpose

Services the 16-entry audio command queue: takes the oldest entry and carries out its kind (play music, release a slot, fades and waits).

## Behavior

- V: the queue is two arrays of 16 dwords at 0x140D494D0 (kind) and 0x140D49510 (parameter), with the entry count in the dword at 0x140D49558; sub_14033FDAC pushes an entry (and runs this function while the queue is full).
- V: kind 1 decodes its parameter as slot = (p >> 8) & 0xF and sound id = low byte, compares the id with the dword at 0x140D4955C + 4 x slot, and either re-activates the slot (MusicSlot_FetchRecord) or releases the old binding, binds the incoming id (sub_1402B1D58) and stores the id.
- V: kind 2 and kind 3 load a fade parameter block (sub_1402B1FB4) around the slot activation, kind 4 releases a slot, kind 16 waits until loading has finished, kinds 17 and 18 count a fade down and clear or set bit 0 of the flag dword.
