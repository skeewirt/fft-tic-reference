- **Address:** `0x140376040`

- **Callers:** the page dispatcher ClassicMenu_RunScreenStack (kind 32)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Page of one entry of the second tavern list (page kind 32): portrait, profile text and a counter of how often the position's date has passed.

## Behavior

- V: the position is `*state >> 4`; the text is bank 17 message (byte) *state, where bank 17 is the loaded data block; the number printed in the text is the counter byte at 0x1411A7220 + position (the only reader of those counters).
- V: writes 255 to event variable 90, builds the page (PagedText_Init), reads the variable back as the portrait code and builds the portrait cell (PortraitCode_FillCell) and the face of the page; 255 means no portrait.
