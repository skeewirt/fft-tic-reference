# sub_1400348F8

- **Address:** `0x1400348F8`

- **Callers:** the application initialiser (one site)
- **Callees:** `sub_1400366B0` (exists), `sub_140036724` (legacy per-slot probe)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The boot "has any save" probe: asks whether the manual, the autosave and the system containers exist and remembers the answers on the manager so the title knows whether to offer a load or a continue.

## Behavior

- V: it sets two flag bytes at manager `+0x258` and `+0x259` from the results of the probes.
- V: it is called once, from the application initialiser, before the title screen exists.
- V: the probes are the container existence test and the legacy numbered-file scan, so the flags also answer "is there an old-style save set".
- I: the two flags are "a save file is present" and "a resume point is present"; the title's Continue entry is what reads them (the read side was not traced in this pass).
- ?: which feature reads each flag individually; only the write side was proven.
