## Purpose

Fills one button-guide entry of a panel: from row (tableKey, rowKey) of UI table 33 sets the IconButton part's label key and the Title text id.

## Behavior

- V: row = UITable_GetRowByKeys(33, tableKey, rowKey); null = return null.
- V: if row dword +4 != 0: v = sub_1400F681C(ctx, row[1], row byte +36, buf); if row dword +8 != 0: v = sub_1400F69BC(ctx, row[2], ..., &key, buf, 0). When v != 0, finds part 'IconButton' (GUINode_FindPartByName(panel+272, ..)) of kind 2 and writes the icon string key at part+232 (sub_1403D87F4).
- V: finds part 'Title' of kind 3 (text node) and sets its text id (dword +248) to row dword +12, setting the dirty byte +316 when it changed. If the part is missing the writes go to null + 248 (as decompiled; a missing Title part would crash, so every button-guide node has one).
