## Purpose

Builds the texture of one pending request record of the battle HD layer: a fixed sheet entry with the record's own palette, or pixels another routine prepared.

## Behavior

- V: the request record is 1128 bytes at 0x143C7C960 + 1128 * index; a record whose first dword is 0 returns 0.
- V: when the record's dword +1104 is not -1 it names an entry through the table dword_140722908, reads that entry (entry 153 from the pack's kept-entry slots when it is there) and expands 512 x 512 4-bit pixels through the 16 texels at record +64 into texture object `index` of the HD layer's table of 112-byte texture objects (dword_142E94390 in the database).
- V: otherwise sub_140418F20 prepares the pixels and the texture is set or updated with the record's width, height and depth.
- V: clears the record's first dword and sets its dword +1120 to 1.
