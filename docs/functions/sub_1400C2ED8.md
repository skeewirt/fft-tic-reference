# sub_1400C2ED8

- **Address:** `0x1400C2ED8`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `int sub_1400C2ED8(GameSaveData *obj, const void *payload, size_t size, int version, int checked)`
- **Callers:** `sub_1400C2E5C` (vtable thunk of the manual-slot object)
- **Callees:** `sub_140033DA4` (CRC), the raw copy helper

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The manual-slot handler: for a version-14 `fftsave.bin` entry it verifies the CRC and the exact payload size, then copies the whole 50-slot image into the save object.

## Behavior

- V: the CRC of the payload is verified through the attach check before anything is copied.
- V: for version 14 the size must be exactly `0x1EA488` (2,008,200 bytes = 50 slots of 40,164); any other size zeroes the buffer and returns an error.
- V: the exact-size rule applies only to the manual slot: the settings entry (version 0) and the resume entries (version 17) are not size-checked here.
- V: on success it copies the payload as one opaque block into the object at `+624`, so all 50 slots become plain bytes in one move.
- V: it is reached only through the object's vtable, from the generic entry dispatcher.
- I: this single rule is why a manual slot can never be widened in place: a larger payload is rejected before any field is read.

## State touched

- Calls: [sub_140033DA4](sub_140033DA4.md)
- Writes: [SaveManager.image](../structs/SaveManager.md#image)

## Notes

- V: the version-and-size gate sits at `0x1400C2F4B`, 115 bytes into this function: it compares the entry version with 14, then the payload size with `0x1EA488`.
- V: on a mismatch it zeroes the object's image and returns an error, so every slot in the file reads as empty rather than partially loaded.
- V: the same gate is skipped for the settings (version 0) and resume (version 17) handlers, which is why those entries accept variable sizes.
- I: accepting a larger manual slot needs this comparison and the writer's size changed, not the container.
- There is no separate function at `0x1400C2F4B`; it is a branch inside this one.
