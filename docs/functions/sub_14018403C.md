## Purpose

The load-screen setup callback: in mode 0 it reads the whole manual-save container, and in mode 1 it advances the screen when there is something to show.

## Behavior

- V: mode 0 calls the manual-slot loader, which fills the image with the empty pattern and requests `fftsave.bin`, then sets the save-I/O command word to 3 (image to cache).
- V: mode 1 asks whether the loader produced anything; when it did not, it sets the screen's state to 2 through the UI state helper.
- V: any other mode does nothing.
- I: the command word of 3 is the state machine's "copy the loaded image into the slot cache" step, which is why the list is empty until it runs.
- ?: what `sub_1400C3790` tests (whether a load is pending or whether the image is valid).
