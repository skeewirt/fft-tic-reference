## Purpose

Builds the classic save menu's slot list, one title card per valid slot.

## Behavior

- V: it clears the list through sub_140245C84 before filling it, then walks the fifty slots.
- V: each slot is tested with CardSlot_IsValid; invalid slots get no title card.
- V: a valid slot gets a classic title card built from its summary fields.
- V: the list is the same slot array the enhanced screen reads; only the card presentation differs.
- I: empty slots are drawn from the invalid result rather than from a separate empty-card record.
- ?: how many cards are built per pass and how the list widget is sized.
