# sub_140221798

- **Address:** `0x140221798`
- **Area:** [Unit rendering](../areas/unit-rendering.md)
- **Prototype:** `? sub_140221798(int slot)`
- **Callers:** Battle unit panel / renderer paths
- **Callees:** sub_14022AA88 (sprite-id to shape)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Resolves the sprite shape of a battle unit from the live unit table.

## Behavior

- V: it reads the live battle unit table at 0x141853CE0, the 21-record table the battle code uses.
- V: the unit's sprite number is converted to a shape with the shared helper.
- V: it reads the scene-shape table, one of the eleven readers the live census hit.
- I: it serves the battle unit panel or the unit's on-field sprite, since it starts from the live table rather than a party record.
- ?: which panel calls it and whether it also returns a palette.
