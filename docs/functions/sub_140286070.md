## Purpose

The equipment-order twin of the item synchroniser: it applies the owned/not-owned rule to the equipment order list of one group. Groups at or above four return immediately, because only four equipment lists exist.

## Behavior

- V: returns immediately when the group argument is 4 or more.
- V: selects one of four equipment list pointers from `off_14067FA90` (8-byte entries).
- V: scans item ids 1 to 260 and keeps only the ids `Item_IsValidId` accepts and `Item_MenuCategory` assigns to the group.
- V: the list walk tests each word against 0xFF and 0x105; the upper constant is the form 0xFF+6 built by the lea at `0x1402860AB`, not a literal.
- V: an owned id that is absent is inserted at index zero with a right shift of the tail; an id that is not owned is removed.
- V: the end conditions are the word 0xFF and any word at or above 0x105.
- V: it writes only the selected list; the sort order is never touched.
- I: it is called from the item syncer and from the snapshot syncer, so both paths keep the equipment order current.
- ?: none.
