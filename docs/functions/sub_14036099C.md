## Purpose

Gives the side category of the unit a unit-info record names: 1 own side, 2 enemy side, 3 'special' ally, 0 none.

## Behavior

- V: returns 0 for a null record or a unit slot (word +10) above 20, and 0 when bit 3 of the unit's byte +494 is set.
- V: side bits (+494 & 0x30) equal to 0x10 return 2; otherwise unit dword +504 bit 0 (the OverrideEntryData special flag) returns 3; otherwise any other non-zero side bits return 2; side bits 0 return 1.
- V: so a unit with the special flag is reported as category 3 even though its side bits are 0 (the guest side), unless its side bits are 0x10.
