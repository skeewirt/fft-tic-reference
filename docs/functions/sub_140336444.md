## Purpose

The equip screen's item click: it applies a list id to a slot, refreshes the stat block and posts the panel
record.

## Behavior

- V: It reads the picked item id from the list table with `word_142E93E42[4*v1] & 0x3FF` (the body masks with
  0x3FF) and, when the slot index is below 5, calls `sub_140288590(0x36, slot, id)` (0x140336444 body).
- V: On a successful apply it calls `sub_140287354` with `g_EquipSet`, the record and the scratch record, then
  copies the scratch hand words back to the unit (the same four + one copy as sub_14036C2A8).
- V: The id is masked before the apply, so no flag is written.
- I: The two branches (slot below 5 vs above) are the equip and the job/ability click; only the first touches
  the equipment words.
