## Purpose

The second battle item panel initialiser, the twin of sub_140323D1C: it sets up the panel for a unit and its current item.

## Behavior

- V: It reads a word at +0x5C of the panel's unit structure and masks it to nine bits for the record lookup.
- V: It compares the record's category with the panel's current category to choose the sub-panel.
- V: It tests a unit-state byte for the panel's disabled flag before drawing.
- V: It calls fifteen helpers and has one direct caller.
- I: The two initialisers differ in which panel object they take, not in how they read the item.
