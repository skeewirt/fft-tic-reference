## Purpose

'Was this action pressed this frame' test for the direction helpers: checks the action's pressed / repeat flags, with an optional key-mask test.

## Behavior

- V: returns 0 when the input source byte is 2. mask == 0: returns 1 when sub_1400F0D00(input+8, action) or sub_1400F0D98(input+8, action) says the action's pressed (+1362 / +1378 stride 16) or repeat flags (+1366 / +1382) are set.
- V: mask != 0: when mode != 0 and (sub_1400F6C8C(action) & mask) != 0 returns 1; else returns 1 when any of the first two press bytes at input + 48 * action + 1386 or 1390 (stride 16) is set.
