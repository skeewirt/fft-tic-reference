Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Finds the look pool index of a battle unit through the scene-unit list and fills the image rectangle the turn panel uses for its small face; returns the pool index or -1.

## Behavior

- V: unit index above 0x14 returns -1; otherwise calls PreviewUnit_ResolveShape and stores palette + 8.
- V: walks the scene-unit list (qword_140D3A410) for the unit whose index byte equals the argument and takes its pool index (byte +9).
- V: for a pool index below 8 the rectangle is page 29 at row 32 * index, for 9 to 15 page 0x101E, else page 30 row 0.
