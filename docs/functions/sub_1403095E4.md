## Purpose

Executes a reaction ability: builds the result record the reaction causes from the reaction id in the word at 0x14186AFF0, or refuses an id it does not handle.

## Behavior

- V: first, an id of 440 loads the unit pointer 0x14186AF78 from the unit table at the index in dword 0x14186AFF4.
- V: the gate table at 0x14067F730 is indexed by id - 422 (32 entries, ids 422..453); an entry whose low two bits are 1 returns 0 at once: the ids 435, 436, 437, 440, 441, 442 and 453.
- V: otherwise both result records are reset and a switch on the id fills the action block: the cases are 422..434 and the single ids 438, 439, 444 and 446; each case writes one or two bytes or words of the block (which ones depends on the id; 422, 423, 424 write +22, +23, +20, 425..428 set status groups and then test Status_FilterPendingSets).
- V: any other id (435..437, 440..443, 445, 447 and above) clears the block's byte +39 and returns -1: the reaction is dropped. The default is at 0x140309795.
- V: a handled id stores its kind flag in the block's byte +39, calls sub_14030A11C and returns 1 (with bit 0x01 of +39 added when the block's word +18 is non-zero).
- V: the only caller is Battle_ResolveAction, which runs it first when the battle-state gate 0x14186AF9C is non-zero; a non-zero answer there ends the resolve (Action_SetWeaponItem, return 0).
