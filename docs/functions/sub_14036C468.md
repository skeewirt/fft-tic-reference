## Purpose

Returns the sell price of the shop row the player has selected, for the sell confirmation panel.

## Behavior

- V: it returns 0 immediately when the word at 0x141874A14 is zero.
- V: otherwise it takes the selected row index from the 16-bit global at 0x141876B54 and reads that row's id from the shared list buffer at 0x141811470.
- V: the id is passed to Item_SellPrice and the result is returned sign-extended in a 32-bit register.
- V: the function reads no other state and writes nothing.
- V: it has no direct callers in the image, which is consistent with a virtual method installed in the sell screen's table.
- I: the zero check at 0x141874A14 is a "sell screen active" gate, because a row price is meaningless when no sell list is open.
- I: the price follows the sell rule (half the record price, at least one), because it delegates entirely to Item_SellPrice.
- V: the price row passes the whole word at 0x14036C485 to the sell-price helper; the helper masks it internally, so the price is right but the flag stays in the argument.
