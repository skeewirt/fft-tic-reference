## Purpose

Second item list screen constructor. It has the same shape as sub_14022AFEC: it initialises the per-screen state record and fills the list cells with icons and tagged text ids.

## Behavior

- V: the per-screen state record is selected from a global screen index with a 0x800-byte stride (the stride is a left shift by 11); a 21 (0x15) marker and a state value are written at the start.
- V: two widget list headers at record offsets 0x4000 and 0x5000 are zeroed; the header at 0x5010 is set to 1.
- V: the function walks a 0xFFFF-terminated word list and posts a text id equal to 0x3800 plus the entry through the menu-side text command sub_1402EC9D0.
- V: row and icon helpers between sub_1402D7724 and sub_1402D844C fill the cells, and the screen state moves through named values before the list is built.
- V: the function has no direct caller, which fits a screen constructor stored in a table.
- I: it is the other member of the pair with sub_14022AFEC, most likely the other of a buy and sell or inventory and equipment pair.
