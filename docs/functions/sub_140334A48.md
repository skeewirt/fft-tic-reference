## Purpose

Refreshes the shop's equip-detail panel: it builds the shop row entries for the selected unit, synchronises the item order group and updates the counts shown beside each row.

## Behavior

- V: the function is large and reserves a stack frame of roughly 8 KB through the compiler's stack probe.
- V: it reads a character render manager pointer and compares two of its counters before doing any list work.
- V: it calls ShopEntry_InitFromList on a row entry, which fills the 40-byte entry from the shared list buffer at 0x141811470.
- V: it calls Item_CountTotal and Inventory_AddCount on row ids, and ItemOrder_SyncGroup once, so the displayed order follows the saved item order group.
- V: it reads the shared list buffer at four sites: three directly for row ids and one as the output buffer of Inventory_BuildEquipList.
- V: sub_14028A138, sub_140288590 and sub_140338060 run during the row update, and memset clears a scratch area first.
- I: the panel is the equip-detail view of the shop rather than the buy list, because it calls Inventory_BuildEquipList and the entry initialiser instead of Shop_BuildItemList.
- ?: the exact set of rows it walks; only the call sites and the three list-buffer reads were traced.
- V: four passes hand the raw word on: the action call at 0x140334BF1, the inventory add at 0x140334D32, the total count at 0x140334D3C and the second action call at 0x140334FFA. The two count callees mask the id themselves; the two action helpers compare the whole word with the party equipment words and so are flag-sensitive.
