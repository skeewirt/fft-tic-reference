Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Runs one coded UI action for a menu screen: it sets a state flag, chooses a case from the code and calls the screen helper for that case.

## Behavior

- V: the function takes three arguments; the first is the action code and the other two are values used by the cases.
- V: it calls sub_14033F7B0 with argument 1 and sets bit 0x3800 in a global state dword. That bit is a flag, not a text id.
- V: it calls sub_1402CD758 with argument 0, then switches on the code minus 0x1B.
- V: the cases are 0x1B, 0x1C, 0x1D, 0x2C, 0x2D and 0x2E (the body subtracts 0x1B then walks 1, 1, 0xE, 1, 1, so only 0x1B appears as an immediate); each calls a different screen helper (page change, list rebuild, close).
- V: the 0x2E case reads a list count, computes a record address with a 0x5C-byte stride and calls the record handler.
- V: the function returns no value.
- I: it belongs to the same menu family as the item list screens, because the callers are the same screen tasks.
- ?: which screen sends the codes and what each code means.
