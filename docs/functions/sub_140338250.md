## Purpose

Builds the item menu's display list for one group and, for the hand groups, filters it through the first saved item order
list. Returns the number of entries.

## Behavior

- V: takes a group value and maps it to the list builder's group numbering by adding five when the value is 0 or 1.
- V: builds the list into the shared display list with a count mode of zero.
- V: for group values 0 and 1 it filters the display list through the first saved item order list, unconditionally.
- V: for other group values it leaves the built order alone.
- V: returns the count reported by the builder (the filtered count is not returned in the filtered case).
- V: the unit id it passes to the builder is read from a word global, not from an argument.
- I: the group mapping mirrors the equipment screen's slot mapping, which is why the same first order list serves both hand
  entries.
- ?: whether returning the unfiltered count for the filtered case is intended.
