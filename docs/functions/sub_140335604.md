## Purpose

Draws a shop row's text: it resolves the row's item id and passes it, with the row's text context, to the draw call.

## Behavior

- V: It reads a 16-bit shop list entry, sign-extends it and masks it to ten bits.
- V: It first asks a UI helper whether the row is visible at all and returns early when the answer is negative.
- V: The masked id is passed to the draw routine together with a text context byte.
- V: It calls three helpers and has two direct callers.
- I: The visibility test before the draw is what keeps the row's id from being resolved for a hidden row.
- V: the id is masked at 0x140335629 before the panel call at 0x14033563C.
