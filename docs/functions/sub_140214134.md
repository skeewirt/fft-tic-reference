# sub_140214134

- **Address:** `0x140214134`

- **Callers:** Unit_GetSpriteSetId (its mode-0 path returns this function's result)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Turns a unit id into a sprite shape and returns the shape's bit class through the out parameter.

## Behavior

- V: Unit_GetSpriteSetId's mode-0 branch returns whatever this function gives, so it is the event/scene sprite path for a plain unit id.
- V: it converts the resolved id with the shared sprite-id to shape helper and calls nothing else.
- V: it reads the scene-shape table, one of the eleven readers the live census found.
- I: the out parameter is the same ((value >> 10) & 3) + 8 bit class that the sibling conversion reports, since both end in the same helper.
- ?: which ids have no shape and what the function returns for them.
