## Purpose

Builds the errand board's list: one 8-byte entry (errand id, sort value) for each errand whose progress variable has bit 2, sorted by the sort value.

## Behavior

- V: for each Profit row id i (the table is nxd 182, cached in qword_143CDA500) it tests event variable 864 + i for bit 2 (0x04); a hit adds an entry whose dword 0 is i and dword 1 is the row's +0x24 (column sort_order).
- V: sorts the entries by the second dword with the library sort sub_1401CCCAC.
