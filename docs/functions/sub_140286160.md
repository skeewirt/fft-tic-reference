## Purpose

Applies the owned/not-owned rule to the obtain-order list, the single list that records the order in which items were first acquired. It takes no argument and always works on that one list.

## Behavior

- V: takes no arguments and reads no group; the target list is `word_141874726`, and the same routine also reads the buffer at `word_141874540 + 243`.
- V: scans item ids 1 to 260 and keeps the ids `Item_IsValidId` accepts (no category test).
- V: the list walk tests each word against 0xFF and 0x105; the upper constant is the form 0xFF+6 built by the lea at `0x140286185`, not a literal.
- V: an owned id that is absent is inserted at index zero; an id that is not owned is removed.
- V: the end conditions are the word 0xFF and any word at or above 0x105.
- V: it has no direct call site; both synchronisers jump to it after their own work.
- I: the obtain order is the "order acquired" sort the menu offers as its special sort mode.
- ?: whether anything else consumes the list besides that sort and the save copies.
