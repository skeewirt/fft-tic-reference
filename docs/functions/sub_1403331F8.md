## Purpose

Changes one equipment slot of the unit shown in the status panel, including the two-hand and shield-slot cases, and refreshes the panel afterwards.

## Behavior

- V: the slot is the first argument, the item id the second, and a flag the third; the unit is the selected unit from the 16-bit global at 0x141811428, read through the party table.
- V: it reads the unit's current word for the slot from the five-word array at record offset 0x54.
- V: slot 1 has a special case: when the unit's word at record offset 0x40 is non-zero and the slot word is zero, the value used is taken from the record offset 0x54 word instead.
- V: when the incoming item id is zero the function follows an unequip path, otherwise it follows the equip path.
- V: both paths end with a call to Inventory_AddCount for the item that leaves or enters the inventory, then sub_140288590 and JobScreen_RefreshAfterChange.
- V: sub_1400ED3E8 and sub_140336664 run on the paths where the slot change has an effect.
- I: the zero-item case is an unequip because the function must return the old piece to the inventory, which matches the Inventory_AddCount call on that branch.
- I: the slot-1 special case is the shield slot, because the code substitutes a second hand word when the shield word is empty.
- ?: the meaning of the third argument; it selects between two paths but its game meaning was not read.
- V: the list entry is compared as a whole 16-bit word at 0x1403332DC and sign-extended at 0x1403332E2 before the id compares; nothing masks the flag bits, so a flagged entry can never equal a plain item id.
