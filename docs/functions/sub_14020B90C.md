## Purpose

Finishes a unit's move and then looks for a tile event where it stopped.

## Behavior

- V: places the unit and its linked unit on the stop tile (sub_14027192C), marks the first scene object as having moved (+339 bit 0) and ends the unit's turn when BTurn_IsUnitDone says so.
- V: then it computes the tile flags with sub_140271AC0, stores them in dword_142FCE878, zeroes dword_142FCE7CC and calls sub_14020435C once; when any flag is set it also calls sub_14021060C.
- I: this is where a unit that has walked onto a crystal starts the learn roll: the flag word is computed once at the stop, not at each step of the walk.
- V: sub_140210AF0 calls it in state 18 when the selected command word (xmmword_142FD35A0) is 7, or is 8 / 255 with bit 0x08 set in a byte of the second scene object.
- ?: what command 7, 8 and 255 are was not decoded.
