## Purpose

Builds and submits an item request for a reaction, temporarily marking the item as not consumed.

## Behavior

- V: It returns at once when the no-consume dword at 0x14186AF80 is set, when sub_140278FA8(4) is non-zero, when the unit's +5 byte bits 0x30 differ from the stored flag, or when the unit id equals the stored actor.
- V: It sets 0x14186AF80 to 2 around the call and restores it afterwards (site 0x14030D379).
- V: It resolves the ability action record and the item, then calls sub_140281488 to turn the request into a unit action block.
- V: It also calls sub_14030D3F0, the item damage and effect entry used by reactions.
- V: One caller, Battle_TurnEngine.
