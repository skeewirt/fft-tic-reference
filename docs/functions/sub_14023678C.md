## Purpose

Fills the item list cells of an inventory or equipment screen. Each cell receives a 16-bit word that packs a kind tag and an item id, plus a page or state id and a count.

## Behavior

- V: the tag is chosen from a mode byte: one mode uses 0x3800 (item) and the other uses 0x7000 (ability).
- V: the tag is OR-ed into each cell word, so the cell word holds the kind in its high five bits and the id in its low eleven.
- V: three cell fields (+0x10C, +0x114, +0x11C) receive a page or state constant (0x94 or 0xA4), and +0x140 and +0x15A receive counts.
- V: the item ids come from byte lists (one byte per entry) that stop on 0xFF; a 0xFFFF word list is also scanned for a count.
- V: the function calls seven item-command list helpers between 0x14030E368 and 0x14030EFE4 to fill the lists beside the cells.
- V: a 2-bit field from bits 12 and 13 of the packed source word is stored to a global before the text id is posted.
- I: the two modes are two tabs or two list types of the same screen.
- ?: the mode semantics and the role of each of the seven helpers.
