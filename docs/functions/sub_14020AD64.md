## Purpose

The auto-battle style command handler: it finishes the unit without a player choice and hands the turn over.

## Behavior

- V: it calls BTurn_FinishUnit, the turn handover, at the end.
- V: after thirty idle frames (a u16 counter above 0x1E) it calls the AI entry sub_14031F130.
- V: the live Wait test left that flag at 0, so this path is not the Wait command (C8).
- I: the idle-frame gate and the AI call make this the auto-battle handler rather than a player row.
- ?: Wait's real command id; C8 records it as open.
