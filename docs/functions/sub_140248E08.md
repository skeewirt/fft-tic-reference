## Purpose

Converts a packed map record into the runtime battle tile table.

## Behavior

- V: it copies 512 source records of 8 bytes into the table at 0x140D8DCB0, merging selected bits of each byte with fixed masks.
- V: the first two source bytes become the map width and height at 0x140C6AD6A and 0x140C6AD6B.
- V: each destination record holds flags and movement cost; the map code reads it with the width and height bounds.
- V: the second half of the table is addressed as a second 256-tile page by the map readers.
- V: the loop runs exactly 512 times, so a larger map cannot be stored in this table.
- I: this is the map load step that turns the level's packed tile data into the in-memory table the battle logic walks on.
