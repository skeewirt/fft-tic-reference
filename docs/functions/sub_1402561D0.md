## Purpose

The top-level per-frame update that keeps the save machinery and the boot/movie transitions moving.

## Behavior

- V: it calls the save frame step sub_1402185A4 and the autosave flush sub_1400C3B84 every frame.
- V: the world-map save sub_1400C480C is called from the same body, so a world-map autosave is also driven here.
- V: it calls Boot_SetState and Movie_Start, so it is part of the application update rather than a scene task.
- V: it reads the fade globals and the save manager object.
- V: the body also loads the world background texture name, so it serves the world-map scene as well as the boot state.
- I: one update function runs the save queue and the outer state transitions together because both must keep going while a scene is paused.
- ?: which state selects each branch and in what order the saves are kicked.
