Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The handler for a scene message word: it resolves the 5-bit class and 11-bit index of the word and dispatches to the text setter of that class.

## Behavior

- V: the index it decodes is the low 11 bits (0x7FF) of the dword at +0xC of the object loaded from the scene-message global; the 5-bit class half is not in this head.
- V: the class selects one of a table of handlers; this routine is the generic entry, and each class lands on a different text or number setter.
- V: the eight callees are the per-class setters: plain text, formatted number, icon-bearing text and the item and ability name variants.
- V: two call sites, both in the scene task code that consumes the message word.
- I: this is how a scene script shows a message without knowing which text table the word refers to.
- ?: the exact class-to-setter mapping; only the range and the callee set were read.
