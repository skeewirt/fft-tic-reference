## Purpose

The world-map screen's update callback, in two modes: build and show the map panel, or trigger the world-map save.

## Behavior

- V: mode 0 builds the panel: it calls the map builder, stores the resulting object at ui `+0x630`, and initialises it with a value of 0x100; if the object's byte at `+0x44` is clear it sets the byte at `+0x45`.
- V: mode 1 calls the world-map save step (`sub_1400C480C`) after checking a global object and its word at `+0x188`.
- V: when the save step reports nothing written and the panel's byte at `+0x44` is set, mode 1 calls the UI state helper with state 2.
- V: any mode above 1 does nothing.
- I: the two modes are the screen's enter/refresh and its save tick; the byte at `+0x44` looks like an "already saved" flag.
- ?: what the panel's bytes `+0x44` and `+0x45` mean, and which event calls this callback with mode 1.
