# sub_140206CE8

- **Address:** `0x140206CE8`
- **Area:** [Battle](../areas/battle.md)
- **Prototype:** `? sub_140206CE8(int slot)`
- **Callers:** The charge release path of a queued action
- **Callees:** BattleAnim_SetChargeMotion (via sub_140269920), sub_140281434, BTurn_MarkMoveDone, BTurn_MarkActionDone, atan2f

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Releases a charged action: it turns the unit toward its target, takes the charge pose and starts the action script.

## Behavior

- V: it reads a row of the three-byte ability animation table at 0x140672DA0.
- V: the charge motion is set through the charge-motion setter the animation code uses.
- V: a direction is computed with atan2f, i.e. the unit is aimed at a point derived from the target.
- V: it calls BattleAction_StartScript and the turn helpers that mark the move and the action done.
- V: the unit action request is rebuilt through the wrapper sub_140281434 before the script starts.
- I: this is the moment a queued (charged) ability is let go, after its charge time has run out.
