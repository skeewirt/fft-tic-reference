## Purpose

Focuses a GUI node (GUICore_FocusNode) with its byte +557 temporarily cleared while any 'character render' slot is active, so the focus switch does not trigger the node's 557 behaviour.

## Behavior

- V: node == 0: returns GUICore_FocusNode(0) (clears focus).
- V: saves b = node+557. Scans the dword array at g_CharaRenderMgr + 13624 (the loop as decompiled is a first-element test: it exits on the first non-zero element, or after the first iteration when the first is zero); when it finds a non-zero dword it sets node+557 = 0. Then GUICore_FocusNode(node) and node+557 = b (restored).
- I: the scan loop is a decompiler artefact of a short loop; the net effect is 'if some chara-render slot flag is set, focus without the 557 flag'.
