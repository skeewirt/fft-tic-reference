## Purpose

Per-frame function of battle state 21 (the crystal / chest / item pickup state): applies the player's choice once it has been made, runs the pickup effects, and calls sub_14020435C again for the next pending flag.

## Behavior

- V: it switches on the choice word xmmword_142FD35A0: 0 and 1 call sub_1402722D8(unit, value) (1 applies the rolled abilities), 2 calls sub_1402722D8(unit, 2) and applies the action result, 4 calls sub_1402722D8(unit, 4), and 7, 8 and 255 only continue.
- V: the unit is the record at +328 of the first scene object (sub_1402607C0).
- V: afterwards it counts a short delay (a u16 at +12 of the second scene object), clears the handled bit of dword_142FCE878 and calls sub_14020435C for the next flag.
- I: the choice word is written by sub_140237FA4 from dword_140D40958 (the crystal window's result) while the message-105 command runs: 1 = learn, 2 = restore, 0 = neither.
