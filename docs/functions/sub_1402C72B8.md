## Purpose

One of the scene-task bodies event opcode 0x78 starts (mode 6): a unit-display scene that also drives the desertion marker, built on the same balloon and unit-marker task skeleton as mode 5.

## Behavior

- V: the event opcode 0x78 dispatcher starts this body for mode 6, in the same way it starts the other mode bodies.
- V: it shares the scene setup with the mode 5 body: resource slot, scene variables, preview sprite records and CharaRender slots.
- V: the node states it drives include Show, Hide, ShowBalloon, ShowUnit, HideUnit and ShowDesertion.
- V: the extra desertion state is the only node name that does not appear in the mode 5 body.
- V: it waits with SceneTask_WaitFrame and ends with SceneTask_Terminate, like the other mode bodies.
- V: it has no direct caller; the mode dispatcher reaches it as a task entry.
- I: the desertion marker makes this the scene body used when a unit leaves the party or the battle, which is why the skeleton is shared with the balloon task.
