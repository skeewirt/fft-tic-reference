## Purpose

Turns a 16-bit text id into a pointer to one string inside one of the game's 32 text pools. It is the single decoder for every text id whose kind selects a pool rather than a table row.

## Behavior

- V: the kind is the id shifted right by 11 and masked to five bits; the pool base is the kind-th entry of a 32-qword global table.
- V: the index is the id masked with 0x7FF; an index of zero returns the pool base itself.
- V: for a non-zero index the function walks the pool byte by byte, counts the separator bytes (values of 0xFE and above) and returns the pointer to the index-th string.
- V: kind 14 (base 0x7000 = 14 << 11) is redirected to sub_140332B48 with argument 2, so ability names come from the ability table rather than a pool; the body compares the five-bit kind with 0xE, there is no 0x7000 immediate.
- V: kind 22 (base 0xB000) is redirected through sub_1402BACCC with argument 9 and a fixed global base, overriding the pool table entry.
- V: there is no end pointer and no bounds check; the walk trusts the pool to contain the requested index.
- I: the pools are per-category packed string lists; slots 1 to 31 are installed at load from one text pack, and slot 0 is the event-script text block.
- ?: what each pool contains in game terms; the pool contents could not be read statically because the table is zero in the image.
