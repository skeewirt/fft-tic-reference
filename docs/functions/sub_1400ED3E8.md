## Purpose

Returns the equip screen's current slot selector: the byte at the UI object's `+0xF1C`, or 0 when the UI module is not up.

## Behavior

- V: it asks the UI module whether it is open and returns 0 when it is not, so a caller never reads a stale object.
- V: the value it returns is the byte at `+0xF1C` of the module's equip object, the field the equip screen keeps the selected slot in.
- V: eleven call sites, all in the equip, sort and item-menu code.
- V: it is a pure read: nothing is written and no argument is taken.
- I: the 0 returned when the module is down is indistinguishable from "slot 0", which is safe because no caller runs while the screen is closed.
- ?: the meaning of the slot numbering (which value is the right hand, which the head).
