## Purpose

The second copy of the classic item-icon state setter; it fills the same 16 by 16 tile state from the item record's icon bytes.

## Behavior

- V: the body is the same sequence as ItemIcon_Set: mask the id to nine bits, read record bytes +0 and +1, compute the tile row by
  division by 15, write the two tile bytes, clamp the palette, write the size and build the packed word.
- V: the only difference is the pair of constants the packed word is built from (a second constant block rather than the first).
- V: four direct call sites.
- I: the callers are one bulk icon builder, two battle/unit panel loops and one shop-row setter, judged from the code around each
  call.
- V: the callers' guards and id sources match the ItemIcon_Set callers: panel words masked to nine bits, one table read masked to
  ten bits.
- I: the two copies are two UI modules' copies of the same routine rather than one shared function, because both are still called.
- ?: whether a linker or a code generator produced the duplicate.
