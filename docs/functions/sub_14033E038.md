## Purpose

Resets the item menu's text-cell block to its default ids before the menu is filled.

## Behavior

- V: It writes a long run of 16-bit values into the block at 0x141D3B7A0..0x141D3B810, mostly zeros, with the constants 0x190, 0x40 and 0xA at fixed cells.
- V: It calls memset on that block and on a second area of the same structure.
- V: It calls sub_14039625C and sub_140397408 afterwards, the pair that resolves and draws the cells.
- V: One caller, sub_14033E4C4.
