## Purpose

Clears every pending status on a unit and refreshes the status icons.

## Behavior

- V: It takes the unit pointer, stores the pending-status block at unit+0x1BE into 0x14186AF70, and ANDs five bytes at +0x1E0 (addressed in the body as (unit+0x1BE)+0x22) with the live status bytes.
- V: It walks 40 status slots, testing bit 0x80 >> (i & 7) of the pending block.
- V: For a set bit it calls sub_140278CF0(unit, index, 0) to clear the status and sub_1401FB064(index + 1, 0, unit id) to refresh the icon.
- V: The unit id comes from +0x1BC and is passed to the icon refresh.
- V: One caller, sub_140241128.
