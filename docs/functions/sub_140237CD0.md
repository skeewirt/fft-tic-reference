## Purpose

Turns the cursor's list cell into a kind-6 battle message entry.

## Behavior

- V: the cell word is read twice and stored zero-extended into the message record: kind 6 at +0x4188 and the id at +0x418C.
- V: the cell array is the static list object at 0x1418716A0 and the cursor index is a word of the shared state (the body reaches it through its pointer alias 0x14184A9B0; 0x1418716A0 is not an immediate here).
- V: it starts a child scene task and waits frames while the selection is live.
- V: it reads the live battle unit table and the message object.
- I: a row-selection task that previews the highlighted row's name as a kind-6 banner (ability name).
- ?: which list it serves and what the second read is for.
