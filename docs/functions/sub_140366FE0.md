## Purpose

The job screen's per-frame update: it tracks the selected unit and row, rebuilds the ability rows for the unit's job, handles input on the ability and equipment lists, and refreshes the detail panel.

## Behavior

- V: it reads the selected unit from the 16-bit global at 0x141811428 and remembers the previous selection in a byte; when the selection changes it resets two screen flags.
- V: it calls sub_140286A78 to rebuild the ability list for the unit's job and JobAbilityList_Build for the list rows.
- V: it reads the shared list buffer at 0x141811470, which at this point holds ability ids written by the ability builder, and compares the selected entry against the constant 486, branching on the result.
- V: it tests the 0x4000 bit (bit 14, `bt r8w,0xe`) of the selected entry before drawing the row, the same packed-word convention the shop list uses.
- V: it calls sub_14028916C when the player changes an equipment slot, and JobScreen_ShowPopup for the confirmation popups.
- V: Input_TestAction drives the accept and cancel handling, and JobScreen_RefreshAfterChange runs when a change has been applied.
- V: it also calls sub_1402C0554 and sub_140327854, the same two helpers the shop screens use to bind a list to its gadget.
- I: the 486 boundary separates two ability id ranges, because the value sits above the item id space and the list holds ability ids at this point.
- I: the screen is the job screen rather than a shop screen, because the ability builder and the job popups dominate the call list.
- ?: which ability id ranges the 486 boundary separates.
- V (2026-11-09): on a tab change the selected tab byte (byte_143CDA92E) picks the list: tab 1 calls JobAbilityList_Build(unit, job word +0x24, 0, g_MenuList, 1) at 0x14036721F, which is Unit_CollectJobSkillsets (the Secondary choices: one skillset word per job); any other tab calls sub_140286A78(unit, tab - 1) (the reaction, support and movement lists over the jobs 74..92).
- V: bit 14 is tested with a bit-test at 0x140367331; when set, the learn action is replaced by a popup at 0x14036733D-0x140367347. The help-id path masks the word with 0x3FF (constant at 0x14036715F) for tabs 2 and above, while the tab-1 path takes the whole word from the load at 0x1403672E1.
- V (2026-11-10): its two `& 0x3FF` masks (0x14036715F, 0x14036757F) strip an ability list word's flag bits before the help key 0x7800 + id and the screen's history entry. They are ability masks.
