## Purpose

A smaller sibling of sub_140109134: it finds one named text part of a UI object and fills it from a packed text id, choosing item, ability or a third source by the text kind.

## Behavior

- V: takes three arguments (object, id, flag) and builds string names to find two gadget parts of the object.
- V: both part lookups are guarded; when either is missing the function returns without writing.
- V: for kind 0x7000 it calls AbilityTable_GetRow with the masked id.
- V: for kind 0x3800 it calls the inlined Item-en row accessor.
- V: for kind 0xB000 a third branch supplies the text without the item or ability tables.
- V: the chosen string is written through the text-node setter at 0x1403F0F8C and a dirty byte is set on the node.
- I: it fills one help or name line rather than a whole panel.
- ?: the caller's screen and what the flag argument changes.
