## Purpose

Runs the crystal / chest window: lists the abilities the roll chose, asks the player to learn them or restore HP and MP (or announces a chest item) and stores the answer in dword_140D40958.

## Behavior

- V: it reads the roll's result block through qword_140D40810 (set by sub_14020435C).
- V: it builds the ability list from the result block's 512-bit set at +94: for each set bit (ability id) it stores the id plus 0x7000 (built as the byte index plus 0xE00, shifted left by 3, plus the bit number, so 0x7000 is not an immediate) in word_141873B30 (512 entries) and, from the 19 per-job sets at +177 + 64 x i, the first index i whose set has the bit, then stores that job's id byte (result +158 + i) in word_1437ACE40.
- V: the list count is the number of set bits; the first page shows at most 8 entries.
- V: result word 4 (chest): the item at result +92 is announced (text 4122, or 4123 when 99 are already held) and dword_140D40958 = 4.
- V: result word 3: a menu (sub_14022CBE4) offers the learn list or the restore confirm; choosing the list and confirming sets dword_140D40958 = 1, confirming the restore sets 2, backing out leaves 0.
- V: result word 2: only the restore confirm is shown, and it loops until confirmed (dword_140D40958 = 2).
- V: a result word of 0 shows text 6204 and no choice; Unit_RollAbilityLearning never returns 0, so this was not seen reachable.
- V: nothing is applied here: sub_140237FA4 turns dword_140D40958 into the choice word that sub_14020BFD4 acts on.
- ?: what the job word list is drawn as (icon or name) in sub_140321DB8.
