# sub_140035A28

- **Address:** `0x140035A28`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `int sub_140035A28(SaveDataManager *manager, const void *chunk, size_t size)`
- **Callers:** `sub_1400358AC` (the manager's vtable slot 16)
- **Callees:** `sub_14003425C` (inflate), `sub_14003441C`, `sub_140031D7C`

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Walks the `UMIF` entry table of a freshly read container: validates the header, descrambles the entry names and keeps one record per entry for the lookup that follows.

## Behavior

- V: it checks the container header (magic `UMIF`, version, entry count) before touching the entries.
- V: the entry records are 32-byte descriptors: name length, data length, name offset, uncompressed length and data offset.
- V: it descrambles the names only; it does not inflate payloads here, which is why an entry nobody requests is never inflated on load.
- V: the resulting records are what the name search (`sub_140036064`) later walks.
- I: because the walk keeps every entry, an entry with an unknown name is retained in the container model and simply never requested; it is not rejected.
- ?: whether a malformed descriptor is skipped or aborts the whole walk was not read.

## State touched

- Calls: [SaveData_InflateEntry](SaveData_InflateEntry.md)
- Reads: [SaveRequestRecord](../structs/SaveRequestRecord.md)

## Notes

Read as the reader half of the container: this routine builds the entry list, `sub_140036064` searches it, `sub_140033DF0` dispatches a hit.
