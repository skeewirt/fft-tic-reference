## Purpose

Loads all fifty slots into the caller's buffer, through the PNG path or the legacy per-slot files.

## Behavior

- V: when the legacy flag at 0x142E7FB78 is set it reads savedata/fftsave_%02d.bin, one file per slot, through the virtual file system.
- V: otherwise it fills the caller's fifty-slot buffer through the same slot loader the PNG path uses.
- V: no writer for the legacy per-slot files exists in this build, so that branch only fires on data from another edition.
- I: the function is the console-compatibility loader, kept for saves that were never packed into a PNG.
- ?: whether any shipped PC data ever sets the legacy flag.
