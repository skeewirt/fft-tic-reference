## Purpose

Moves the cursor on a list of GUI nodes: optionally focuses nodes[cursor], then updates every node's CursorOver / CursorOut animation (sub_1400F5C78) with 'is cursor' = (index == cursor).

## Behavior

- V: valid = nodes != 0 && count > cursor && cursor >= 0. If focusOwner == 0 and valid: result 0 (no focus change). If focusOwner != 0 and valid: result 1. If not valid and focusOwner == 0 it first calls GUICore_FocusNode(0). (Invalid with focusOwner != 0 returns the unset result.)
- V: when nodes != 0: if result != 0, sub_1400F5674(nodes[cursor]) focuses the cursor node. Then for i in 0..count-1, for every non-null node, builds a 4-byte option struct {+0 flagA, +1 flagB, +2 u16 = 0} and calls sub_1400F5C78(node, &opts, i == cursor).
- V: returns the last result (focus result or the void call's leftover).
