# sub_140304F44

- **Address:** `0x140304F44`
- **Area:** [Battle](../areas/battle.md)
- **Prototype:** `int sub_140304F44(int mode, int x, int y)`
- **Callers:** sub_140304DC0
- **Callees:** sub_140282A7C

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Answers what a map tile contains: it bounds-checks a tile coordinate and returns the element/terrain flags packed for that tile.

## Behavior

- V: Arguments are a mode (ecx), x (edx) and y (r8d); both coordinates are rejected when negative or not below the map width and height bytes at 0x140C6AD6A and 0x140C6AD6B.
- V: The mode picks one of four pairs of bit patterns (4/6, 6/4, 2/0 and 2/4) that are applied to the tile data.
- V: The tile index is built from the context at 0x14186AF68 (position bytes +0x50 and +0x51) scaled by the map width byte, and the byte is fetched through the layer base at 0x140D8DCB0.
- V: It also reads 0x1407B0761 and writes the answer into 0x1407B0791 and 0x1407B0792.
- V: One caller, sub_140304DC0.

## Referenced by

- Called by: [Formula_KnockbackCalc](Formula_KnockbackCalc.md)

## Notes

V: a tile's element flags are eight packed bytes per tile, with the tile index bounded by the map size; the bounds are read here.
