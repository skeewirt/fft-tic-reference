## Purpose

Looks a file name up in the mounted-pack registry's hash tree, inserting a new node when the name is not there yet.

## Behavior

- V: the registry is an array of 512 buckets selected by the low nine bits of a 32-bit hash of the name.
- V: a node holds the hash at `+0x20` and the name at `+0x18`; equal hashes are resolved by a byte-wise name comparison.
- V: it is the tree operation of the registry: find, and insert when absent, in one call.
- V: five call sites: the pack mount list, the single-pack mount and three lookups in the file layer.
- V: the bucket mask is the same for the pack registry and the file registry, so both hold 512 buckets of names.
- I: because the name is stored lower-cased by the mount code, the comparison is effectively case-insensitive.
- ?: what the node's other fields are; only the hash, the name and the bucket link were read.
