## Purpose

Resolves one battle action: copies the 20-byte action, sets up per-command data, dispatches the formula and runs the post steps.

## Behavior

- V: copies the 20-byte action a1 and sets up pointers into g_BattleUnitTable for the actor (action byte 0) and target a2.
- V: reads the aux flags4 dword for the ability id; `& 3` and `& 0x1000000` are stored at unit-state byte +26 (bytes read at 0x140309C5E, 0x140309C6C).
- V: for command type 10 clamps `if ((unsigned)(id - 406) > 7) id = 406` then reads kind4 byte 1 (byte_140788F55[2*id]) into word_1407B0787, at 0x140309EC3.
- V: for ids < 368 copies the 20-byte AbilityAction_GetRecord(id) into the action block; command type 1 uses the item record (sub_1402B8E04).
- V: the u8 formula id v23 (forced to 1 when outside 1..0x6A) is dispatched through the formula registry by an indirect call at 0x140309F53 (the handler is g_FormulaHandlers[v23]: an 8-byte-entry table at image offset 0x682BC8, indexed by v23).
- V: after the call: `v23 < 7` calls sub_1403067D0 (0x140309F5B); `v23 >= 7` with `v23 == 100` clears word +0x12 of the action (0x140309F68); then sub_14030A11C(1).
