Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Builds the item list for one shop tab, choosing between the shop's stock list and the party's inventory depending on a flag, and returns the number of ids produced.

## Behavior

- V: the first argument is the tab index and the second is a flag that selects the source.
- V: the tab is mapped to a menu category: tab 0 and 1 become categories 5 and 6, tabs 2 and 3 stay 2 and 3, tab 4 becomes 4, and tab 5 becomes category 7.
- V: when the flag is non-zero it calls Shop_BuildItemList with a unit of 0xFFFF (produced by ORing ecx with -1), the shop number from 0x141811684, the mapped category, the list buffer at 0x141811470, mode 0 and the sort flag clear.
- V: when the flag is zero it calls Inventory_BuildEquipList with the same category and buffer instead, which lists what the party owns rather than what the shop sells.
- V: both branches return the count that the callee produced.
- V: the function clears nothing and reads no other state.
- I: the flag is the buy-versus-equip distinction, because the zero branch lists the party inventory and the non-zero branch lists shop stock.
- I: the tab mapping to categories 5, 6, 2, 3, 4 and 7 matches the six category groups Shop_BuildItemList accepts, so the tabs are the shop's category tabs.
- ?: why tab 0 and tab 1 map to categories 5 and 6 rather than 0 and 1.
- V: the shop branch calls Shop_BuildItemList with mode 0 at 0x14036C42D and the equip branch calls Inventory_BuildEquipList with mode 0 at 0x14036C45E, so neither branch sets a flag on this path.
