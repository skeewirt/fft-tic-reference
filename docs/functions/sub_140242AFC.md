Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Initialises one 0x20-byte UI element: screen position, texture coordinates, size, and a packed flag word, from a source record and
a rectangle.

## Behavior

- V: takes the element, a source record, a position pair and a rectangle.
- V: a masked field of the byte at element +0xF selects between two layout branches (the field is the byte's bits 2 to 6 compared
  with 0x64).
- V: in the first branch the position comes from the rectangle plus the source, the texture offset from the source, and the size
  from two words of the rectangle.
- V: in the second branch it derives a packed word from the rectangle's flags and writes it at element +0x1E.
- V: writes the position at +0x10/+0x12, the texture coordinates at +0x14/+0x15 and the size at +0x18/+0x1A.
- V: the item-icon setter runs immediately after this builder at every icon site and overwrites +0x14, +0x15, +0x16 and +0x18 (the +0x16 store is in ItemIcon_Set; this body writes only +0x14/+0x15 and the word pair at +0x18/+0x1A).
- V: 91 direct call sites.
- I: the element is a generic image/quad record shared by many screens, because the builder is called from unrelated UI code.
