- **Address:** `0x14025FC38`

- **Callers:** The YOX page writer and reader
- **Callees:** memmove

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Copies rows into the 16-bit image page stored in the battle payload.

## Behavior

- V: the copy steps by 0x800 bytes per row, so the page is a 16-bit surface 0x800 bytes wide.
- V: the destination is the 1 MB page at 0x142FF9F90 that the payload carries for kind 1.
- V: the page is compressed on write and inflated on load, so this helper works on the page after it is decompressed.
- I: 0x800 bytes per row at two bytes per pixel means a 1024-pixel-wide page.
- ?: the page height and what the image shows.
