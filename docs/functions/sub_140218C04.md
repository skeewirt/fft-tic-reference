## Purpose

Copies a freshly loaded flat image into the slot cache.

## Behavior

- V: it fills a local buffer with sub_140218728 and then moves the fifty slots into the cache at 0x142C8B970.
- V: it is called from the save frame step when the normal load fails, so the cache still ends up with data.
- V: it performs no validation of its own; whatever the loader produced is copied.
- I: the fallback exists so a failed PNG read does not leave the menu with an empty slot list.
