## Purpose

Returns the 3-byte usable-item sub-record (I: formula, amount, status record index into the 6-byte table at 0x14080FBA0), or null when the item is not of this kind.

## Behavior

- V: calls Item_CategoryFirstId(id) and computes index = id - that first id (16-bit); then calls Item_FindCategoryIndex(id) again; -1 returns 0.
- V: kind = g_ItemCategoryType[category]; kinds 4 and 9 select the tables 0x14080FB70 (ids 0xF0..0xFF; 0xFE and 0xFF are never reached) and 0x14067277C (kind 9 is unreachable); element size 3, index = id - first id of the kind; any other kind returns null.
- V: relies on the callees leaving r9 and r10 untouched (it keeps the id in r9 and the index in r10 across both calls); the stock callees only touch rax, rcx, rdx and r8.
