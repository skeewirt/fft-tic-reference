## Purpose

The complement of the Mime predicate: it accepts a battle unit that is not a Mime and carries a particular marker, then walks the target list looking for an entry that is flagged.

## Behavior

- V: it requires the same record shape as the Mime predicate: kind 9, index 21 or below, and the flag bit 0x08 set at `+0x1EE`.
- V: it rejects the record when its job byte at `+3` is 0x5D (Mime), the opposite of the sibling routine.
- V: it further requires the byte at `+0x1A1` to be 0x15 (21).
- V: the list at `+0x0C` and `+0x10` is then walked and each entry's record is accepted only when its own byte at `+0x1BE` is non-zero.
- I: the pair of tests (a status-like byte at `+0x1A1` and a list-entry flag at `+0x1BE`) suggests a "has already been acted on" check, but the meaning of both bytes is unproven.
