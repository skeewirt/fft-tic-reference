## Purpose

Publishes a built list to the UI: it checks that the UI list module is open and hands the list parameters to the module's list setter with a "publish" flag.

## Behavior

- V: it resolves the UI module through its global, asks the module whether it is open, and returns when it is not.
- V: it then takes the module's list object and forwards four caller values plus a stack byte of 1 to `sub_140128E1C`.
- V: the constant 1 on the stack is the publish/visible flag, so the call both fills and shows the list.
- V: two call sites: the equip-screen list builder and the job-screen list builder, both right after they filled the menu list.
- I: "publish" is the moment the list becomes visible; a builder that skips it leaves the previous list on screen.
- ?: what the four parameters mean to the setter (start index, count, selection, mode).
