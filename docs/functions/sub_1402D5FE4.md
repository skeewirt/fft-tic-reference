Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The Outfitter/shop sell-or-confirm handler for the selected slot. It refuses a pending (bit-15) word, prices
the slot on the confirm branch, and clears the slot when the sell is accepted.

## Behavior

- V: It reads the slot word at unit +0x54 + 2*slot and tests it as signed (a zero test at 0x1402D6129, a negative branch
  at 0x1402D612E). A bit-15 word is negative and takes the state-5 branch instead of the sell branch.
- V: On the confirm branch it prices the slot with `Item_SellPrice` and stores the price in
  `xmmword_14078D9C0`.
- V: On the accepted sell path (the menu word 4 is zero) it clears the selected slot word at 0x1402D625A,
  refunds the stored price with `sub_140284684`, calls `PartyUnit_ReloadEquipment` and sets UI state -105.
- V: The help token is built with a 0x3FF mask (0x1402D60F3) from the same word.
- I: The signed test is the flag test: because bit 15 makes the word negative, a pending purchase cannot be
  sold until it is committed or undone.
