## Purpose

Fills the shop row's category text from the item in the global shop list.

## Behavior

- V: It reads the shop list entry at the row index and masks it to ten bits.
- V: The item record's category byte then indexes the shop's category text table, and two bytes of that row are written to the row's text globals.
- V: It also writes a fixed 0xC000C value to a row state field, which looks like two packed text attributes.
- V: It calls one helper and has no direct caller.
- I: The category byte is the same one the equip checks use, so the shop's category text and the menu category agree.
- V: the id is masked at 0x140332CEC before the item record lookup at 0x140332CEF; the entry's flag bits are discarded.
