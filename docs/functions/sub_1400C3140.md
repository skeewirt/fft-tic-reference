## Purpose

Turns one ready buffer into a named container entry: it seals the buffer with a CRC, queues it under the given name with version 17 and marks the object clean.

## Behavior

- V: it only acts when both the buffer pointer at `+624` and the length at `+632` are set; otherwise it returns without queueing.
- V: it stores the CRC-32 of the buffer at `+12` and then queues the entry with version 17 and the buffer length.
- V: after queueing it clears the dirty byte at `+641`, so the same buffer is not queued twice.
- V: three sites: the flush's per-record queue, the map insert's fallback and the manual battle save's `resume_enmaNN_world.sav`.
- V: version 17 is the resume version; the manual slot uses 14 and the settings block 0.
- I: the guard on both pointer and length is why an empty group produces no entry at all rather than an empty one.
- ?: whether the queue keeps the buffer or copies it; the allocator note in `sub_1400C30BC` implies the queue takes a copy.
