# sub_1401E7EF8

- **Address:** `0x1401E7EF8`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `? int sub_1401E7EF8(void *manager)`
- **Callers:** Title / continue setup (the twin probe of Boot_Update)
- **Callees:** sub_140033CBC (request), sub_140034CF0 (read kick), sub_1400366B0 (exists), NXD registry lookups

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Probes the SYSTEM save area for `settings.sav` while the title and continue paths set themselves up, and applies what it reads.

## Behavior

- V: the body builds the area name SYSTEM and the entry name settings.sav and asks the save-data manager for that entry.
- V: the file is tested for existence before the read; the request is built with the generic queue helper and the read is kicked through the manager.
- V: reads the global language block and the NXD registry after the entry arrives.
- I: the loaded block is the 0xF0-byte options record, so the title menu can show the stored language, volumes and progress bits (the 0xF0 size is not an immediate in this body).
- I: it is a sibling of the settings probe in Boot_Update: two functions, four references, same area and entry.
