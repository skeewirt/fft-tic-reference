## Purpose

Builds one row of an item list: its name text, the item's small picture path and the parts that draw them.

## Behavior

- V: takes the list object, a row index, a value and the item id.
- V: finds the row element through a helper and returns when it is missing.
- V: stores the value in a per-row dword array at list +0x5C and sets a flag byte at the row element +0x1A0.
- V: the row element's base is list +0xB0 plus the row index times a 0x68-byte stride.
- V: a negative value clears the row's flag byte and returns before any name or icon work.
- V: the item id, the fourth argument, is used only after that check, for the name and the small path.
- V: looks the item name up and pushes it into the row's part string ring.
- V: calls a second item helper whose byte result is also pushed into the ring.
- V: formats the small item picture path into a 260-byte stack buffer.
- V: binds that path as a texture name to the row's icon node.
- V: two direct call sites, in list refresh code.
- I: the row element is a fixed 0x68-byte record per list slot, because the row index is multiplied by that stride.
