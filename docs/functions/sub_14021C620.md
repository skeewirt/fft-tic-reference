## Purpose

The classic load menu: it reads the chosen card, imports the header and materialises the run.

## Behavior

- V: input is polled with the action test helper, and the chosen card's slot is taken from the list state.
- V: the selected entry's header is imported with sub_14021849C before any body is touched.
- V: the run is then materialised through sub_140257354, the same path title Continue uses.
- V: a work-copy move follows, and the menu waits on its card animation before it retires.
- I: classic and enhanced loads differ only in the card layer; both end in the same header import and materialiser.
- ?: the page and node map of the classic card layer.
