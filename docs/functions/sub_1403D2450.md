## Purpose

Loads the byte range of chunks [first, last) of a chunked file into one of 8 cached buffers (or a single scratch buffer) and returns 0 on success.

## Behavior

- V: a table of 16-byte chunk records at *(a1 + 16): size = rec[last].offset + rec[last].size - rec[first].offset (the three dwords at 16 * last - 16, -12 and 4 * first * 4); a 4-chunk step is used for the index (v13 = 4 * first).
- V: single-chunk loads (last - first == 1): with forceNew set the first free of 8 cache slots (dword at a1 + 456 + 4 * k == -1) is used, -1 when none; without it an existing slot holding the same first index is a hit and returns 0 immediately.
- V: no slot (-1): sub_1403D25A4 drops the scratch buffer, a new buffer of that size is allocated with sub_140011750 into qword +24 / +32; with a slot: sub_1403D26C4(a1, slot, size, first) allocates it (qword +328 + 8 * slot and +392 + 8 * slot, dword +456 + 4 * slot = first).
- V: dword +316 = first; the data is read with MemFile_Read(*(a1), buf, rec[first].offset, size) when the memory source qword +304 is 0, else memmove from +304 + offset. Returns 1 on allocation failure.
- V (2026-11-10): its three callers pass the g2d.dat reader `qword_140D3AD58` (a 488-byte reader opened on system/ffto/g2d.dat by sub_1401E7C58): the chunked file is g2d.dat, 'YOX' header with the table offset at +8 and the entry count (2450) at +12, rows of (u32 offset, u32 stored size, u32 type 6, u32 0). Every caller loads one entry n as [n, n + 1), reads it with PackFile_ReadEntry and drops the scratch buffer with sub_1403D25A4.
