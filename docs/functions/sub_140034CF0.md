## Purpose

Kicks the container read state machine for one area name, which makes the pending entry requests for that area get looked up, inflated and delivered.

## Behavior

- V: the shape mirrors the write kick: file object, request kind (5 for the manual slot, 7 for the autosave) and the area name.
- V: it runs after the requests were queued with `sub_140033CBC`, and only the names queued in that pass are delivered.
- V: six direct sites: the settings boot probe, the manual-slot loader, the resume fan-out, the battle-resume part of a slot load and the title probe.
- I: it shares the request object's busy flag with the write kick, so a pending write has to finish before a read starts.
- I: the machine is the same one the writer uses, in the opposite direction.
