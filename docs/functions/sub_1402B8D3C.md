## Purpose

Returns the 2-byte head / body sub-record (added to the unit's max HP / MP, capped 999: sub_1402779EC), or null when the item is not of this kind.

## Behavior

- V: calls Item_CategoryFirstId(id) and computes index = id - that first id (16-bit); then calls Item_FindCategoryIndex(id) again; -1 returns 0.
- V: kind = g_ItemCategoryType[category]; kinds 2 and 7 select the tables 0x14080FAB0 (ids 0x90..0xCF) and 0x1406732FC (ids 0x102, 0x103); element size 2, index = id - first id of the kind; any other kind returns null.
- V: relies on the callees leaving r9 and r10 untouched (it keeps the id in r9 and the index in r10 across both calls); the stock callees only touch rax, rcx, rdx and r8.
