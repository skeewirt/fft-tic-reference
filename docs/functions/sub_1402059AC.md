## Purpose

The end-of-action notification task: it reads the action's presentation row, pushes the message and then retires.

## Behavior

- V: the object carries the BattleActionEndNotification vtable, so instances of it are notification tasks.
- V: the ability animation table at 0x140672DA0 is read at its third byte, the battle-text column of the three-byte row (the `lea` encodes base+2 = 0x140672DA2, so the table base is not an immediate).
- V: it pushes a message through the queue producer rather than calling the dispatcher directly.
- V: it reads the skip request source, the event fast-forward flag, before deciding whether to wait.
- I: this is the banner/notification step that follows a resolved action, not the action itself.
- ?: what condition selects the notification text and how long it waits.
