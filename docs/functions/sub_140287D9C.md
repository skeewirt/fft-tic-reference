## Purpose

Builds the Outfitter's candidate list for the selected unit and shop: five category lists are merged, ordered,
and the first four output words are marked with bit 15 when they differ from the live and override words.

## Behavior

- V: The pointer arguments are not read; the unit is `g_SelectedUnitIndex` (0x141811428) and the shop is
  `g_SelectedShopIndex` (0x141811684).
- V: For each of the five category bytes 5, 6, 2, 3 and 4 it calls `Shop_BuildItemList` with mode 2 and the
  sort flag set, writing into a 152-word stack list.
- V: It merges the lists into the caller's output, capping at 146 entries and stopping on 0xFFFF. The merge is
  an insertion sort whose adjacent comparisons go through `sub_14028B180`; the comparison group per position
  comes from the byte table reached through the pointer at 0x14067FAE8.
- V: The sort swaps two stack words at 0x140288256/0x14028825B (load, store, store): the candidate list is
  reordered in place, flags and all.
- V: It then walks the output and, for each of the first four words, compares the signed candidate word with
  the unit's raw word (0x140288525/0x14028852C) and the override word (0x140288537/0x140288540). A candidate
  that matches neither is OR-ed with 0x8000 (the constant 0xFFFF8000 is loaded at 0x140288544, OR-ed at
  0x140288549 and stored at 0x14028854C).
- V: The mark loop runs four times: 0x140288471 sets the count to 4 (a loop count of 4), not five. The fifth
  output word is not written by this function; the session functions copy it from the unit's +0x5C.
- V: A unit word that already has bit 15 does not equal the signed candidate, so the mark is re-applied on a
  pending word; the "changed" test is therefore against the raw word, not its masked id.
- V: The stack list entries are masked with 0x3FF before they are sorted (0x1402882A0/0x1402882B3); the mark
  is the only flag added.

## Notes

- V: The function writes a 5-word-capable output but only four marks. The earlier sheet's "five output words"
  was one too many; the fifth is the caller's copy of unit +0x5C.
- V: It never reads or writes the shared menu list; the bit-14 "cannot equip" marks of the shop list are not
  copied here because mode 2 filters those entries out.
