## Purpose

Copies the shared display list into the saved order list of one menu group, so that the order the player left the menu list
in becomes the stored order.

## Behavior

- V: takes one group index and looks the list pointer up in a table of five pointers, without a range check.
- V: reads the shared display list from its first word and copies entry after entry into the group list.
- V: it stops at the 0xFFFF terminator of the display list (compared with the word -1) and then writes the value 255 into the group
  list as its end marker.
- V: there is no capacity check; the group list is the smaller array (21 to 141 words) and the display list can hold up to
  256 words.
- V: it touches no other global and calls nothing.
- I: the single caller is the item-menu handler that rebuilds all five group lists after a sort, which fits "confirm the
  displayed order as the saved order".
- ?: whether a display list longer than the group list has ever been observed; the stock group sizes leave at most two spare
  words.
- V: the whole 16-bit word is copied from the shared display list to the saved order list off_14067F498[group] (load at 0x140285F2C, store at 0x140285F57), with no mask; a flagged entry would be copied with its flag.
