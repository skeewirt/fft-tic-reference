## Purpose

Builds the battle signal list of the statuses a pending action result applies (the same list UnitPanel_SetSignalList builds for the unit panel) and returns its length.

## Behavior

- V: copies the two five-byte status sets at BattleControl +693675 and +693680, builds the status id list with StatusList_BuildFromResultBlock, and for each id (bit 0x80 = removed) looks up the UIStatusEffect row of key id + 1.
- V: an entry is kept when the row's list_category (+0x14) is non-zero, battle_signal (+0x18) is not 59 and BattleSignal (table 214) has a row of that key; it stores the signal byte (row +0x18 as read, with the removed bit) and counts it.
- V: copies at most 40 bytes to the caller's buffer and returns the count.
