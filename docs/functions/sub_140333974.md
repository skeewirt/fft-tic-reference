## Purpose

A shop list gadget handler: it edits the shop's displayed list and emits the message token for the item it acts on.

## Behavior

- V: It reads and writes entries of the global shop list, masking each entry to ten bits whenever it needs the item id.
- V: Before editing it checks that the row index is inside the current list length.
- V: One branch builds a 0x6800 message token from the entry's id, which is how the shop names the item in its message line.
- V: The entry's other bits are preserved when an id is written back, so the list's flag bits survive an edit.
- V: It calls twelve helpers and has one direct caller.
- I: The edit-in-place pattern and the preserved flag bits are the shop list's own convention, shared with the row helpers.
- V: the sell action tests bit 14 with the 0x4000 constant at 0x140333C58 and the test at 0x140333C5D; a flagged entry is refused through the error byte at 0x140333C62. The help token masks the word at 0x140333C14.
