## Purpose

Adds an OverrideEntryData row's HP and Speed growth bonuses to a unit work record, by the play mode (the configuration byte +196).

## Behavior

- V: does nothing unless both pointers are set; the index is byte +196 of the record qword_140C69690 points to.
- V: the row holds four (offset, count) dword pairs at +0x5C/+0x60, +0x64/+0x68, +0x6C/+0x70 and +0x74/+0x78; when the index is below a pair's count, the i16 at row + offset + 2 x index is added to c +138, +139, +142 and +143 respectively, each only when the sum stays at 254 or below.
- V: Unit_ComputeStats reads work +138 + 2 i as the (growth constant, multiplier) pair of stat i in the order HP, MP, Speed, PA, MA, so +138 / +139 are the HP pair and +142 / +143 the SPEED pair (stat index 2, stored at work +58), not the MP pair; the row's four arrays are the columns hp_growth_constant_bonus, hp_multiplier_bonus, speed_growth_constant_bonus and speed_multiplier_bonus.
- V: the index is the play mode, the key of the DifficultyLevel row (see the behaviour EntryGrowthBonusesByPlayMode).
