## Purpose

Builds the elements of an item or effect panel: for ordinary items it sets the classic icon, and for one special category it
allocates and fills a block of effect entries.

## Behavior

- V: has no direct callers; it is reached through a UI dispatch table.
- V: reads a global mode and branches on it.
- V: reads the item id from a dword at record +0x28 and looks the record up.
- V: when record byte +5 is not 0x20 it sets the classic item icon from that id.
- V: when the byte is 0x20 it allocates a 0xA00-byte block and fills 0x50-byte entries in two nested loops (the inner loop runs
  sixteen times; the outer count was not read), storing the block on the record.
- V: the filled entries carry a constant byte, the item id and a per-entry value.
- V: 0x64D-byte body (the .pdata size, not an operand).
- I: the 0x20 category is a special item kind with its own effect list, because the code takes a completely different branch for it.
- ?: the panel the elements belong to and the meaning of the mode branch.
