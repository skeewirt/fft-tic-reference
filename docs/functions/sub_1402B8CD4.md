## Purpose

Returns the 2-byte shield sub-record (copied into the unit's evade group, I: physical / magic evade), or null when the item is not of this kind.

## Behavior

- V: calls Item_CategoryFirstId(id) and computes index = id - that first id (16-bit); then calls Item_FindCategoryIndex(id) again; -1 returns 0.
- V: kind = g_ItemCategoryType[category]; kinds 1 and 6 select the tables 0x14080FA90 (ids 0x80..0x8F) and 0x140672764 (kind 6 has no ids); element size 2, index = id - first id of the kind; any other kind returns null.
- V: relies on the callees leaving r9 and r10 untouched (it keeps the id in r9 and the index in r10 across both calls); the stock callees only touch rax, rcx, rdx and r8.
