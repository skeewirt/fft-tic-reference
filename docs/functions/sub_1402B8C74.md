## Purpose

Returns the 8-byte weapon sub-record (I: range, attack flags, formula, -, power, evade, element, status effect), or null when the item is not of this kind.

## Behavior

- V: calls Item_CategoryFirstId(id) and computes index = id - that first id (16-bit); then calls Item_FindCategoryIndex(id) again; -1 returns 0.
- V: kind = g_ItemCategoryType[category]; kinds 0 and 5 select the tables 0x14080F690 (ids 0x00..0x7F) and 0x140680500 (ids 0x100, 0x101); element size 8, index = id - first id of the kind; any other kind returns null.
- V: relies on the callees leaving r9 and r10 untouched (it keeps the id in r9 and the index in r10 across both calls); the stock callees only touch rax, rcx, rdx and r8.
