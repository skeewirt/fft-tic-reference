## Purpose

Adds a unit's candidate action slots for command a2 (one entry per usable ability, or a fixed set for Throw / Items / Jump) to the AI slot table at word_141872598.

## Behavior

- V: the command type (byte_14067E010[a2]) 2 adds fixed slots (ids 122.. and 125.. groups of 3) plus one more; type 3 adds one slot; other types loop 16 slots of Skillset_BuildAbilityList(a2, 1).
- V: aux flags4 sign test at 0x140316F1D (the byte at 0x140787F87 + 8*id, i.e. byte 3 of the flags4 dword, is compared with 0): only ids whose flags4 top bit (byte 3 negative) is set are added.
- V: for ids < 0x170 it also needs AbilityAction_GetRecord(id): byte 13 (halved by a unit flag) <= a unit word and record byte 6 bit 8 or 4 matching unit status bits.
- V: ids >= 0x170 go straight to the sub_1403170CC(unit, command, slot) availability check; entries store id | (unit << 10) in the slot and the command at byte 2.
- V (read 2026-11-12): arguments are the unit slot (a1), the command (skillset) byte (a2, an int the caller loaded from the unit's +0x12 or +0x13; the offsets are the caller's) and the number of entries already in the row (a3); the result is the new entry count. The row is byte_141873038[unit] x 34 entries of 4 bytes in g_AiCommandTable (struct AiCommandEntry): word id | slot << 10, byte +2 the command, byte +3 flags.
- V: command kinds (g_CommandKind[a2]): 2 adds up to six fixed entries (ids 122..124 when sub_1403170CC(unit, a2, 0) passes, 125..127 for 1; command byte a2) and one more entry when any of 12 further checks passes; 3 adds one entry (word = slot << 10, byte +2 = a2); 10 returns at once when the item record named by the row header's item word (word_141872E24, header +4) has type byte 10; 9 adds one jump entry (byte +2 = 18, word = slot << 10) when no list ability below 0x18F was added; every kind loops the 16 slots of the set's list (Skillset_BuildAbilityList(a2, 1)).
- V: for a monster set (a2 - 176 <= 0x2F) the entry's flag byte +3 gets bit 0x08 for the fourth list slot and loses it for the others; the stores of the command byte are at 0x140316DE0, 0x140316E35, 0x140316E78, 0x140316E9F, 0x140316FFF (variable) and 0x1403170AB (constant 0x12, the jump entry).
- V: a2 arrives as an int with the byte's value.
