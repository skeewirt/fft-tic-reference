## Purpose

Fills a selection panel from one item: clears its text, stores the id, updates a named node, and sets the small item picture and
name on the panel's parts.

## Behavior

- V: takes the panel, the item id and the selection record.
- V: clears the panel's text buffer and stores the id at +0x608.
- V: copies one selection element and calls the panel visibility helper.
- V: looks a node up by name and sets a byte on it when found.
- V: on the icon branch, formats the small item picture path into a 256-byte stack buffer and binds it as a texture name.
- V: four direct call sites.
- I: they are item selection/refresh paths, because each one binds the small picture or clears a selection panel.
- I: the named node is the panel's item picture holder, because the same branch binds the small path.
- ?: the name used for the node lookup.
