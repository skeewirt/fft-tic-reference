## Purpose

Builds one resume payload in scratch memory: header, work copy or battle snapshot, and the YOX image page.

## Behavior

- V: it zeroes a 1.5 MB scratch block, then copies either the 40,164-byte work copy (kind 0) or the 668,112-byte battle snapshot (kind 1) to offset 0x154.
- V: the payload header (magic FFTI, version 0x7A, kind, structured size, self-check, leader summary, play time and timestamp) is filled by sub_1402D0108.
- V: for kind 1 it compresses the 1 MB image page into the tail after the snapshot and writes the YOX tag.
- V: the finished payload is handed to the group store sub_1400C30BC.
- V: it returns 0 on success and -1 on failure.
- I: it is the only producer of the resume payload; the adapter stub installed at object+0xF0 merely forwards to it (the +0xF0 offset is in the caller's handler object, not in this body).
- ?: which call site invokes the installed callback.
