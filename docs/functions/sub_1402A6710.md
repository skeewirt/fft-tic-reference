## Purpose

Refreshes one possession or shop panel row: it resolves the entry in the third argument either as an item id or as a UI table row and fills the row's icon, name and grey-out state.

## Behavior

- V: it builds a 512-byte work area and then processes the entry at a3.
- V: the first dword of the entry (`*(int *)a3`) is compared with 261 at `0x1402A69CE`; below it the entry is an item id, at or above it a UI table 0xEC row.
- V: the item branch calls `Item_GetRecord(*(unsigned __int16 *)a3)` and uses record byte +0xA (>= 0x14) for the grey-out state; the 4-byte entry is read as a word by the record accessor.
- V: the item id and the table row share the dword; the comparison is a discriminator, not a width bound on a packed word.
- V: the row fill then calls `ShopItemList_FillRow` and sets the "GrayOutPossession" state from the count and the scene variable 44.
- V: the dword is written by the shop list builder; the accessor reads only its low word.
- I: the function is shared by the shop and possession panels, which is why the entry can be either kind.
- ?: which producer writes an entry at or above 261.
- V: the row label is text line 2098, or 2099 when the item record's byte +10 (for an item id below 261) is 0x14 or more or the PoachItem row byte +0x36 (column notice_mark) is non-zero; the PoachItem row is the one of the entry dword +24; it calls PoachRow_SetMonsterIcon for the icon.
