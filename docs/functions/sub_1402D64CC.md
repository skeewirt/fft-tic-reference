# sub_1402D64CC

- **Address:** `0x1402D64CC`
- **Area:** [Unit data](../areas/unit-data.md)
- **Prototype:** `__int64 __fastcall sub_1402D64CC(__int64 unused, __int16 slot)`
- **Callers:** `sub_1402D58EC`, `sub_1402D7280`
- **Callees:** `sub_140288788`

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Puts the override word back into a cleared slot, or clears the slot's override when the slot is not restored.

## Behavior

- V: It clears the unit word first (0x1402D6515) and reads the override word for the selected unit and slot
  from `g_UnitEquipOverride` (0x1402D651A).
- V: For slot 2 or above it writes the whole override word back (0x1402D65A7) and clears the override
  (0x1402D65AC), with no flag test.
- V: For slots 0 and 1, when both hand words are zero it restores both from the override array
  (0x1402D654F loop) and clears the first two override words as one dword (0x1402D656A).
- V: Otherwise, when the override is non-zero, it calls `sub_140288788` for the override id (0x1402D6581);
  only a return of 1 writes the override back (0x1402D6593) and clears it.
- I: The whole-word copy means a bit-14 override is restored unchanged; the routine never masks the id.
