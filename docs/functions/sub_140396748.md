## Purpose

A second copy of the order-list filter, working on the possession list instead of the shared display list. It reorders a
0xFFFF-terminated list by one of the saved item order lists and drops entries the order list does not name.

## Behavior

- V: takes a group index and reads the order-list pointer from a second pointer table that holds the same five list
  addresses as the main table.
- V: reads the order list until the value 255 or any value of 261 or above.
- V: for each order entry it scans the target list for the first entry whose low ten bits match, and copies the raw entry
  into a 264-word stack buffer.
- V: terminates the buffer with 0xFFFF (the -1 held in ebp after ORing it with -1, stored as a word) and copies it back over the target list.
- V: the target list is a static array at a fixed address, separate from the shared display list.
- I: the caller fills that array from the inventory snapshot before filtering it, resting on its other call sites.
- V: returns the number of entries kept.
- I: the possession list is filled from the inventory snapshot by the same caller family, which is why the filter needed a
  second copy here.
- ?: why a separate copy of the filter exists instead of a call to the first one; the two differ only in how the order list
  is addressed.
