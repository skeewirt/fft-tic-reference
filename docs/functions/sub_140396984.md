## Purpose

Fills the attribute part of an equip preview: which stats an item would add and which of them the unit already has.

## Behavior

- V: It zeroes two words of the output record and keeps the item id in a 16-bit register.
- V: The id is masked to ten bits for the record lookup and again for each sub-record lookup.
- V: The record's kind byte selects the weapon, shield, armor or accessory sub-record, and that sub-record supplies the attribute and inflict bytes.
- V: Each attribute index is compared with the unit's current attribute values so the preview can show the delta.
- V: It calls five helpers and has five direct callers.
- I: The preview uses the same sub-record selection as the live stat functions, so the two views cannot drift as long as both read the same tables.
