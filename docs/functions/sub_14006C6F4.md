## Purpose

A typed read wrapper over the virtual file system: opens a named file, optionally seeks to an offset, reads a fixed block and closes it.

## Behavior

- V: it delegates the actual transfer to the virtual read routine, so it inherits the pack-first resolution.
- V: the callers are the legacy save loader and three asset loaders, all of which read one known file into one buffer.
- V: the offset and length are the caller's; the routine does not parse what it reads.
- V: the legacy save loader uses it to fetch a numbered flat image, the fallback path that only runs when the legacy flag is set.
- I: it is the "read exactly this file at this offset" convenience layer, which is why six unrelated loaders share it.
- ?: whether a failed open is reported as a short read or as a distinct error.
