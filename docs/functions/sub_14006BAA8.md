## Purpose

Reads a file through the engine's virtual file system: it resolves the path, opens the stream, copies the bytes into the caller's buffer and closes it.

## Behavior

- V: it is the generic read routine of the file layer, used by the save code, the pack code and several loaders (13 direct sites counted in the code).
- V: the path is resolved against the mount table first, so a file inside a mounted pack is served without touching the disk.
- V: the buffer and the expected length come from the caller; the routine reports how many bytes were read and whether the read succeeded.
- V: the legacy flat-image save loader reaches it for the numbered per-slot files, which is the only save path that uses it.
- I: because the save containers live outside any pack, the disk branch is the one the save code exercises.
- ?: the behaviour on a partial read (short file) was not traced.
