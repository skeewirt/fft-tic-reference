## Purpose

Resolves one row of a small UI table from the key held on a screen object and a mode index, and returns the row's dword at `+0x0C`.

## Behavior

- V: the key is the dword at screen `+0x1B0`; the second argument is passed as the row index.
- V: the lookup uses table id 0x2B (43) through the row-by-key helper; a null screen or a missing row returns -1.
- V: it returns the row's dword at `+0x0C`, which the callers use as a mode or count.
- V: four call sites, all in the item and equip menus; the equip sort confirm passes its sort mode as the index.
- I: the table is the menu's per-mode parameter row (sort order, page size), which is why a missing row is treated as "no mode".
- ?: the table's columns beyond `+0x0C`; they were not read.
