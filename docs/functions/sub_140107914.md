## Purpose

Plays the show / hide states of the battle command list cursor for one cursor event of the battle main window.

## Behavior

- V: for the ability list cursor event (kind 1, phase below 2) it plays a state chosen by the ability under the cursor: the Ability row (word +58780 & 0x7FF, only when the action word's kind bits are 0x7000) has shows_unknown_info (+0x3C) equal to 1 or 2 -> the state whose key is at w +58744, else the state at w +58760; the other one is stopped first.
- V: the same state is also chosen when the character render manager's flag byte (+13501) is set while the battle control's flag at +693392 is clear.
- I: the two states are 'ShowUnknown' and 'HideUnknown' (the research reading of the key strings); the test marks abilities whose details are not shown to the player yet.
