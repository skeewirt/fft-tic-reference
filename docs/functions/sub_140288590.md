Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Equips one item into a party slot: it validates the id, returns the old item to the inventory and writes the
masked id into the slot; for a one-handed weapon it may swap the two hand words.

## Behavior

- V: It masks the id with 0x3FF (the 0x3FF constant at 0x1402885B4, a 0x3FF mask at 0x1402885BD) and calls
  `sub_140288788` (0x1402885CB) to validate.
- V: On a valid result it adds the old slot word to the inventory with `Inventory_AddCount` (0x14028861B) and,
  for a hand slot, adds the other hand word too (0x140288647) before clearing it (0x14028864C).
- V: It writes the masked id to the slot (0x140288656); this is a plain id, never a flag.
- V: For a hand slot with a two-handed weapon (`sub_140284998` at 0x140288674 returns non-zero) it swaps the two
  hand words (0x140288699/0x14028869E), so the primary hand keeps the two-handed item.
- V: It calls `sub_140285A6C` to save every unit unless the unit index is 0x36 (the dummy).
- I: This is the "equip now" path of the equip screen; it never sets bit 15, so a word written here is a
  committed word.

## Notes

- V: The mask is applied before both the validate and the store; a flagged input word loses its flag here.
- V: The swap moves whole words; because the stored word is masked, no flag travels through it.
