## Purpose

The main unit panel: it lays out the unit's equipment rows, choosing each row's text id and icon from the equipped item.

## Behavior

- V: It walks five hand words, masks each to nine bits, treats 255 as empty, and skips anything at or above the 261 bound.
- V: For a shown item it builds a text id of 0x3800 plus the raw hand word, not the masked id.
- V: The icon call takes the same hand word through the icon setter.
- V: A second loop draws the ability/status rows using the 0x7000 and 0xB000 text blocks; those rows are not item ids.
- V: It calls fifteen helpers, including the icon setter and the scene refresh, and has no direct caller.
- I: The text id using the raw word while the lookup uses the masked id means the upper bits of the hand word would leak into the text id if they were ever set.
