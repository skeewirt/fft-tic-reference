## Purpose

Resolves the user's Documents folder through the shell and returns it as the base for the save path.

## Behavior

- V: it is called once, by the save folder builder, before the `My Games` segment is appended.
- V: it asks the shell for the known folder rather than reading an environment variable, so a redirected Documents folder is honoured.
- V: the returned string is used as a base only; the routine does not append the game folder itself.
- V: a failure returns an empty or null base and the folder builder then produces a relative path (the caller does not branch on failure).
- I: the shell call is what makes the save folder follow the user's profile, and why two Windows accounts see different saves.
- ?: the exact shell interface used and its failure value.
