## Purpose

Posts a battle message that depends on the current map, then marks the unit's action as done.

## Behavior

- V: it reads scene variable 39 and uses it as the index into the u16 map table at 0x140D3F950.
- V: an NXD table row is fetched (registry find, then row by id and entry row) before the message is emitted.
- V: the message text is built through BattleMsg_Dispatch.
- V: the function finishes by calling BTurn_MarkActionDone for the acting unit.
- I: the message concerns the current map because the only table read is the per-map word table; the message kind itself was not read.
- ?: which command produces it and what the map word selects.
