# sub_140333338

- **Address:** `0x140333338`
- **Area:** [Unit data](../areas/unit-data.md)
- **Prototype:** `int sub_140333338(unsigned char slot, unsigned int word, char learned_only_off, char refresh)`
- **Callers:** sub_1403333F0, sub_1403358FC
- **Callees:** sub_14028916C, JobScreen_RefreshAfterChange, sub_1403369F8

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Equips one ability list word into an ability slot of the selected party unit (the Status screen's ability lists and the combat sets): it checks the word's list flags, strips them, and hands the plain id to sub_14028916C.

## Behavior

- V: the unit is g_SelectedUnitIndex; the slot's current word is read from the party record at +0x5E + 2 * slot.
- V: a zero word is accepted only when the slot already holds something (an unequip); otherwise the function sets byte_140D407BE to 5 and returns 0.
- V: a word with bit 14 (0x4000) set is refused the same way; when the third argument is 0 the word must carry bit 12 (0x1000), else refused; a word with bit 11 (0x800) returns 0 at once.
- V: the word is masked with 0x3FF and passed to sub_14028916C(unit, slot, id, 0); on success it calls JobScreen_RefreshAfterChange when the fourth argument is set, then sub_1403369F8(word, previous word).
- V: sub_1403333F0 (a combat set) ORs bit 12 into the stored set word itself before calling it.

## Notes

- I: bit 12 marks a learned entry, bit 11 an entry already equipped or innate, bit 14 a greyed entry; the flags live in bits 10..15 of the list word, so ability ids above 1023 do not fit in the word.
