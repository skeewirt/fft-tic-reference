Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

A shop row helper: it returns the party's total holding of the item shown in a shop list row, with a flag bit for whether it can be equipped.

## Behavior

- V: It reads the 16-bit entry of the global shop list at the row index, masks it to ten bits as the item id, and asks the item total for that id.
- V: It then tests bit 14 of the entry and, when set, marks the result with a high bit before returning.
- V: The bit-14 flag is the list's cannot-equip marker, so the return value is a count plus a flag rather than a plain number.
- V: It calls two helpers and has no direct caller.
- I: Returning the flag inside the count means the caller must mask before using the number.
- V: the id is masked with 0x3FF at 0x140332C70; bit 14 is tested at 0x140332C78 and, when set, bit 30 is set in the result at 0x140332C7F. The return is count | 0x40000000 for a greyed row.
