## Purpose

Builds the help text of an ability row; for a movement ability it adds the '+N' number from the ability id.

## Behavior

- V: mode 0 is the ability help: the kind of the ability (Ability_GetAuxRecord) 1 goes to sub_14029F7C8; kind 8 (movement) goes to sub_14029F4B4 only for the ids 486, 487, 488 (text base 925, N = id - 485) and 489, 490, 491 (text base 926, N = id - 488); every other kind or id builds no text.
- V: so only the Move +1..+3 and Jump +1..+3 ids get a number; an added movement ability gets none.
- V: modes 1 and 2 fill a descriptor (sub_1400FA94C) and call sub_1400F94DC with it; I: another help text, not read; the function returns whether the output text is non-empty.
