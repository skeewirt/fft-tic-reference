## Purpose

Confirm handler for a battle command: it stores the chosen value in the command request and starts battle program 3.

## Behavior

- V: the 16-bit value the caller passes is written to both request words at +2 and +8, so the two stay equal.
- V: the request block is the twenty-byte command record is the message record 0x142FD35A0 plus 4; this body writes request words at +2 and +8, i.e. 0x142FD35A6 and 0x142FD35AC of the message record.
- V: battle program 3 is started for the acting slot with BattleAction_StartScript(3, slot, 0).
- V: the unit's menu id and the command-list state are read through Battle_MenuIdOfUnit and the list object.
- I: this is the plain confirm path of the command menu, taken when the chosen row needs no extra target.
- ?: which command ids reach this path rather than the unit-targeting sibling.
