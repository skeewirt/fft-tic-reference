## Purpose

The ending-save add-on: it shows its panel, records the cleared game through the options writer and offers the resume path.

## Behavior

- V: the object uses the UIAddonFFTOEndingSave vtable, so this is the add-on that runs at the ending.
- V: it calls Options_ApplyBlock, one of the three call sites of the settings writer.
- V: it binds and releases UI names and finds and plays the node named Show.
- V: it calls sub_140257354, the resume materialiser, and a restore helper.
- I: the options write is what sets isGameCleared, the bit that unlocks the post-ending state; the same writer serves the option screen and the launcher.
- ?: what the restore helper does here and which save the resume path reads.
