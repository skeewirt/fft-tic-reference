## Purpose

Event handler of an errand screen: on event 0x10001 shows the two treasure-progress gauges (milestone counts).

## Behavior

- V: switch on the event a3: 0 plays sound 0x68 and starts a fade; 1 clears a flag; 2 calls sub_1401E3FF4(qword_143CD9E48, 1); 0x10001 builds the page.
- V: for 0x10001 it counts owned treasures with EventVar_Read: variables 848..863 (16) and 801..831 (31).
- V: for each count it counts how many of the 8 milestone bytes are <= the owned count: byte_1406807B8 for the 848.. variables (loop `< 8`, 0x14016E6E5) and byte_1406806B8 (g_ErrandTreasureMilestones) for the 801.. variables (0x14016E72F).
- V: passes (count, count == 8) to sub_14016EB08 for page 0 and page 1.
