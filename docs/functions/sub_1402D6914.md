## Purpose

The Outfitter/shop message handler. It covers the cancel message, the leave message, the shop-order message,
the "equip this pick" message and the "apply the candidate list" message.

## Behavior

- V: The switch is on the message dword. Message 6 calls `sub_1402D5B6C` (the cancel restore); message 0xC
  handles the overflow check; message 0x25 sets `g_ShopOrderGroup` and calls `sub_1402D7640`.
- V: Message 0x45 reads the selected slot word (0x1402D6C30), clears bit 15 with a bit-15 clear (0x1402D6C35),
  and calls `sub_1402D7280` with the cleared word (0x1402D6C47). This is the re-buy/confirm path.
- V: Message 0x46 copies the unit's five words to a stack record with `sub_1402D7584` (0x1402D69A3), sets the
  fifth candidate from unit +0x5C (0x1402D69F9), builds the candidates with `sub_140287D9C` (0x1402D6A18) and
  recomputes the two-handed word (0x1402D6A34).
- V: In the same message it walks four candidates loaded signed (a signed load at 0x1402D6A55). A zero candidate or
  one with bit 15 set (a bit-15 test (the 0xFFFF8000 constant) at 0x1402D6A74) is removed from the slot with `sub_1402D6464`
  and its price added to `dword_143D1AC68`; a plain candidate either clears a matching override or subtracts
  the old pending price.
- V: It stores the candidate word at unit +0x54..+0x5A (0x1402D6AC0), so bit 15 is written when the candidate
  carries it, then calls `PartyUnit_ReloadEquipment` and the stat/candidate refreshers.
- V: It tests only bit 15 in the candidate and unit comparisons, not bit 14.
- I: Message 0x45 is "buy/confirm the pick" and 0x46 is "apply the list and leave"; both are part of the same
  session that only the commit/cancel messages end.
