## Purpose

Appends one 16-byte element to a segmented container whose control block sits at a fixed global plus 0xF8. When the current segment is full it allocates the next 0x3800-byte block and links it into the block list.

## Behavior

- V: the control block is reachable from a global pointer plus 0xF8; the element begin and end pointers are at +8 and +0x10 and a block count is at +0x24.
- V: the capacity used for the full test compares a dword at +0x24 with the current element count shifted left by 6; the two are not a plain element count, so the unit of that comparison is unclear.
- V: when the container is full, the function asks the game allocator at 0x140011750 for a 0x3800-byte block, using the heap pointer held by a global object when that object exists and a null heap otherwise.
- V: the new block pointer is stored in the block list and the element is appended; the element's second qword is cleared.
- V: an allocation failure returns 0 without appending.
- I: the element is 16 bytes because the append advances the end pointer by 16 and writes a qword pair, and 0x3800 bytes is the segment size.
- ?: what the +0x24 comparison counts and what the element type is.
