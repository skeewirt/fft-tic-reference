## Purpose

Shows or hides one icon image slot and sets its icon by id: plays the node's Show / Hide state and, when the icon is shown, calls GuiImage_SetIconById.

## Behavior

- V (arguments): slot (a2): qword +0 = the slot's GUI node (nothing happens when it is 0), +8 = embedded GuiImage object, +32 = pointer to a second slot-like record, +136 = dword (previous icon id), +144 = byte 'shown'. iconRec (a3): dword +0 = icon id, byte +4 = 'hide' flag. a4 = skipStates.
- V: new shown = (iconRec.id > 0 and iconRec[4] == 0); the old byte is kept in v6 and slot+144 = new shown.
- V (when skipStates == 0): stops the OPPOSITE state (shown -> 'Hide', else 'Show' via UIName_Key + GUINode_StopState, key released with sub_1403D8D1C) and then plays the wanted one with sub_140409824(node, key, -1), i.e. at its last frame (instant, see sub_140409824 note in sub_1402A91E4).
- V (when shown): GuiImage_SetIconById(slot+8, iconRec.id, 0, 1). If the slot was hidden before and is shown now and slot+32 is non-null, byte (slot+32)+144 = (slot+136 == iconRec.id) - i.e. the paired record is marked 'same icon as before' only on a hidden -> shown edge.
- V: the return value is the last call's result and is meaningless to callers.
