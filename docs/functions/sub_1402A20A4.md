## Purpose

Sets the description text of the job command detail window: the second description once its condition holds.

## Behavior

- V: gets the JobCommand row; its user_situation column (+0x1C) is a UserSituation key. When it is non-zero, the description_2 string (+0x10) is non-empty and UserSituation_IsMet says the condition holds, the text shows description_2; in every other case it shows description (+0x0C).
- V: then sets the text id of the second text node to 900 and plays the 'ShowDetail02' / 'HideDetail02' states.
