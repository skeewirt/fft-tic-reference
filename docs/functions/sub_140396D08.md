## Purpose

Validates an equip preview against the unit's current equipment: it compares the candidate item with the item already in the slot and with the job's equip rules.

## Behavior

- V: It reads the unit's hand word for the slot, masks it to ten bits and compares it with the candidate.
- V: A candidate identical to the current item is accepted without further checks.
- V: Otherwise it asks the preview equip check whether the job may equip the candidate, and the category check whether the candidate is a valid item.
- V: It also tests a per-slot byte at +0x177 of the unit state, which marks a slot that is locked or already changed.
- V: It calls six helpers and has three direct callers.
- I: The locked-slot byte is what prevents two preview changes from being applied to the same slot in one pass.
