## Purpose

Draws the item icon for a shop list row.

## Behavior

- V: It reads the shop list entry, sign-extends it from 16 bits and masks it to ten bits.
- V: The masked id is passed to the item icon wrapper, which resolves the record and sets the icon tile and palette.
- V: The resulting tile and palette bytes are copied into the row's icon globals.
- V: It calls two helpers and has no direct caller.
- I: The sign-extension is harmless because the ten-bit mask follows it, but it shows the entry is read as a signed word first.
- V: the id is masked at 0x140332D5F before the help lookup; the flag bits are discarded.
