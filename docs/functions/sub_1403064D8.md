## Purpose

The shared stat-sap effect: picks which stat byte the formula writes by the ability being resolved.

## Behavior

- V: switches on the ability word at 0x1407B0778 (the +8 word of the formula block).
- V: ids 143 and 197 write the result byte +20 of the action block, 144 and 198 write +22, 145 and 199 write +23: the value is the byte at 0x1407B079D (the copied action row's byte +9) & 0x7F; the block's flag byte +39 gets bit 0x01.
- V: any other id does nothing (it changes no stat).
