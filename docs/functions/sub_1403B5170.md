## Purpose

One GUILayer effect pass (the +320 group in GUILayer_ApplyEffects' order): fills a draw command for a full-rect quad with the layer's source texture, picks a shader permutation by whether any of three 2-vectors is non-zero, and submits the command.

## Behavior

- V: sets cmd+96 = render target slot (qword_143CDA098 + 8 * (slot + 64 * byte target+86) + 24224), cmd+144 = its +40; bits 9..11 of cmd+124 = the target's format-kind field (+16 when the target's +8 is 1 or 2).
- V: shader digit 0 = 1 when any of the three float pairs at fx+120/124, +128/132, +136/140 has squared length > 1.1920929e-7; ShaderSelector_SetDigit(sel, 0, that) then ShaderSelector_Apply(sel, cmd, 4, ...).
- V: after Apply, cmd texture slots a2[100 + int16 (fx+64) + 1] = the target slot's +40 of the pass-'pass' source (qword_143CDA098 + 40 * pass + 20832, +40) and a2[100 + int16 (fx+66) + 1] = the qword at fx+328's +40 when set, else the same source. cmd+136 = the layer's own qword (record v9[1060]), cmd+200 = (qword v9[1063]) +40 or 0, dword cmd+212 = (fx+8) << 6, dword cmd+208 = 16, bits 12..21 of cmd+124 = 0x6000 (fixed), qword cmd+6016 = 0, cmd+80..95 = *rect (a3).
- V: submits with sub_140069A38(cmd, 4, 96) and, when it returns a block, sets +12 = 0, +8 = 4, RenderState_PackCommand and sub_140069980.
