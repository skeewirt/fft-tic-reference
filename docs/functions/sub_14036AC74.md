Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Takes the shop row at the current selection index and makes it the active item of the shop's detail and confirmation panels.

## Behavior

- V: the function reads the selected row index from the 16-bit global at 0x141876B54 and uses it to pick the id out of the shared list buffer at 0x141811470.
- V: the picked id is stored in the 16-bit UI field at 0x143C518F0 and the order-group byte at 0x140D407BA is cleared, so the list order follows the row the player chose.
- V: a one-shot byte at 0x14184A643 guards the first-time setup, and two screen flags at 0x143CDA950 and 0x143CDA951 are toggled around it.
- V: the function then runs a long series of panel refreshes, including sub_1402BE694, sub_1401987F0, sub_1402C1244, JobScreen_RefreshAfterChange, sub_1401D1EAC, sub_1402C33D0 and sub_140284998.
- V: sub_140284F6C and sub_1402C4880 run on the paths where the selected row is a valid item.
- V: it has one direct caller, sub_14036C850, and does not build the list itself.
- I: the function is the row-selection handler of the shop list, because it converts a row index into an item id and then refreshes exactly the panels that show the chosen item.
- I: the JobScreen_RefreshAfterChange call is a generic "equipment changed" refresh reused by this screen, not evidence that this is the job screen.
- ?: what sub_1401D1EAC and sub_1402C33D0 show for the selected item.
- V: the chosen item is copied as the whole 16-bit word at 0x14036ACDD and stored at 0x14036ACE1; there is no mask, so a flagged entry reaches the confirm path with its flags.
