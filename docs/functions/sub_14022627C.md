## Purpose

Counts the decimal digits of a value, for laying out a printed number.

## Behavior

- V: the function is a 66-byte leaf that calls nothing and touches no global.
- V: it returns a small count, the number of decimal digits the value prints as.
- V: the text formatter uses it to reserve the width of a numeric argument before printing.
- I: zero still counts as one digit, since a printed zero occupies one character.
- ?: what it returns for negative values; no sign handling was read.
