## Purpose

Returns a code for the highest-priority status present in two 5-byte status sets of a unit state.

## Behavior

- V: loops over the 40 statuses (the address 0x140788FE5, entry 0 byte 5, is loaded at 0x14027915E; step 16); bit k of the sets at +34 and +29 selects status k.
- V: keeps the status whose entry byte 2 is the largest; the result is 129 + k (set at +34) or 1 + k (set at +29), plus 128 when entry byte 5 has bit 3 set.
- I: the code selects a status icon or message.

## Notes

Its table operand is the status properties table.
