# sub_140316C90

- **Address:** `0x140316C90`
- **Area:** [Unit data](../areas/unit-data.md)
- **Prototype:** `void *sub_140316C90(void *unit, unsigned short id)`
- **Callers:** `sub_140316B04`
- **Callees:** `Item_GetWeaponRecord`

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

A thin weapon-record lookup for a unit: it filters the empty and out-of-range ids and returns the weapon sub-record.

## Behavior

- V: An id of 255 returns no record.
- V: An id at or above 261 returns no record.
- V: Otherwise it calls the weapon record accessor and returns its result.
- V: It calls one helper and has one direct caller.
- I: The two filters are what make it safe to call with a raw equipment word.
