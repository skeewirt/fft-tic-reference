## Purpose

Handles a break or destroy effect on a piece of equipment: it finds the item, checks whether it can break, and removes it from the slot.

## Behavior

- V: It reads an equipment word and accepts it only when it is below 261.
- V: The item record's breakable flag decides whether the effect applies; an unbreakable item is left alone.
- V: A broken item is removed from the slot and returned through the inventory-return path.
- V: It calls three helpers and has one direct caller.
- I: The bound is the stock 261 rather than the packed hand word's ten bits, so this path reads a plain id.
