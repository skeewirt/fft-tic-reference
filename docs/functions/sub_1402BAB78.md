## Purpose

Applies the pending music request: starts the requested track, stops the current one, and runs the pending fade.

## Behavior

- V: the request state is 16 bytes at 0x140D3A900 (sound id, then the three dwords of the music slot record); a request of -999 stops the channel; -998 and -997 clear the state; -1 means none.
- V: for another id it calls EventMusic_LoadTrack(sound object, channel 8, id - 1), copies the id and the three record dwords to the current-track block at 0x140D3A8E0 and clears the request.
- V: when the current track id is 99 and the channel is no longer busy the channel is stopped (the compare at 0x1402BAB8C).
- V: nothing reads the three record dwords after this copy (census of 0x140D3A8E0..0x140D3A91F, 39 operands).
