## Purpose

Input handler of the job-list panel for mode 2 (the main cell grid): confirm / cancel / detail buttons and cursor movement across the 19 cells.

## Behavior

- V (confirm, action 26 or p+8528 / p+8824 click flag set): if sub-mode p+19012 == 4 posts command 18 to the addon owner (sub_140152494(owner+152)); else when cell = p+19016 <= 0x12 calls sub_14012FC6C(p, cellState != 0 ? 6 : 3, 0) where cellState = dword [p + 148 * cell + 8964], and plays sound 14.
- V (cancel, action 27): out[0] = 1100, sound 15, p+19033 = 1.
- V (other buttons): sub_140131734 (action 0x8E: detail / refuse), sub_140131688 (action 0x7E), sub_140132D48 (palette gate) can consume the event and return; action 143 (0x8F) suppresses movement.
- V (movement): cur = p+19016; column table at p+72 (3 ints, upper bounds, 19 as the last): group g = first index with cur < bound; v17 = sub_1400F6D58(cur, groupLow, groupHigh - 1, keys, repeat) moves inside the group; if unchanged sub_1400F6DD4(g, 0, 2, ...) switches group: new cell = clamp(cur +/- width of a group) into the new group's range (width at p+76, sign by direction). A forced cell p+8520 >= 0 (pointer hover) overrides the result when it differs from the current cell.
- V (commit): when the cell changed: p+19016 = cell, JobList_OnCursorChanged(p, cell, 0), out[1] = cell, out[2] = 1, sub_140132D6C(p) (refresh every cell's palette / state).
- V: out[0] = 1409 / 1410 / 1100 are the event ids returned to the addon (1409 appears when the cursor is not moved; 1410 is set when the detail action returns).
