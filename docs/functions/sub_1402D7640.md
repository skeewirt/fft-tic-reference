## Purpose

Rebuilds the shop's displayed item list into the shared menu list and then syncs the candidate array from the
selected unit's scratch record.

## Behavior

- V: It reads the shop cursor/order byte and the shop order group, calls `Shop_BuildItemList` with the selected
  unit and shop and writes the list into `g_MenuList` (0x141811470), then binds the rows with
  `ShopList_BuildEntries`.
- V: It calls `sub_140289894` to copy the selected unit into the scratch record (0x141801100), then
  `sub_1402D746C` to copy the four + one hand words from the scratch record into `g_EquipCandidates`.
- V: The list builder is called with mode `(v6)+1`; the mode controls whether an unequippable item is marked
  with bit 14. The call sites in this function use the value from `sub_140336788`, so a marked list is possible
  here.
- I: This is the shop's list refresh; it is the bridge between the shop list (bit 14 marks) and the equip
  candidates (bit 15 marks).
- V: the list is built with Shop_BuildItemList at 0x1402D76D0 using mode (v6 + 1), so mode 1 can set bit 14 on a refused item and mode 2 drops it; the list is then ordered in place at 0x1402D76E1.
