## Purpose

The formula handler for the revive consumable: it decides whether the target can be revived, then sets the amount
of HP restored from the item's chemist row and a random roll.

## Behavior

- V: it calls sub_140309504 first and returns without writing anything when that call returns 0.
- V: when the block loaded from `0x14186AF68` has bit `0x10` of its byte at +0x61 set, it copies a 16-bit value from
  that block's +0x30 straight into the result block at +6 and skips the item-data path.
- V: otherwise it rebuilds the item id from the byte at `0x1407B077E`, the item id's low byte plus `0x10`, by adding

- V: it ends by calling sub_140306378.

- I: the fifteen-bit scale means the helper returns a fraction of `0x8000` (the implied full scale; the body only masks the sign with `0x7FFF`), so the stored amount is a percentage of
  the item's amount plus one.
- I: this is the revive formula because its only stock user, Phoenix Down, is the one item with the revive amount
  pair in the chemist table.
