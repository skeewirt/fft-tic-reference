# sub_140238444

- **Address:** `0x140238444`
- **Area:** [Battle](../areas/battle.md)
- **Prototype:** `? sub_140238444(int slot)`
- **Callers:** Battle message and action paths
- **Callees:** BattleMsg_Dispatch, Ability_GetAuxRecord, SceneVar_Read, sub_1400F8930

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Posts the action-name banner for a unit, with a job-pair special case.

## Behavior

- V: it calls BattleMsg_Dispatch once with kind 7, the action-name message.
- V: an ability id is masked with 0x1FF at 0x14023846C before the aux record is read (a third UI mask).
- V: the aux record of the ability supplies the name that the banner shows.
- V: the function contains the Mime/Calculator job gate, its one job-id comparison cluster.
- V: it reads a scene variable and the live unit table before the message.
- V: it tests bit 0x40 of AbilityAux flags3 (aux +3): when the bit is clear, or the display flag dword_140782A24 has 0x60000 set, the kind-7 message is sent with its fifth argument 0 (except for a few action ids); when it is set, the argument passed in is used.
- I: bit 0x40 of flags3 selects a variant of the banner; what the fifth argument changes is not decoded.
- I: a first path sends a kind-5 message (storing the ability in g_BattleLineAbility) after a chain of tests on the action id (below 368), a byte of the action record and several unit status bytes; the tests are read, their meaning is not decoded.
- I: the banner says what the unit is doing; the job gate selects a different wording for the two special jobs.
- ?: the message id and what the job gate changes.
