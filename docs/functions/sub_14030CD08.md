## Purpose

Finds a unit that learns the current ability from the action, rolling the learn chance; returns the unit index or -1.

## Behavior

- V: returns -1 when dword_14186AFF8 != 0, no current ability (word_14186AF5C == 0), or the ability's aux flags3 & 0x20 is clear (`*((_BYTE*)&g_AbilityAuxTable + 8*id + 3) & 0x20`, 0x14030CD40).
- V: scans units (512-byte records) other than a1 whose state byte has bit 2 set, sets that byte to 4 and requires sub_140278FA8(unit, 4) == 0.
- V: for that unit's job walks 24 skillset slots; when Skillset_GetAbility equals the ability and the slot's bit is clear it rolls `Rng_Percent(100, *((_BYTE*)&g_AbilityAuxTable + 8*id + 2))` (learn_percent, 0x14030CE28); a zero return stores the ability in *a2 and returns the unit index.
