## Purpose

Event task that opens a UI panel: it drops the pending input bit, reads the panel selector and starts the panel task with a fixed text id.

## Behavior

- V: It clears bit 0x10 of the flag dword at 0x141D32E14 before doing anything else.
- V: When bit 9 of the dword at 0x1437FC2C0 is set it clears that bit and calls sub_1402E9918 with 0x23.
- V: It selects a 0x5C-byte record from the array at 0x140D8D8C0 by the count at 0x140D8DBA0 (minus one) and calls sub_1402D0538 on it.
- V: It calls sub_14034004C with 0x221, then tail-jumps to sub_1402D4A3C.
- V: One caller, sub_14033EEDC.
