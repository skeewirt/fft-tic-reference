# sub_140287398

- **Address:** `0x140287398`
- **Area:** [Unit data](../areas/unit-data.md)
- **Prototype:** `__int64 __fastcall sub_140287398(__int64 block, _WORD *words)`
- **Callers:** `PartyUnit_ReloadEquipment`, `sub_14028531C`, `sub_1402855F0`
- **Callees:** `sub_140286C8C`

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Sums the stat contributions of five equipment words into the 0x141876E90 block (or a caller block) using only
their masked ids.

## Behavior

- V: It loops five times, reads each word, masks it with 0x3FF (a 0x3FF mask at 0x1402873F6), and calls
  `sub_140286C8C` for the item's stat row.
- V: It accumulates the returned stat words into block +0x06, +0x08, +0x0A, +0x0C, +0x16, +0x18, +0x20 and
  +0x22 (0x140287408..0x14028747D). It does not touch block +0x24 (the hand words).
- V: The block is cleared at +0x06, +0x16 and +0x20 before the loop (0x1402873B4..0x1402873C0).
- I: This is the stat half of the panel refresh; the hand half is the raw copy done by the caller.
