## Purpose

Returns the 2-byte accessory sub-record (copied into the unit's evade group), or null when the item is not of this kind.

## Behavior

- V: calls Item_CategoryFirstId(id) and computes index = id - that first id (16-bit); then calls Item_FindCategoryIndex(id) again; -1 returns 0.
- V: kind = g_ItemCategoryType[category]; kinds 3 and 8 select the tables 0x14080FB30 (ids 0xD0..0xEF) and 0x140673674 (id 0x104); element size 2, index = id - first id of the kind; any other kind returns null.
- V: relies on the callees leaving r9 and r10 untouched (it keeps the id in r9 and the index in r10 across both calls); the stock callees only touch rax, rcx, rdx and r8.
