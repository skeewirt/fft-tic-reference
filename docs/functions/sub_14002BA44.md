# sub_14002BA44

- **Address:** `0x14002BA44`
- **Area:** [Save data](../areas/save-data.md)
- **Prototype:** `?`
- **Callers:** the application initialiser (2 references in that routine)
- **Callees:** the folder and pack helpers, the save-file name builder

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Builds and probes the console save thumbnail path, `system/savedata/ICON0.PNG`, and mounts or opens the save folder that would hold it.

## Behavior

- V: the literal path it builds is the console thumbnail location (`system/savedata/ICON0.PNG`), not a PC save file.
- V: it is reached twice from the application initialiser and from nowhere else in the executable.
- V: on this build nothing ever writes that path and neither of the owner's save sets contains it, so the whole routine is inert on PC.
- I: it is a leftover of the console save UI: the thumbnail is what a console front end shows for a save, and the PC build keeps the code but not the feature.
- ?: what the routine does when the path exists (mount, open for read, or only remember it) was not traced, because there is no file to observe.

## Notes
