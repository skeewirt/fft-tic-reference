Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Returns a small action-mode code for a unit from its command flags and its current ability, special-casing ability 367 and job 93.

## Behavior

- V: the unit command byte at +0x1A1 is looked up in the command table at 0x14067E010 and the result is kept in a register.
- V: it clears a global byte, calls sub_14030DD1C on the unit and inspects unit +0x63 bit 2 and unit +0x65 bit 4.
- V: bit 2 of +0x63 with an ability of 0, 0x16F or 0x1D gives one path; otherwise the ability record is fetched.
- V: an ability id of 0x16F (367) is compared directly; this equality is separate from the 368 boundary compare.
- V: a job byte of 0x5D (93) changes the result through the job check that follows.
- V: the returned codes are small values 1, 5, 6, 7 and 8, plus a negative value for an invalid unit.
- V: when the state word at 0x14186AF9C is zero it calls sub_140279370 with 0xFF before the main switch.
- I: the codes select an action prompt or cursor mode, because the callers are the preview and commit paths.
- ?: the meaning of each code; only the values are read, not the consumer switch.
- V (2026-11-10): the unit is the argument; the command byte is +0x1A1 and the ability word the signed word at +0x1A2; the answer is, in order: a unit with mask 0x04 at +0x65 or a non-zero sub_14030DD1C answer returns that answer + 6 (7 for the +0x65 case); a Toad unit (+0x63 mask 0x02) returns 5 unless the ability is 0, 367 or 29 (a command kind of 10 returns 5 whatever the ability); an ability above 0x16F skips everything below and returns 0.
- V: for an ability up to 0x16F with command kind 0 or 6: the action row's flag byte +5 mask 0x20 together with the unit's +0x62 mask 0x08 returns 2.
- V: for command kind 0 only, and a unit whose job byte is not 93: the MP cost is action-row byte +13, halved when unit +0x99 has bit 7; it is stored in the byte at 0x1407B078E; a unit MP (+0x34) below the cost returns 3; otherwise the cost is subtracted unless the simulate mode (g_BattleSimulating) is 2; then it returns 0.
- V: so an ability id above 0x16F is never checked and never pays MP; see AbilityAboveStockBoundaryHasNoMpCheckOrCost. The preview twin is sub_14030B1A0 (it stores the cost without paying). The 367 equality is at 0x140282960.
- V: the id bound is a 16-bit compare of the ability id with ax = 0x16F, then a jump past the MP block when above (ax also serves the Toad test's 367 just before).
