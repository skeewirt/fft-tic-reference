## Purpose

The Outfitter entry handler: it prepares and calls the menu function at 0x1402BE7E8, then runs the per-frame
dispatcher.

## Behavior

- V: It sets up a small stack message (two dword -1, a byte 0, the input word and the menu word) and calls
  `sub_1402BE7E8` with it (0x1402D5809).
- V: It tail-calls `sub_1402D6F10` (0x1402D5812), which dispatches on the current menu id.
- I: The first call arms the screen; the second runs the frame. No equipment word is read or written here.
