- **Area:** [Battle](../areas/battle.md)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

For a party unit given by its save index, builds the unit's battle command byte list on a scratch unit and answers the first command whose list holds a usable entry (the twin of sub_14030E010, which builds the live menu list).

## Behavior

- V: takes the highest free slot (byte +1 == 0xFF) of g_PreviewUnitTable (slots 20 down to 0), fills it with UnitWork_BuildFromSaveIndex and UnitInfo_FillFromBattleUnit, and frees it again (+1 and +437 back to 0xFF) before it returns.
- V: looks the unit up with sub_14030DB88(slot); the list is a stack byte array: 1 first, then the primary set (unit +0x12) unless it is 0 or 0x18, then the secondary set (+0x13) unless 0, then 0xFF. A unit whose primary or secondary set is in 0xB0..0xDF (a monster set; tested as byte + 0x50 <= 0x2F) lists the primary set alone and counts as usable.
- V: for each listed command byte whose kind (g_CommandKind[command] & 0xF) is 0, 1, 2, 3, 4, 7 or 10 it asks sub_14030DD8C(slot, command, ...) whether the command has a usable ability (the byte is taken as an 8-bit argument); any other kind counts as usable unless the kind is 15. The first usable command byte is stored through outCommand and the function returns 0; it returns 1 when there is none or no slot is free.
- V: the command bytes are stored in a stack list (0x1402177A3, 0x1402177AE, terminator 0xFF at 0x1402177B3).
