Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Builds the usable list for a battle command: it checks the command kind and writes one text cell per entry for the menu.

## Behavior

- V: It resolves the unit with sub_14030DB88 and gives up when that fails.
- V: It looks the selector up in g_CommandKind (0x14067E010) and compares the kind with 6; for any other kind it writes 0xFFFF (the all-ones word, produced by ORing eax with -1) into the first cell and returns.
- V: For kind 6 with unit flag +0x63 bit 2 set it writes the synthetic text id 0x16F and calls sub_1402BB060.
- V: The cells it writes hold the item table id (or 0xFFFF, the same all-ones word) and ids that come from sub_140275860.
- V: Two callers, the two battle menu builders sub_14023678C and sub_1402EA58C.
