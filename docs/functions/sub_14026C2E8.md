# sub_14026C2E8

- **Address:** `0x14026C2E8`
- **Area:** [Unit rendering](../areas/unit-rendering.md)
- **Prototype:** `? sub_14026C2E8(int slot)`
- **Callers:** The unit sprite renderer
- **Callees:** sub_14025FA60, sub_14025FE14, sub_1400CB5B4

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Loads or refreshes the high-definition sprite entry for one render slot.

## Behavior

- V: it reads the high-definition sprite entry by shape, one of the four readers the live census hit.
- V: it compares a record byte with 0xAA, the marker T1 records for this function.
- V: it calls the sprite and texture helpers and reads the renderer's slot state.
- V: the 0xAA value marks an entry that has no HD sprite, so the slot falls back to the base sheet.
- I: a slot load that runs when a unit's job or equipment changes its sprite.
- ?: which slot it fills and when the load is retriggered.

## Notes

Evidence: T1 (the 0xAA marker), the live reader census (hd_entry_by_shape) and the body scan. 509 bytes.
