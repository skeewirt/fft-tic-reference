## Purpose

Looks up the sprite shape's LUT parameter record for a scene unit and stores it, with two CharShape bytes, in the scene object's block +960..+979.

## Behavior

- V: builds a small request (byte 0 = scene object dword +348 bit 2, byte 1 = whether the object's byte +300 low two bits equal 1, byte 2 = a value derived from the tile data at the object's position, read through sub_140249000) and calls CharaRender_LookupLutParams with the shape key (the object's word +28, from its byte +10).
- V: stores the result's float at +960, dwords at +968 / +972 and words at +976 / +978 (the LUT parameter record), the byte the lookup returns at +3 of its output into object byte +964 (the CharShape depth_sort_height_offset column) and the byte it returns at +20 into object byte +966 (the CharShape unknown_2e column).
- V: only recomputes when the shape key, the flag dword or the layer value changed from the cached ones at +28 / +32 / +30; a shape key beyond the CharShape row count falls back to row 0.
- V: when the renderer has no LUT block (the global renderer's field at +148128 is 0) the record keeps its defaults and both bytes are 0.
