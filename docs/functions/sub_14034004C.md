## Purpose

Pushes a 'play this music' command onto the audio command queue.

## Behavior

- V: when bit 0 of the dword at 0x140D4955C is set it first pushes a command of kind 2 (parameter 16); then pushes kind 1 with the argument as parameter, then kind 3 (parameter 16).
- V: the argument is `sound id | slot << 8`; the stock callers pass the constants 0x11B, 0x220, 0x221 and 0x223, and sub_1402F109C passes the whole 16-bit command-state word.
