## Purpose

Seeds a unit's candidate action slots for its current command before the action row is written.

## Behavior

- V: It reads the unit's command byte at +0x12 (absolute 0x141853CF2 + index*512, record base 0x141853CE0) and branches on the item/throw command range 0xB0..0xDF (the upper bound is tested by comparing al with 0xE0 and branching below, not as a 0xDF immediate).
- V: It marks the candidate record (0x88 bytes per slot) with 1 and stamps the unit index into the high bits of a word.
- V: It sets the slot flags (bit 1 of +2, bit 0 of +3) and writes 0x80 into byte +1.
- V: It calls sub_140316C90 and sub_140316D24, the latter adding up to 16 skillset slots per command.
- V: One caller: sub_1403167E4.
- V (read 2026-11-12): the row of the AI command table (g_AiCommandTable, 16 rows x 34 entries x 4 bytes) is byte_141873038[unit slot]; the function writes entry 0 (command byte 1, word = slot << 10) for a unit whose primary set is outside 0xB0..0xDF (compared against 0xB0 and 0xE0), fills the row header at byte_141872E20 (8 bytes: byte +2 |= 2, byte +3 |= 1, byte +1 = 0x80, the rest cleared) and, when unit byte +0x06 bit 0x20 is clear, calls sub_140316C90 for the unit's two hand words (+0x20 and +0x24) and sets header bits from the result.
- V: it then calls sub_140316D24 for the primary set (+0x12) and, when the primary byte (+0x12) is outside the monster range (the 8-bit test add 0x50, cmp 0x2F at 0x140316C16), for the secondary set, and ends the row with an entry of word (slot << 10) + 367 and bytes +2 / +3 = 0xA9 / 0x84 (one word store of 0x84A9) and, when fewer than 34 entries are used, the terminator 0xFF in byte +2 of the next entry. It returns the entry count + 1.
- V: the two set bytes are loaded at 0x140316BF1 and 0x140316C1E (displacement 0x1853CF2 / 3 from the table base 0x141853CE0 = unit +0x12 / +0x13, so the offsets are not separate operands; the hand words +0x20 / +0x24 are addressed the same way).
