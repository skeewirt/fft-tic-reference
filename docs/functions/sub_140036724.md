Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

The legacy per-slot probe: scans numbered container names `0001.png` through `0050.png` in one save root and reports whether any of them exists.

## Behavior

- V: the loop runs a counter from 1 to 0x32 (50) and formats each name with the `%s%04d.png` template before testing it.
- V: it returns as soon as one name exists, so the answer is "any", not "which".
- V: it is reached from the boot "has any save" probe and from the manager's vtable slot 20; no writer for those numbered files exists in this build.
- V: neither of the owner's save sets contains a numbered PNG, so on a normal install the scan always answers false.
- I: the numbered set is the legacy per-slot layout of an earlier build or platform; the modern build keeps the probe for the first-run decision only.
- ?: what slot 20 does with the answer beyond the boot flags was not traced.
