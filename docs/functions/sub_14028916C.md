## Purpose

Writes one word into a party unit's ability slots (primary skillset, secondary skillset, reaction, support, movement) and re-derives the unit's state, used by the Status screen's ability lists and the combat sets when the player changes one slot. (Corrected 2026-11-10: this sheet first called these words equipment slots; the equipment words are at +0x54.)

## Behavior

- V: the unit index selects the record in g_PartyUnits and the slot selects one of the five 16-bit ability words at record offsets 0x5E onward (slot 1 = secondary +0x60, 2 = reaction +0x62, 3 = support +0x64, 4 = movement +0x66).
- V (live 2026-11-10): the word is stored exactly as the caller passes it; the callers strip the ability list's flag bits (0x800, 0x1000, 0x4000) first (sub_140333338's `& 0x3FF`).
- V: when the record's byte at offset 0x177 is not 0xFF and the slot word differs from the id being stored, the byte is reset to 0xFF, which invalidates the cached value the byte holds.
- V: the new word is stored in the slot unconditionally (no range or validity test).
- V: the function then calls sub_140285A6C and sub_140288A24 to rebuild the unit's derived state.
- V: depending on its fourth argument (set by the callers for supports that affect what the hands may hold, sub_14036771C), it calls sub_1402875A4 to pick a five-piece equipment set, moves each chosen id from the inventory into the unit with an inventory -1, and returns the previous item through Inventory_AddCount.
- V: sub_140289320 and sub_14031EEA8 run on the paths where the set is rebuilt, and the function returns an integer status.
- I: this is the single-slot counterpart of the job-change re-equip, because it writes one slot first and then asks the same picker to fill the rest.
- ?: the meaning of the status value and of the flag that selects the rebuild path.
