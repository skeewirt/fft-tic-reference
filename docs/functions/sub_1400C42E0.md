## Purpose

Requests one named resume entry from the autosave container: it formats the name for a part and a point and queues the request on the group object.

## Behavior

- V: the name comes from the shared name builder, so read and write agree on every spelling.
- V: the request is queued through the generic entry request routine on the group object passed in.
- V: six sites, all inside the read fan-out.
- V: it does not kick the read; the fan-out does that once after all six requests.
- I: queueing all requests before one kick is what lets the container be opened once for a whole point.
- ?: whether a missing entry leaves the group's previous buffer in place.
