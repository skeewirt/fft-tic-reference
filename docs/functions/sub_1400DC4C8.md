Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

One of the battle targeting predicates: it decides whether a unit (or its target list) qualifies, and in this variant it accepts only a Mime and then walks the unit's stored target list through the caller's callback.

## Behavior

- V: it rejects a null object or a null predicate, and requires the source object's kind accessor to answer 9 (a battle-unit record).
- V: the unit index at object `+8` must be 21 or below, which is the bound of the preview-unit table (512 bytes per entry).
- V: a flag bit 0x08 in the record's word at `+0x1EE` must be set; when the mode byte on the stack is zero the record's job byte at `+3` must also be 0x5D (Mime).
- V: the caller's predicate is then run on the record, and if it passes the list at object `+0x0C` (count) and `+0x10` (indices) is walked, calling the second callback for each entry until the requested count is reached.
- I: the Mime test is the reason this variant exists: the action it guards can only be aimed at, or performed by, a unit in that job.
- ?: what the flag bit at `+0x1EE` means, and which action uses this exact variant (18 callers share the shape).
