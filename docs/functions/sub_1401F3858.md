# sub_1401F3858

- **Address:** `0x1401F3858`
- **Area:** [UI framework](../areas/ui-framework.md)
- **Prototype:** `? sub_1401F3858(int unit, int mode)`
- **Callers:** Party / unit panel refresh paths (not enumerated)
- **Callees:** sub_14022AA88 (sprite shape), SceneVar_Read, unit-renderer and UI node helpers

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Refreshes a party/unit panel: it looks up the unit's sprite shape and shows or hides the lock and starting-team icons.

## Behavior

- V: the body reads the scene-shape sprite table, one of eleven readers the live census hit.
- V: it names four UI states in its data: ShowLock, HideLock, ShowStartingTeamIcon and HideStartingTeamIcon.
- V: it reaches the unit renderer manager and reads a scene variable before the UI work.
- I: a lock icon marks a unit that cannot leave the party and a starting-team icon marks the battle roster, which is why the same function owns both toggles.
- ?: which screen calls it (party list, job screen or both) and which node each state is played on.
