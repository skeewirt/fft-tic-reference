## Purpose

Fills an effect description (out) from a usable item's or an action's added-effect record.

## Behavior

- V: for an item it reads the chemist sub-record's added-effect index (+2), for an action the action record's byte 11; the record's flag byte selects a copy of the 5 status bytes to out +9.. (0x80 / 0x20) or out +14.. (0x10).
