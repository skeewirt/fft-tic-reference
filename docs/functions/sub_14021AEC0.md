## Purpose

The classic-mode save step: it packs the live party into the work copy and writes the chosen slot.

## Behavior

- V: the live party is packed with SaveWork_PackFromParty, one of the five callers of the pack wrapper.
- V: the classic slot title card is built with SaveSlot_BuildClassicTitle.
- V: the slot is written through the same cache the enhanced path uses, so a classic save is a normal 0x9CE4 slot record (0x9CE4 is the size SaveWork_PackFromParty writes, not an immediate here).
- V: it is reached from the classic save menu, not from the enhanced slot screen.
- I: only the card presentation differs from the enhanced save; the record and container are identical.
