## Purpose

Sets up a battle window object. Only its unit list was read: it collects a number for each unit whose flag dword has bit 1.

## Behavior

- V: fills dword_1437A02D0 with -1, then for each of the 21 battle units whose dword +504 has bit 1 (0x2) stores the unit's byte +401 at the next index and counts them in dword_1437A019C.
- V: the same function copies 8 blocks of 128 bytes from unk_140D40060 into the window object.
- V: sets g_BattleState to 83 (the deployment state, in which Battle_AddJoinedUnit may use records 0..15).
- V: it is the deployment setup: for each record 0..20 (unless event variable 50 passes sub_1400FB65C(3, ...)) it keeps the slot byte and the drawn unit (SceneObject_FindByUnitIndex) in a 24-byte entry at window +2440 + 24 x record and sets the slot byte to 0xFF, so during deployment every record, the battle's own units included, reads as free to Battle_AddJoinedUnit's search (seen live 2026-11-22: with a battle unit in record 16, the first placement took record 16).
- V: clears window +0x18 (the joined unit's drawn unit, which Battle_JoinUnitAndLoad sets) to 0.
