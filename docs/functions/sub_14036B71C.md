Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Shop menu command handler: a switch on the command word drives buy, sell, equip and exit, and updates the shop list and the inventory.

## Behavior

- V: The command word at [rcx] is compared through a subtraction chain covering 0..0x21, with separate cases for 1 and 0x21.
- V: It calls ShopList_BuildEntries to rebuild the list and ItemOrder_SyncGroup to keep the order lists in step.
- V: Inventory_AddCount is called on the buy path, so the count change goes through the single write point.
- V: A 0x1F30-byte frame holds the list buffer, with an alloca probe for the large stack use.
- V: One caller, sub_14036BE10.
