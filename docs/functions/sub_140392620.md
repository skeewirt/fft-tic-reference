## Purpose

Builds the ability-token list for a job in a job-tree screen, restricted to an id window chosen by a3, tagging each id.

## Behavior

- V: resolves the job (Job_IdToIndex(a2); g_JobTable stride 49, 0xAE entries) and gets 24 ids via Skillset_BuildAbilityList(job, 47 or 31).
- V: a3 selects an id window: 0 -> 1..421, 1 -> 422..453, 2 -> 454..485, 3 -> 486..509; ids outside the window are zeroed.
- V: each kept id gets token bits `((byte_140787F83[8*id] >> 7) & 0x2000) + 0x4000`: the aux flags3 sign turns 0x4000 into 0x6000 (0x140392776).
- V: a4 is terminated with -1; returns the count.
