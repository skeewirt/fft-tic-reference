## Purpose

Returns the Item row byte +0x1A (column noun_class_2) of an item, or -1 when the row is missing.

## Behavior

- V: looks up nxd table 45 by item id and returns the byte at row +26; -1 when the table or row is missing.
- V: three callers push the result as a numeric format argument after the item id: BattleMsg_BuildArgs, sub_140142014 and sub_140196468.
