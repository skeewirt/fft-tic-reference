## Purpose

Applies a unit's pending status bits (bitset at unit-state +29..+33) to its status state, subject to immunity and conflict checks.

## Behavior

- V: sets the current preview unit a1 (g_BattleUnitTable + 512*a1, 512-byte records) and loops v7 over 0..39 status bits (`v7 < 40`).
- V: reads the status property table (0x140788FE0, 40 x 16 bytes) through compiler-folded operands: byte_140788DFC = 0x140788FEB + 16*v7 + i (bytes 11..15) at 0x14030CB31, ANDed with the unit's 5 bytes at +495; a hit skips the status.
- V: otherwise copies 5 bytes from aDefghijklmnopq = 0x140788FE6 + 16*v7 + j (bytes 6..10) into the unit-state byte array at +34 (0x14030CB7B).
- V: then calls sub_1403052DC(a2), sub_14030CA00(a1), sets the bit in the unit's +495 mask and calls sub_140278CF0(unit, v7, 0); a non-zero result skips the rest.
- V: special cases after that: status 19 clears byte +46; statuses 9 and 34 copy bits 0x30 of byte +5 from a second record (status 9 also clears some +494 bits and a word pair).

## State touched

- Calls: [sub_140278CF0](sub_140278CF0.md), [sub_1403052DC](sub_1403052DC.md)

## Notes

The displacements byte_140788DFC and aDefghijklmnopq lie numerically inside the aux table (0x140787F80..0x140788F80) but address the status property table at 0x140788FE0; the names are IDA auto-names, not real objects.

Both folded operands (0x14030CB31, 0x14030CB7B) address the status property table with folded offsets.
