## Purpose

Updates the panel icon and flags for one status effect on one unit.

## Behavior

- V: the first argument is the status id; the body indexes it as status + 1 and switches on that value.
- V: the default case reads a dword flag table at 0x1406735D0 by that index with no bound check.
- V: the table has defined entries past index 40, so a 41st status reads a meaningful but unintended word.
- I: the writes go to UI node flags, not to a sprite: the status list's icon source was not traced.
- ?: which sprite or part draws the icon, and what each flag bit means.
