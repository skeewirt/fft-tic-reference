## Purpose

Answers whether a unit may use one ability id: it checks the unit's availability flag and then the learned bit for that id.

## Behavior

- V: The unit index scales by 512 into the table at 0x141853CE0; a set bit 0x20 at +6 makes the id unavailable and the function returns 1.
- V: Ids 5..0x17 are accepted without a learned-bit test (the body tests `(id-5) <= 0x12`, so 0x17 is the inclusive upper bound, not an immediate).
- V: Id 0xE0 is mapped through Job_IdToIndex on the unit's job byte at +3 before the test.
- V: Otherwise the id must equal the unit's command byte at +0x12 or +0x192; then the learned bit is read from the array at +0x36 (byte id >> 3, bit id & 7), and the function returns 0 for set and 1 for clear.
- V: Eleven call sites in four functions, all AI candidate or scoring code.
