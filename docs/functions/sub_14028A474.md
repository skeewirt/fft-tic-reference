## Purpose

Builds a list of the first 24 ability slots of a party unit's job, tagging each id with display bits, in 9 modes selected by a6.

## Behavior

- V: for each slot reads a learned flag (BitReader_ReadBits(1) or forced 1) and the id a1[2*i]; id 0 is skipped.
- V: modes 0, 2 and 6 test the aux flags3 sign `byte_140787F83[8*id] >= 0` (0x14028A5F7, 0x14028A652, 0x14028A668); in mode 0 a clear sign sets token bit 0x4000, a set sign (not learned) gives 0x6000.
- V: the sources of Ability_GetAuxRecord are used in mode 8 only: entries whose category is not 6..8 are kept.
- V: modes 2 / 6 compare the unit's JP (word at +2*job+202) with Ability_GetJpCost and set 0x4000 when the JP is too low; modes 4 / 5 / 7 set 0x1000 for learned entries.
- V: outputs 8-byte records at a5 (job in word 0, tagged id in word 1), terminated with 0xFFFF0000 except modes 3 and 8; returns the count.
- V: the ability word of an 8-byte row gets 0x1000 (loaded at 0x14028A61B and 0x14028A62E, ORed at 0x14028A620 and 0x14028A633) or 0x6000 (ORed at 0x14028A678). No separate 0x4000 or 0x2000 immediate exists in this function: the 0x4000 half always arrives together with 0x2000 in the 0x6000 case.
