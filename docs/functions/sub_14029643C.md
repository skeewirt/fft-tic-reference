## Purpose

Fills one row of a multi-column item list, choosing the row filler by a kind argument.

## Behavior

- V: takes a context, a row source object, a row record, a row index and a kind on the stack.
- V: kind 1 selects a per-row entry at the row record plus 0x140 plus 0x58 times the index.
- V: for that entry it calls one of two fillers depending on a byte in the entry, then optionally writes a value into a node from a
  looked-up row.
- V: kind 0, the other branch, calls ItemCell_SetItem with the row's item id, which sets the small picture and the name.
- V: any other kind returns without filling.
- V: three direct call sites, all in one list-refresh function.
- I: the list is a shop or inventory list with several columns, because the filler is chosen per column kind.
