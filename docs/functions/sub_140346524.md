Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Clears the shop "new" badges and the poach "new" marks after the player has been through a shop or the den.

## Behavior

- V: the function returns immediately unless the global mode word at 0x1407D453C is non-zero and a field at offset 0x40 of a UI object is zero.
- V: it calls sub_14028B510, the routine that clears the shop badge for items sold in shops that are open at the current story progress.
- V: it then calls sub_14036F440 and sub_1402EDF94 to refresh the affected screens.
- V: a loop over poach types 1 through 96 checks the poach count byte at 0x1411A7810 + 522 and the two-byte new pair at + 813.
- V: when a type has a non-zero count and its new pair is set, the routine clears the high byte of the pair and records that something changed in the byte at 0x1411A7283.
- V: the loop bound is 97 entries and the count byte is read with the same + 522 offset the poach routines use.
- I: the two clears are badge bookkeeping for the shop and den screens, because the function only touches the badge and poach new flags and then refreshes the screens.
- ?: why the mode word at 0x1407D453C gates the whole routine.
