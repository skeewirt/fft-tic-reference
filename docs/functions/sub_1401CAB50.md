Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Insertion sort of a list of 24-byte poach entries by the poach item's sort name, ascending; ties fall back to the id.

## Behavior

- V: for each entry the PoachItem row (UI table 0xEC) of its first dword is fetched; the strings at row +0x14 (column sort_name) are compared byte by byte, and an entry that compares smaller moves before the previous one.
- V: when a row is missing or the strings are equal the dword 0 (the poach id) decides, smaller first.

## Notes

Name is ours. The other order (by the sort key byte) is sub_1401CAC8C. The +0x14 string is reached as dword index 5 of the row, so the constant 0x14 does not appear in the body.
