## Purpose

Refreshes the sprite palette state of all 19 cells after the cursor / mode changed.

## Behavior

- V: for i in 0..18 with cell = p + 8936 + 148 * i: if dword [cell+12] == 6 or (byte cell & 2) calls sub_140132DC8(p, i); then always sub_140132E1C(p, i, 1).

## Notes

Cell +12 == 6 means 'state 6' (the confirmed / cursor state in sub_140130DF0), bit 2 of the cell byte at p+8936 + 148 i is the 'tinted' flag set by sub_140132E1C.
