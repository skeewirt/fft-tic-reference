## Purpose

Builds the text of an event message. It installs the 32 text-pool bases, then substitutes each of up to five operand words with the string its text id names, writing the result into the message buffer.

## Behavior

- V: it fills 31 of the 32 pool bases: for index 1 to 31, base[index] = pack + 0x80 + the dword offset stored at pack + 4*index, with the pack pointer taken from a global. Slot 0 is left to EventScript_LoadIntoBuffer.
- V: it indexes a table of 0x258-byte message records by the current message index and stops at a 0xFF marker while looking for the record.
- V: it substitutes several groups of operand words from the message record: loops of five, five, two and five words, each read as a 16-bit value with stride 2; a word whose low 11 bits are all ones is treated as "no name".
- V: for each operand it builds a text id by adding one of 0x6800, 0x7800, 0x9800, 0x5800 or 0x6000 to the word, calls sub_140226208 and copies the returned string into the output buffer.
- V: 0xFE is written as the empty or separator byte when a substitution has no string.
- V: the copy loop checks a fixed end pointer and jumps to an overflow path when the buffer is full.
- I: the four loops are the operand groups of one event message instruction.
- ?: the exact operand layout and whether the text is rebuilt every frame or once.
