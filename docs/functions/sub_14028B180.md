## Purpose

Compares two item ids by one named record field and returns a signed ordering value. It is the single comparison used by
every item sort in the game.

## Behavior

- V: masks both ids to ten bits before doing anything else.
- V: obtains one key per id from the key helper, passing the field and the extra order argument through.
- V: for most fields the result is the second key minus the first.
- V: for three fields (the type, the id itself and the name-table key) the sign is inverted, so those fields sort the other
  way round.
- V: field 2 has an extra rule: ids in one particular category are ranked before the others, independent of their keys.
- V: field 9 compares the item names as byte strings, fetched from the item name table; equal strings compare equal.
- V: it returns zero only when the chosen field cannot distinguish the two ids.
- I: the inversion of three fields is deliberate and gives those fields the opposite order to the rest.
- ?: the exact intent of the field-2 category exception.
