## Purpose

Answers whether the container file for one area name exists, formatting the path against the save root selected by its second argument.

## Behavior

- V: the path is built from the area name and the literal `%s%s.png` against the root returned by the root selector, then handed to the file-existence helper.
- V: the second argument selects the root: index 0 is the Steam-id subfolder at +0x430, index 1 the parent folder at +0x530; the argument is doubled and incremented before the selector call, and the two offsets are in the selector's body, not this one.
- V: a 0x100-byte stack buffer holds the formatted path, so a name longer than the buffer would be truncated by the formatter.
- V: fourteen direct sites: the boot probe, the mount machine, the title and load-screen checks and the settings reads.
- I: it is a pure probe: it does not open, read or create anything, so a false answer means the caller skips its file step entirely.
- ?: whether the second root is a fallback tried after the first fails, or a separate question, is decided by each caller; the routine itself answers for the root it is given.
