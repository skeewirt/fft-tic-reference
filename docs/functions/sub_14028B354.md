Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Purpose

Produces the numeric sort key of one item for one field. The comparator calls it twice per comparison, once per id.

## Behavior

- V: field 0 returns the equip type byte of the item record, with one type value remapped to a larger number.
- V: field 1 returns the price word of the item record.
- V: field 2 returns a sub-record byte chosen by the item's menu category.
- V: field 3 returns a byte of the equipment sub-record: the weapon record's fifth byte for weapons, the shield or accessory
  record's first byte otherwise, and zero when the id fits neither.
- V: field 4 returns the shield or accessory record's second byte and zero for weapons.
- V: field 5 returns the owned-plus-equipped count of the id.
- V: field 10 returns the id itself.
- V: field 11 returns one when the extra order argument equals the id and zero otherwise.
- V: field 12 returns a dword read from the item's name-table row, and a large constant when the row is missing.
- V: fields 6, 7, 8 and 9 have no case and return zero; field 9 is handled inside the comparator instead.
- I: the pair of equipment bytes (fields 3 and 4) is what the equip screen sorts by when it orders gear within a category.
- ?: the meaning of the name-table dword used by field 12.
