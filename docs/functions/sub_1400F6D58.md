## Purpose

Steps a cursor value by one with wrap-around when the Left / Right pair is pressed (actions 35 / 36, masks 0x8000 / 0x2000; the input action table names them menu_left / menu_right, keys A / Left arrow and D / Right arrow), via sub_1400F6FA0.

## Behavior

- V: calls sub_1400F6FA0(&delta, &wrap = 1, keys, repeat). If it reports no press (delta 0) returns cur.
- V: n = cur + delta. wrap flag set: returns n; but n > max returns min, and n < min returns max (wraps). wrap flag clear: clamps to [min, max] (result = n bounded by max, then not below min).

## Notes

Used in the job-list panel input handlers for moving the cell cursor inside a column (min / max from the column table at panel+72). Masks 0x8000 / 0x2000 are Left / Right (input action table rows 35 / 36); the sibling sub_1400F6DD4 uses 0x1000 / 0x4000, Up / Down (rows 33 / 34).
