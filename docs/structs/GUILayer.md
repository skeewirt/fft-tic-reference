# GUILayer

- **Kind:** structure
- **Area:** [UI framework](../areas/ui-framework.md)
- **Size:** 592 bytes

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Summary

A UI layer: a component drawn offscreen and composited with its effects (mask, drop shadow, glow). Fields as read by the layer passes.

## Behavior

- V: live (Job Tree, 1280 x 720): the name tag layer reads strength 0.5, radius 0.8, offset (1.6, 1.6), rect (457, 2, 130, 94), atlas offset (296, -377); the title layer radius 2.0, offset (0, 2.667), strength 1.
- V (GUILayer_PackAtlasRect): a layer whose glow, effect or shadow radius exceeds 3.2 gets the wide margin when its atlas rectangle is packed (rect and atlas_offset are written there).
- V (live read 2026-10-30, 58 layers of a running screen): layer_kind 0 for every layer but one whole-layer blur layer (kind 1); blend_mode 0 for most, 2 (multiply) on the Lv chips, 7 on one; the last layer holds the full 1280 x 720 rectangle.
