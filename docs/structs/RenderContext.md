# RenderContext

- **Kind:** structure
- **Area:** [Graphics](../areas/graphics.md)
- **Size:** 6032 bytes

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Summary

The per-thread draw state every pass fills before it packs a command: sort key, clip rectangle, render target, blend and raster words, vertex/index buffers and three binding tables (constant buffers, textures, sampler words) indexed by registry slot ids. Contexts live in an array of the render device (stride 6032) and are reset at the start of every frame.

## Behavior

- V: RenderContext_ResetFrame rewrites every context at the start of a frame; all 64 sampler words become the default word (0 at runtime: point filter, wrap).
- V: a pass sets only the fields it needs and inherits the rest from whatever the context holds when it packs its command (see the flow FrameUiSubmission).
