# g_LoadedMapId

- **Kind:** global
- **Address:** `0x142FF9EB8`
- **Area:** [Battle](../areas/battle.md)
- **Type:** `int`

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Summary

32-bit id of the map the loader last accepted (a map with a block); read by the battle setup and the scene update, which compare it with stock map numbers; cleared by the scene reset
