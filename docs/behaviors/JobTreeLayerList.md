- **Kind:** observed behaviour
- **Scope:** the layer slots of a UI frame and, for the Job Tree screen, which component opens each one and how its float rectangle is made
- **Area:** [UI framework](../areas/ui-framework.md)
- **Affects:** [GUICore_CommitFrame](../functions/GUICore_CommitFrame.md), [GUICore_DrawWidget](../functions/GUICore_DrawWidget.md), [ComponentLayer_Begin](../functions/ComponentLayer_Begin.md), [ComponentEffects_Collect](../functions/ComponentEffects_Collect.md), [ComponentLayer_DrawMaskComponent](../functions/ComponentLayer_DrawMaskComponent.md), [GUIComponentRef_Draw](../functions/GUIComponentRef_Draw.md), [GUINode_DrawChildren](../functions/GUINode_DrawChildren.md), [GUILayer_Select](../functions/GUILayer_Select.md), [GUILayer_SetCurrent](../functions/GUILayer_SetCurrent.md), [GUILayer_Flush](../functions/GUILayer_Flush.md), [GUILayer_BoundsToRect](../functions/GUILayer_BoundsToRect.md), [UIRender_AccumulateQuadBounds](../functions/UIRender_AccumulateQuadBounds.md), [GUILayer_ExpandBounds](../functions/GUILayer_ExpandBounds.md), [GUIRenderer_ResetFrame](../functions/GUIRenderer_ResetFrame.md), [GUICore_DrawOutsideBars](../functions/GUICore_DrawOutsideBars.md), [GUILayer](../structs/GUILayer.md), [UiLayerComposite](../flows/UiLayerComposite.md), [WidgetRootsAreLayers](WidgetRootsAreLayers.md), [LayerCompositeOrder](LayerCompositeOrder.md), [LayerAtlasPlacement](LayerAtlasPlacement.md)

Confidence tags: **V** decoded, **M** measured, **I** inferred, **?** unknown.

## Summary

A UI layer is not tied to a component by any pointer: the layer records hold no component link (only the mask component of a masked layer is stored). The list of layers of a frame is a pure function of the draw traversal: widgets are drawn from the last vector entry to the first, inside a widget the component trees are walked last child first, a component with an enabled effect group (or the widget root) opens a layer slot, the parent continues in a new slot after every child layer, and a slot without any draw is reused. The float rectangle of a layer is the union of the integer bounds of the quads drawn into it, grown by the blur reach of its effects and by 16 pixels and clamped to the target. The Job Tree frame read live had 27 slots (26 used) for the screen's four drawing widgets.

## Behavior

- V: rectangle rule, step 1 (draws). UIRender_AccumulateQuadBounds raises the double bounds r+152..+176 with the four transformed corners of every emitted quad (min x, min y, max x, max y, layout pixels of the target). GUILayer_Flush (run at every layer switch and at the end of the frame) turns them into integers with GUILayer_BoundsToRect (left = trunc(min x), top = trunc(min y), right = trunc(max x + 1), bottom = trunc(max y + 1), truncation toward zero) and, when the result is non-empty, merges it into the slot's dirty rectangle r + 512 * slot + 41824 (replace when that is empty, else union). The dirty rectangles and the layer ids are cleared every frame by GUIRenderer_ResetFrame. So the dirty rectangle of a layer is the union over all of its quads of [trunc(min), trunc(max + 1)) in x and y.
- V: rectangle rule, step 2 (GUILayer_ExpandBounds, once per slot after the last widget). If the dirty rectangle is empty the layer rectangle is not written. Otherwise radius R = max(0, float layer+500 when the kind dword layer+28 is 1, layer+188 when the shadow byte +177 is set, layer+204 when the glow byte +178 is set, layer+180 when the single-float byte +176 is set); pad P = 0 for R <= 0, else f * UIBlur_TapCount(R / f, 1/255) with f = 1 (R <= 3.2), 2 (<= 6.4), 4 (<= 12.8), 8 (<= 25.6), 16 (<= 51.2), 32; examples: R 0.667 gives 3, 0.8 gives 3, 1.0 gives 4, 2.0 gives 6, 2.667 gives 8, 4.0 gives 12, 6.0 gives 16, 6.667 gives 20; every edge grows by P, then by 16, then is clamped to [0, 1280] x [0, 720] (W, H = r+184 / r+188); the layer rectangle (x, y, w, h) = (x0, y0, x1 - x0, y1 - y0) as floats at layer+208..+220. A layer entirely off the target ends with w or h = 0. An effect group whose flag byte is clear adds nothing, whatever stale radius the record still holds.
- V: the integer rectangle that GUILayer_PackAtlasRect derives (layer+240..+252) is therefore (x0', y0', x1', y1') with the clamped edges above; the live check on 26 + 40 used layers matched exactly (a drop-shadow layer of radius 2.0 gets P = 6, a glow of 2.667 gets 8, a single-float group of 0.667 gets 3).
- I: a software renderer needs no component link for the rectangle: it knows the quads of each layer, takes the union of their [trunc(min), trunc(max + 1)) bounds, and applies the pad of the layer's strongest effect radius, the 16 pixel margin and the clamp. The radii are the UIB radius times the layer scale min(sx, sy) (GUILayer_BuildRecord; 2/3 at 720p).
- V: component <-> layer link. The 592-byte layer record (r + 303480 + 592 * slot) and the 512-byte slot block (r + 512 * slot + 41336: 488 bytes of context copy, dirty rectangle, layer id, flag) contain no pointer to a component, widget or node, with one exception: the context copy of a masked layer (the layer of a component whose mask is a component) holds the mask component at ctx+392 and its Mask node at ctx+400 (live scan of all 27 slots for any component or widget address). The only other per-component value that survives is the layer id (ctx+548 = u16 comp+552 << 16, 0 for every component of the Job Tree). The link is therefore the traversal itself: replay GUICore_CommitFrame over the object tree (widget vector at core+24, components at widget+104, component node tree at comp+272, reference nodes kind 12 with the cached component at node+304 and the name keys at node+208 / +224) and count slots as below.
- V: slot machine (r = the UI renderer, count r+606584, current r+606588, draw counter r+606592). A draw (an image, text, rect, nine-grid, digit node, ...) increments the draw counter and records quads into the current slot. GUILayer_SetCurrent(-1) flushes (the counter merges into the slot, and the count grows when the current slot is the last one) and selects the slot index = count. ComponentLayer_Begin opens a layer when the component's effect collector returns 1 or the force rule applies (widget root: always, since widget byte +83 is 1; other components: byte comp+561): GUILayer_Select builds a record from the component context in the slot at index count (an existing record is reused only for a non-zero layer id with compatible settings). After a child component that opened a layer GUIComponentRef_Draw calls GUILayer_Select with the PARENT context: a new record at the next index with the parent's (inherited) effect groups, and every later draw of any component goes into it until another layer opens. A layer that received no draw leaves the count alone, so its slot is rebuilt by the next layer. At the end of a widget the open record is flushed and reset.
- V: a component with a mask component (comp+244 group resolving to a component, ctx+409): before its own layer is built ComponentLayer_DrawMaskComponent draws the mask component into the next slot (default record, flag +487 = 1, no layers inside it), and the component's layer follows in the slot after it (flags +489 = 1). A component with an image mask (ctx+384) opens only its own layer.
- V: the widget loop. GUICore_CommitFrame walks the widget vector from the last entry to the first (descending priority word w+62 along the vector, so ascending priority in draw order) and draws the widgets whose byte +74 or +75 is non-zero and +79 is zero. The two bar draws after the loop (GUICore_DrawOutsideBars for the layer transform whose int at +128 is 1) add a draw counter without quads, so the last slot of the frame is a counted empty slot (live: slot 26, dirty (0, 0, 0, 0), not used).
- V: inside a component, GUINode_DrawChildren starts at the first child, follows the +32 links to the last sibling and draws backwards through +40, so the last list entry is drawn first (bottom) and the first entry last (top); kinds: 1 container (recurse; Layer / LayerRoot nodes open nothing), 2 image, 3 text, 4 nine-grid, 5, 6 rect, 7, 8, 10, 12 component reference, 14 virtual; kinds 9 (Mask), 11 and 13 (Collision) draw nothing. A reference is skipped when its node is hidden (+204 = 0 or +145 set), when the component is missing, disabled (+416 = 0) or has the opacity group with +188 <= 0.
- V: components of the Job Tree widget (752 in memory) that can open a layer: UnitSelect (glow group, 23 of them), the Route* arrows (30, glow group) and Line* pieces (11, glow group) when their glow strength or radius is above 0, Cross (5, single-float group when its value is above 0), TextBoardJobName (23, drop-shadow group, always on while visible), TextMask of the main tab (drop shadow plus a component mask: TextBoard01 of ffto_main_tab) and the two BGBlur instances (opacity / blur group, comp+192: kind 1 layers, hidden in the frame read). - V: what depends on the screen state. ## Notes

The live replay is a read-only walker over the UI objects in memory (the static-layer extractor of Tree Studio). The studio's model: its atlas module (the layer trace and the placement) and its layer plan.
